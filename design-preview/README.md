# 拾光 · 界面改版预览（DAWN v2）

> 本目录是**界面改版方案的交付物**，不参与 Nuxt 构建，也不依赖项目运行环境。
> **未修改项目中任何已有代码**，整目录可直接删除。

## 打开方式

| 文件 | 说明 |
|---|---|
| **`preview.html`** | 可交互高保真原型（单文件自包含，双击用浏览器打开即可） |
| **`design-spec.html`** | 设计方案文档：现状诊断 + 设计令牌 + 页面级方案 + 落地建议（含前后对照截图） |

两个文件都不需要服务器、不需要构建，直接双击打开。

### 成熟度重评工具（`tools/maturity-audit.py`）

独立于原型的命令行工具，用于诊断与批量修正「幼苗标签失效」问题：

```bash
python design-preview/tools/maturity-audit.py                  # dry-run 报表
python design-preview/tools/maturity-audit.py --list EVERGREEN # 列出常青名单
python design-preview/tools/maturity-audit.py --stale 90       # 复核候选
python design-preview/tools/maturity-audit.py --apply          # 批量写入（自动备份，可回滚）
```

失效诊断、判定标准与治理机制见设计方案文档**第 10 章**。默认 dry-run 不改任何文件。
原型里的列表筛选条与图谱「按成熟度」着色，用的就是这套工具的重评结果（真实数据注入）。

### 原型怎么玩

- 底部有一枚 **「预览工具条 ›」** 胶囊，点开后可切换 7 个页面（登录 / 首页 / 列表 / 详情 / 图谱 / **我的密钥** / 后台）与交互状态（命令面板 / 新建笔记 / **新建文件夹** / **批量导入** / **导入超限** / 删除确认 / 编辑态 / 空状态），并可一键切换 **亮暗主题**、**移动端模拟**（390×812 真机尺寸）与 **身份**。
- **身份切换（工具条最右侧）** 是这一轮的重点：初始管理员 / 普通管理员 / 普通用户三档，切换后可以直观看到同一页面的三种形态 ——
  - 图标栏：普通用户不出现「后台」入口；
  - 后台页面：初始管理员可见 6 个密钥、可创建两类角色；普通管理员只见「自己 + 普通用户」4 个、只能创建普通用户、自己的行不可自禁；普通用户看到无权限页；
  - 笔记详情：普通用户不出现「编辑」，更多操作菜单里也没有「删除」；
  - 「我的密钥」页：三个角色都能看到自己的密钥 + 一份权限边界清单。
- 键盘：`⌘K` / `Ctrl+K` 打开命令面板（支持 `↑` `↓` `Enter`），`⌘\` 收起侧栏，`Esc` 关闭任意浮层。
- 侧栏可在「结构 / 领域 / 标签」三个面板间切换；拖动侧栏右缘可调宽。
- **结构树任意层级都可展开 / 收起**：展开态为「箭头旋转 90° 且转强调色 + 文件夹图标变强调色实底」，收起态为「箭头朝右灰色 + 文件夹灰描边」，两种状态一眼可辨。
- **新建文件夹**：结构面板段控行右侧的文件夹按钮（仅管理员身份可见）→ 选父目录（含 vault 根）→ 填名称 → 实时预览路径 → 创建后立即出现在目录树中。空名称 / 非法字符 / 同层重名都会就地提示。
- **批量导入笔记**：顶栏「新建 → 导入笔记（批量）」，或结构面板段控行右侧的上传按钮，或工具条上的「批量导入 / 导入超限」。支持**拖拽**、**选择文件**、**选择文件夹**（保留来源目录层级），可指定父目录 + 新建子文件夹，并实时显示落点路径。
  - **体积校验是真实的**：用浏览器 `File.size` 读取你选中的文件 —— 单个文件 **> 5 MB** 或单个文件夹合计 **> 100 MB** 会立即置为阻断，主按钮禁用并给出「哪条规则 / 超了多少 / 卡在哪个文件 / 怎么解决」四件事。
  - 三个策略可选：同名文件 **跳过 / 自动重命名 / 覆盖**；不支持的类型（如 `.png`）标为「跳过」而不阻断整体。
  - 对话框里有三枚**评审用示例**按钮（合规集合 / 单文件超限 / 文件夹超限），不准备任何文件也能看到三种关键状态。
  - 导入完成后目录树、笔记总数与「全部笔记」列表会同步更新。
- 笔记详情右上角 **「更多操作」菜单**：复制笔记链接 / 复制文件路径 / **在结构树中定位**（自动展开全部祖先目录并高亮当前笔记）/ 删除（仅管理员）。
- **结构树右键菜单**（触屏长按 500ms 等价）：右键文件夹 / 笔记 / 空白处，弹出该位置可用的操作 ——
  - **重命名**：就地编辑，Enter 提交 / Esc 取消；同目录重名、非法字符、空名都会被拒并给出完整原因。
  - **在本目录下新建文件夹 / 新建文件**：父目录已按右键位置预选，不用再手动找。
  - **复制 / 粘贴**：复制取快照存入前端剪贴板（侧栏底部出现可取消的提示条），粘贴到目标目录；同名一律拒绝，不允许粘到自身或其子目录。
  - **删除**：二次确认，文件夹会写明将连带删除多少篇笔记。
  - **权限按三档身份收敛**（切换工具条最右侧的「身份」看差异）：初始管理员六项齐全、可删非空文件夹；普通管理员删非空文件夹会被拒（「需初始管理员」）；**普通用户的六项写操作全部置灰并写明「只读身份」**，只保留「复制链接 / 复制路径」两个可用动作。vault 一级目录（`00_Inbox`、`03_Knowledge` …）对**所有角色**都不可重命名、不可删除。
- **侧栏折叠入口都在左边**：展开态用侧栏头部右上角的收起键；收起后在左侧图标栏顶部突出显示一枚展开键（带一次呼吸提示）。`⌘\` 快捷键同样可用。
- 图谱：拖拽节点可固定位置（双击解除），滚轮缩放，空白处拖拽平移；右上角「物理」开关会重新点火一次力导向，**布局收敛后会自动静止**，不会持续抖动。

## 目录结构

```
design-preview/
├── preview.html            交付物 ①：可交互原型（单文件，由 build.py 生成）
├── design-spec.html        交付物 ②：设计方案文档（单文件，由 build-spec.py 生成）
├── build.py                内联 src/ → preview.html
├── build-spec.py           内联 src/ + 截图 → design-spec.html（需要 Pillow）
└── src/
    ├── body.html           原型页面结构（含数据占位符）
    ├── styles.css          DAWN 设计语言样式表（令牌 + 组件 + 页面 + 响应式）
    ├── app.js              原型交互脚本（含轻量力导向布局，无第三方依赖）
    ├── spec.css            文档样式
    ├── spec-body.html      文档正文
    ├── fetch-snapshot.py   只读抓取线上真实数据快照（GET，无写操作）
    ├── data/               数据快照（48 篇笔记 / 55 标签 / 目录树 / 287 节点图谱 / 一篇完整样张）
    └── shots/              文档插图（JPEG，由 build-spec.py 自动生成）
```

## 重新构建

```bash
# 重建原型（无第三方依赖）
python build.py

# 重新抓取线上真实数据快照（需要项目根目录下的有效访问密钥）
python src/fetch-snapshot.py

# 重建设计方案文档（需要 Pillow，并把前后截图放到约定的临时目录）
python build-spec.py
```

## 关于数据

原型中的笔记标题、路径、标签、日期、图谱节点与连线，全部是线上花园的**真实数据快照**，不是占位文本。

原型为**离线静态稿**：筛选、分页、命令面板、对话框、图谱拖拽都在浏览器本地完成，
**不会发起任何网络请求，也不会写入任何数据**；演示用的表单提交只做界面反馈，不产生真实副作用。
