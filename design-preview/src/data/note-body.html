学习路径

基础类型 → 接口与函数 → 类与高级类型 → 泛型 → 类型断言守卫 → 类型兼容性与结构化类型 → 索引签名与索引访问类型 → 映射类型 → 工具类型与装饰器 → 类型声明文件

其中索引签名 → 映射类型 → 工具类型是一条强依赖链：映射类型借用索引签名语法，内置工具类型全部基于映射类型实现。
