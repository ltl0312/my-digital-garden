# NestJS 请求生命周期

## 📍 知识体系定位
- **所属技术栈**：后端（Node.js 生态）
- **所在层级**：NestJS 框架 → AOP 切面层（请求处理管道）
- **上游依赖**：<a href="obsidian://open?file=控制器与路由">NestJS 控制器与路由</a> — 理解请求从客户端到达控制器的路径
- **下游延伸**：<a href="obsidian://open?file=TypeORM数据库集成与CRUD">NestJS TypeORM 数据库集成</a> — 异常过滤器处理数据库层抛出的异常
- **同级技术**：Spring AOP（Filter → Interceptor → Aspect），Express 中间件链

## 概述（Overview）
> 一句话定义：NestJS 的请求生命周期定义了 HTTP 请求从进入服务器到返回响应的**完整处理管道**——依次经过中间件（Middleware）、守卫（Guard）、管道（Pipe）、拦截器（Interceptor）、控制器（Controller），异常时经过过滤器（Exception Filter）。

## 执行顺序概览

```
客户端请求
    │
    ▼
┌──────────────┐
│   中间件       │  ← 请求预处理：日志、CORS、body 解析
│  Middleware    │
└──────┬───────┘
       ▼
┌──────────────┐
│   守卫         │  ← 鉴权/授权：检查权限、角色
│   Guard        │
└──────┬───────┘
       ▼
┌──────────────┐
│   拦截器(前)   │  ← AOP 切面：请求转换、日志记录
│ Interceptor   │
└──────┬───────┘
       ▼
┌──────────────┐
│   管道         │  ← 参数验证与转换：DTO 校验、类型转换
│   Pipe         │
└──────┬───────┘
       ▼
┌──────────────┐
│   控制器       │  ← 路由处理：执行业务逻辑
│ Controller     │
└──────┬───────┘
       ▼
┌──────────────┐
│   拦截器(后)   │  ← 响应转换：包装响应格式
│ Interceptor   │
└──────┬───────┘
       ▼
    客户端响应
       
    ★ 任何环节抛出的异常 → 异常过滤器 (Exception Filter)
```

> 守卫在**所有中间件之后**、**任何拦截器或管道之前**执行。

## 一、中间件（Middleware）

中间件是在路由处理程序**之前**调用的函数，可访问 `request`、`response` 和 `next()`。

**用途**：身份验证、请求体解析、日志记录、CORS、请求参数预处理。

### 自定义中间件

```typescript
import { Injectable, NestMiddleware } from '@nestjs/common';
import { Request, Response, NextFunction } from 'express';

@Injectable()
export class LoggerMiddleware implements NestMiddleware {
    use(req: Request, res: Response, next: NextFunction) {
        console.log('Request...');   // ② 记录每次请求
        next();                       // ② 必须调用 next() 将控制权传递给下一个处理器
    }
}
```

### 应用中间件

```typescript
import { Module, NestModule, MiddlewareConsumer } from '@nestjs/common';

@Module({
    imports: [CatsModule],
})
export class AppModule implements NestModule {
    configure(consumer: MiddlewareConsumer) {
        consumer
            .apply(LoggerMiddleware)       // ② 应用中间件
            .forRoutes('cats');            // ② 限定路由范围：/cats 开头的所有路由
    }
}
```

### 多个中间件

```typescript
consumer.apply(cors(), helmet(), logger).forRoutes(CatsController);
// ② 按顺序执行：cors → helmet → logger
```

### 全局中间件

```typescript
const app = await NestFactory.create(AppModule);
app.use(logger);             // ② 全局生效，对所有路由
await app.listen(3000);
```

## 二、异常过滤器（Exception Filter）

异常过滤器负责处理应用中**所有未处理的异常**，自动发送友好的错误响应。

### 抛出标准异常

```typescript
@Get()
async findAll() {
    throw new HttpException('Forbidden', HttpStatus.FORBIDDEN);
}
// ③ 客户端收到：{ "statusCode": 403, "message": "Forbidden" }
```

### 自定义异常

```typescript
// ② 继承 HttpException，与内置异常处理无缝协作
export class ForbiddenException extends HttpException {
    constructor() {
        super('Forbidden', HttpStatus.FORBIDDEN);
    }
}
```

### 全局异常过滤器

```typescript
import { FastifyReply, FastifyRequest } from "fastify";
import { ExceptionFilter, Catch, ArgumentsHost, HttpException, HttpStatus } from '@nestjs/common';

// ② @Catch() 参数为空 → 捕获所有异常
@Catch()
export class AllExceptionsFilter implements ExceptionFilter {
    catch(exception: Error, host: ArgumentsHost) {
        const ctx = host.switchToHttp();
        const response = ctx.getResponse<FastifyReply>();
        const request = ctx.getRequest<FastifyRequest>();

        // ② 非 HTTP 标准异常统一返回 503
        response.status(HttpStatus.SERVICE_UNAVAILABLE).send({
            statusCode: HttpStatus.SERVICE_UNAVAILABLE,
            timestamp: new Date().toISOString(),
            path: request.url,
            message: new ServiceUnavailableException().getResponse(),
        });
    }
}

// ② @Catch(HttpException) → 只捕获 HTTP 相关异常
@Catch(HttpException)
export class HttpExceptionFilter implements ExceptionFilter {
    catch(exception: HttpException, host: ArgumentsHost) {
        const ctx = host.switchToHttp();
        const response = ctx.getResponse<FastifyReply>();
        const request = ctx.getRequest<FastifyRequest>();
        const status = exception.getStatus();

        response.status(status).send({
            statusCode: status,
            timestamp: new Date().toISOString(),
            path: request.url,
            message: exception.getResponse(),
        });
    }
}
```

### 业务异常封装

```typescript
import { HttpException, HttpStatus } from '@nestjs/common';

export class BusinessException extends HttpException {
    constructor(err: BusinessError | string) {
        if (typeof err === 'string') {
            err = { code: BUSINESS_ERROR_CODE.COMMON, message: err };
        }
        super(err, HttpStatus.OK);
    }

    static throwForbidden() {
        throw new BusinessException({
            code: BUSINESS_ERROR_CODE.ACCESS_FORBIDDEN,
            message: '抱歉哦，您无此权限！',
        });
    }
}

// ② 业务错误码集中管理
export const BUSINESS_ERROR_CODE = {
    COMMON: 10001,
    TOKEN_INVALID: 10002,
    ACCESS_FORBIDDEN: 10003,
    PERMISSION_DISABLED: 10003,
    USER_DISABLED: 10004,
};
```

## 三、管道（Pipe）

管道实现了 `PipeTransform` 接口，有两个典型用例：
- **转型**：将输入数据转换为所需形式（如字符串 → 整数）
- **验证**：评估输入数据，有效则原样传递，无效则抛出异常

管道在**控制器路由处理器**的参数上运行。Nest 在调用方法**之前**插入管道。

### 绑定管道

```typescript
@Get(':id')
async findOne(@Param('id', ParseIntPipe) id: number) {
    return this.catsService.findOne(id);
}
// ② ParseIntPipe 将 URL 字符串参数转为数字
// ③ 如果转换失败（如传入 'abc'），自动返回 400 错误
```

### 全局范围管道

```typescript
async function bootstrap() {
    const app = await NestFactory.create(AppModule);
    app.useGlobalPipes(new ValidationPipe());  // ② 全局应用验证管道
    await app.listen(3000);
}
```

## 四、守卫（Guard）

守卫实现了 `CanActivate` 接口，负责**授权**——根据权限、角色等条件决定是否将请求交给路由处理程序。

> 守卫在**所有中间件之后**、**任何拦截器或管道之前**执行。传统 Express 应用通常用中间件做鉴权，但 NestJS 提供了语义更精确的守卫层。

---

## 五、拦截器（Interceptor）

拦截器实现了 `NestInterceptor` 接口，提供 AOP 切面能力。`intercept()` 方法接收两个参数：`ExecutionContext` 和 `CallHandler`——不调用 `handle()` 方法就不会执行路由处理程序。

**用途**：响应格式统一包装、请求日志、性能监控、缓存。

### 完整的异常处理与拦截器注册

在 `main.ts` 中注册全局过滤器和拦截器：

```typescript
import { NestFactory } from '@nestjs/core';
import { AppModule } from './app.module';
import { AllExceptionsFilter } from './common/exceptions/base.exception.filter';
import { HttpExceptionFilter } from './common/exceptions/http.exception.filter';

async function bootstrap() {
    const app = await NestFactory.create(AppModule);

    // ② 注册全局异常过滤器
    app.useGlobalFilters(new AllExceptionsFilter(), new HttpExceptionFilter());

    await app.listen(process.env.PORT ?? 3000);
}
bootstrap();
```
