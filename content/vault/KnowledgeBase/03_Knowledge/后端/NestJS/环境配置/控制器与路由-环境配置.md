# NestJS — 控制器与路由环境配置

> 本指南聚焦于控制器的创建与配置。基础安装请参考 <a href="obsidian://open?file=环境配置与项目初始化">NestJS 环境配置与项目初始化</a>。

## 信息来源
- **官方文档**：https://docs.nestjs.com/controllers （✅ 可访问）

## Step 1: 使用 CLI 快速生成控制器

```bash
# 基础控制器
nest g co user

# 生成带 CRUD 的完整资源模块（推荐，会同时生成 controller + service + module + dto + entity）
nest g resource user
# 选择传输层：REST API
# 是否生成 CRUD 入口点：Y
```

## Step 2: 验证控制器路由

创建 `UserController` 后，CLI 会自动在 `app.module.ts` 中注册：

```typescript
@Module({
    controllers: [AppController, UserController],  // ← CLI 自动添加
    // ...
})
```

```bash
# 启动服务
npm run start:dev
# 浏览器访问 http://localhost:3000/user
```

## Step 3: 配置请求体验证（ValidationPipe）

```bash
npm i class-validator class-transformer -S
```

在 `main.ts` 中全局启用：

```typescript
import { ValidationPipe } from '@nestjs/common';

async function bootstrap() {
    const app = await NestFactory.create(AppModule);
    app.useGlobalPipes(new ValidationPipe({
        whitelist: true,         // 自动剔除 DTO 未定义的属性
        forbidNonWhitelisted: true, // 存在未定义属性时抛出 400
        transform: true,         // 自动类型转换
    }));
    await app.listen(3000);
}
```

## Step 4: DTO 验证示例

```typescript
import { IsString, IsInt, Min, Max } from 'class-validator';

export class CreateCatDto {
    @IsString()
    name: string;

    @IsInt()
    @Min(0)
    @Max(30)
    age: number;

    @IsString()
    breed: string;
}
```

## 可用装饰器速查

| 装饰器 | 作用 |
|--------|------|
| `@Controller('prefix')` | 指定控制器路由前缀 |
| `@Get()` / `@Post()` / `@Put()` / `@Delete()` / `@Patch()` | HTTP 方法 |
| `@Param('id')` | 捕获路由参数 |
| `@Query('key')` | 捕获查询字符串 |
| `@Body()` | 捕获请求体 |
| `@Headers('name')` | 捕获请求头 |
| `@HttpCode(201)` | 自定义响应状态码 |
