# NestJS — 模块系统环境配置

> 本指南聚焦于模块的创建与组织。基础安装请参考 <a href="obsidian://open?file=环境配置与项目初始化">NestJS 环境配置与项目初始化</a>。

## 信息来源
- **官方文档**：https://docs.nestjs.com/modules （✅ 可访问）

## Step 1: 模块组织结构最佳实践

```
src/
├── user/                         # 每个功能域一个独立目录
│   ├── dto/                      # 数据传输对象
│   ├── entities/                 # 数据实体
│   ├── user.controller.ts
│   ├── user.module.ts
│   └── user.service.ts
├── common/                       # 共享模块
│   ├── filters/                  # 异常过滤器
│   ├── guards/                   # 守卫
│   ├── interceptors/             # 拦截器
│   └── pipes/                    # 管道
├── config/                       # 配置文件
│   └── database.config.ts
├── app.module.ts                 # 根模块
└── main.ts
```

## Step 2: 创建功能模块

```bash
nest g resource user     # 一键生成完整模块
nest g mo common         # 创建共享模块目录
```

## Step 3: 模块导入/导出规则

```
规则一：模块默认是单例，同一 Provider 在所有导入处共享
规则二：Provider 必须位于当前模块的 providers 或被导入模块的 exports 中
规则三：@Global() 模块只需在根模块导入一次
规则四：动态模块的 forRoot() 在根模块调用，forFeature() 在功能模块调用
```

## Step 4: 动态模块配置模板

```typescript
import { Module, DynamicModule } from '@nestjs/common';

@Module({})
export class ConfigurableModule {
    static register(options: ModuleOptions): DynamicModule {
        return {
            module: ConfigurableModule,
            providers: [
                { provide: 'CONFIG_OPTIONS', useValue: options },
            ],
            exports: ['CONFIG_OPTIONS'],
        };
    }

    static forRootAsync(options: ModuleAsyncOptions): DynamicModule {
        return {
            module: ConfigurableModule,
            imports: options.imports || [],
            providers: [
                {
                    provide: 'CONFIG_OPTIONS',
                    useFactory: options.useFactory,
                    inject: options.inject || [],
                },
            ],
            exports: ['CONFIG_OPTIONS'],
        };
    }
}
```

> **💡 补充**：`register()` 用于同步配置，`forRootAsync()` 用于需要注入其他 Provider 的异步配置。

## 常用模块配置速查

| 场景 | 方法 | 示例 |
|------|------|------|
| 数据库连接 | `TypeOrmModule.forRootAsync()` | 从 ConfigService 读取数据库配置 |
| HTTP 客户端 | `HttpModule.register()` | 配置 baseURL、超时 |
| 定时任务 | `ScheduleModule.forRoot()` | 全局启用定时任务 |
| 事件 | `EventEmitterModule.forRoot()` | 全局启用事件系统 |
