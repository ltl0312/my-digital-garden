# NestJS — 环境配置与项目初始化

## 信息来源
- **官方文档**：https://docs.nestjs.com/first-steps （✅ 可访问）
- **参考文章**：掘金「看完这篇，Nestjs入门了」：https://juejin.cn/post/7432778708269170738

## 前置条件
- Node.js >= 16（推荐 Node.js 18 LTS 或 20 LTS）
- npm / yarn / pnpm 包管理器
- （可选）MySQL 8.0+（数据库章节需要）

## Step 1: 安装 NestJS CLI

```bash
# 全局安装 NestJS 命令行工具
npm i -g @nestjs/cli

# 验证安装
nest --version
# 预期输出：10.x.x
```

## Step 2: 创建新项目

```bash
# 创建项目（project-name 替换为你的项目名）
nest new project-name

# CLI 会询问：
# 1. 包管理器选择：npm / yarn / pnpm
# 2. 自动安装依赖
```

## Step 3: 项目结构速览

```
project-name/
├── src/
│   ├── app.controller.spec.ts   # 控制器单元测试
│   ├── app.controller.ts        # 路由控制器
│   ├── app.module.ts            # 根模块
│   ├── app.service.ts           # 业务逻辑服务
│   └── main.ts                  # 应用入口
├── test/                        # E2E 测试
├── nest-cli.json                # Nest CLI 配置
├── package.json
└── tsconfig.json
```

## Step 4: 启动项目

```bash
# 开发模式（热更新，推荐）
npm run start:dev

# 生产模式
npm run start:prod

# 普通启动（无热更新）
npm run start
```

启动后在浏览器访问 `http://localhost:3000`，应看到 `Hello World!`。

## Step 5: Nest CLI 常用命令

```bash
nest g resource user     # 生成完整 CRUD 模块（含 DTO、Entity、Service、Controller）
nest g mo user           # 只生成 Module
nest g co user           # 只生成 Controller
nest g s user            # 只生成 Service

# 禁用自动生成 .spec.ts 测试文件（nest-cli.json）：
{
    "generateOptions": {
        "spec": false
    }
}
```

## Step 6: 自定义端口与配置环境变量

```bash
npm i @nestjs/config -S
```

`.env` 文件：
```ini
PORT=3000
```

`main.ts` 中使用：
```typescript
await app.listen(process.env.PORT ?? 3000);
```

## 核心配置项说明

| 配置项 | 默认值 | 推荐值 | 说明 |
|--------|--------|--------|------|
| `nest-cli.json → generateOptions.spec` | 生成测试文件 | `false` | 不需要测试文件时禁用 |
| `tsconfig.json → resolveJsonModule` | `false` | `true` | 使用 Swagger 导入 package.json 时需要 |
| `main.ts → app.enableCors()` | 不启用 | 按需启用 | 前后端分离时需要 CORS |

## 常见问题

### 问题 1：端口被占用
- **解决**：修改 `main.ts` 中的端口号，或创建 `.env` 文件通过环境变量配置

### 问题 2：`nest` 命令不可用
- **解决**：确认全局安装成功：`npm list -g @nestjs/cli`。如使用 nvm，确认当前 Node 版本

### 问题 3：热更新不生效
- **解决**：确认使用 `npm run start:dev` 而非 `npm run start`。检查文件是否在 `src/` 目录下
