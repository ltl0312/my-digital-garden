## Step 1: 全局管道（ValidationPipe）配置

```bash
npm i class-validator class-transformer -S
```

在 `main.ts` 中：

```typescript
import { ValidationPipe } from '@nestjs/common';

async function bootstrap() {
    const app = await NestFactory.create(AppModule);
    app.useGlobalPipes(new ValidationPipe({
        whitelist: true,             // 剔除未知属性
        forbidNonWhitelisted: true,  // 遇到未知属性报 400
        transform: true,             // 自动类型转换
        transformOptions: {
            enableImplicitConversion: true,  // 隐式转换
        },
    }));
    await app.listen(3000);
}
```

## Step 2: 全局异常过滤器配置

创建 `src/common/filters/http-exception.filter.ts`：

```typescript
import { ExceptionFilter, Catch, ArgumentsHost, HttpException, HttpStatus } from '@nestjs/common';

@Catch()
export class AllExceptionsFilter implements ExceptionFilter {
    catch(exception: unknown, host: ArgumentsHost) {
        const ctx = host.switchToHttp();
        const response = ctx.getResponse();
        const status = exception instanceof HttpException
            ? exception.getStatus()
            : HttpStatus.INTERNAL_SERVER_ERROR;

        response.status(status).json({
            statusCode: status,
            timestamp: new Date().toISOString(),
            message: exception instanceof HttpException
                ? exception.message
                : 'Internal server error',
        });
    }
}
```

在 `main.ts` 中注册：

```typescript
import { AllExceptionsFilter } from './common/filters/http-exception.filter';
app.useGlobalFilters(new AllExceptionsFilter());
```

## Step 4: 全局 CORS 与中间件配置

```typescript
// main.ts
async function bootstrap() {
    const app = await NestFactory.create(AppModule);

    // 启用 CORS
    app.enableCors({
        origin: 'http://localhost:5173',   // 前端地址
        credentials: true,
    });

    // 全局中间件
    app.use(helmet());                     // 安全头
    app.use(compression());                // gzip 压缩

    await app.listen(3000);
}
```

## 组件作用域总结

| 组件类型 | 实现接口 | `useGlobal*()` | 应用时机 |
|---------|---------|---------------|---------|
| Middleware | `NestMiddleware` | `app.use()` | 路由处理前 |
| Guard | `CanActivate` | `useGlobalGuards()` | 中间件之后、拦截器之前 |
| Pipe | `PipeTransform` | `useGlobalPipes()` | 拦截器之后、控制器之前 |
| Interceptor | `NestInterceptor` | `useGlobalInterceptors()` | 控制器前后（AOP） |
| Filter | `ExceptionFilter` | `useGlobalFilters()` | 异常发生时 |
