# Java 面向对象 — 内部类与匿名内部类

- **所在层级**：Java 后端 → L1 面向对象

- **下游延伸**：📋 待补充：Java-Lambda表达式 —— 匿名内部类的函数式替代方案

## 核心概念
> 内部类是定义在另一个类内部的类，用于封装仅在一个地方使用的逻辑。匿名内部类是最常用的形式，适合一次性实现接口或抽象类。

## 一、内部类的分类

```java
class Test {
    static class Inner1 {}   // 静态内部类 → 相当于静态变量
    class Inner2 {}          // 实例内部类 → 相当于实例变量

    public void doSome() {
        class Inner3 {}      // 局部内部类 → 相当于局部变量（作用域仅在方法内）
    }
}
```

---

## 二、匿名内部类（最常用）

> 匿名内部类是**局部内部类的一种特殊形式**，没有名字，用一次就扔。

### 典型用法：临时实现接口
```java
class Test {
    public static void main(String[] args) {
        MyMath m = new MyMath();
        // 匿名内部类 —— 直接在参数中 new 一个接口实例
        m.mySum(new Computer() {
            public int sum(int a, int b) {
                return a + b;
            }
        }, 10, 20);
    }
}

interface Computer {
    int sum(int a, int b);
}

class MyMath {
    public void mySum(Computer c, int a, int b) {
        System.out.println(c.sum(a, b));
    }
}
```

### 为什么"不建议"广泛使用？
- 只能用一次，无法复用
- 如果同一逻辑需要在多处使用，用普通类实现接口更清晰
- 但在**回调、事件监听、一次性策略**等场景，匿名内部类非常方便

## 三、访问控制权限

Java 的 4 个访问控制权限：

| 访问控制符 | 本类 | 同包 | 子类 | 任意位置 |
|-----------|------|------|------|----------|
| `public`    | ✅ | ✅ | ✅ | ✅ |
| `protected` | ✅ | ✅ | ✅ | ❌ |
| 默认（不写）| ✅ | ✅ | ❌ | ❌ |
| `private`   | ✅ | ❌ | ❌ | ❌ |

### 各目标的可用修饰符

| 修饰目标 | 可用的访问控制符 |
|----------|-----------------|
| 属性 | 四个都可以 |
| 方法 | 四个都可以 |
| 类 | 只能 `public` 或默认 |
| 接口 | 只能 `public` 或默认 |

## 四、包（Package）与 import

- 包名命名规范：`公司域名倒序 + 项目名 + 模块名 + 功能名`
  - 如：`com.alibaba.druid.filter.stat`
- `package` 在代码第一行，`import` 在其下
- `java.lang` 包下的类不需要导包（如 String、System）
- 编译带包名的类：`javac -d . 类名.java`（`.` 表示当前目录，`-d` 自动创建包目录结构）
