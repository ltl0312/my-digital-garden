# SpringBoot 离线桌面应用架构设计

## 📍 知识体系定位
- **所属技术栈**：Java 后端
- **所在层级**：L3 框架层 → Spring Boot → 桌面部署模式
- **上游依赖**：Spring Boot 自动装配、JDBC 数据源配置、Vue 3 前端基础
- **下游延伸**：Tauri 桌面开发（L3 运维）、SQLite 进阶（WAL 模式/并发）
- **同级技术**：Docker 容器化部署（服务端模式）、传统 Web 部署（Tomcat）

## 概述（Overview）
> 将 Spring Boot 从"服务端 Web 应用"改造为"纯离线桌面程序"——数据存在本地 SQLite 文件，界面用 Electron/Tauri 套壳 Vue 3，后端在后台以 localhost 方式运行，用户感知不到这是一个 Web 应用。

## 设计初衷（Motivation）

### 历史演进
- **前身技术**：传统桌面开发用 C# WinForms/WPF（Windows 专属）或 Java Swing/JavaFX（UI 丑陋、开发效率低）。
- **为什么前身被淘汰**：Web 前端（Vue/React）的 UI 表现力远超原生桌面框架，开发者更愿意用熟悉的 Web 技术栈。
- **本技术的核心突破**：Electron/Tauri 将 Chromium/WebView 封装为桌面窗口外壳，让 Web 前端"伪装"成原生桌面应用；SQLite 让数据库变成单一文件，零安装零配置。
- **为什么是它活下来了**：VS Code、Figma、Notion 等顶级桌面应用都使用 Electron 架构，证明了"Web 技术栈做桌面软件"的可行性。Tauri 作为轻量化替代品正在快速崛起（体积更小、内存更低）。
- **当前版本**：Electron 28+ / Tauri 2.x / SQLite 3.4x / Spring Boot 3.x

> ⚠️ **版本兼容性**：Electron 依赖 Node.js 20+；Tauri 2.x 依赖 Rust 1.70+；SQLite JDBC 驱动版本需与 Spring Boot 3.x 兼容（推荐 `org.xerial:sqlite-jdbc:3.45+`）。

### 设计思想
核心思想是"降级而非重写"——把 Web 服务从"面向互联网"降级为"面向本地回环"：
- 用户浏览器 → `localhost:随机端口`（而非公网 IP）
- MySQL/Redis 服务端 → SQLite 本地文件（而非独立进程）
- 外网 API 调用 → 本地文件读写或本地计算
- 部署到服务器 → 打包为 `.exe` 双击运行

### 跨学科溯源（如适用）
> Electron 的 Chromium 内核 → XD-3（浏览器渲染引擎）→ XD-4（JavaScript 引擎 V8 的 JIT 编译）；SQLite 的 B-Tree 文件存储 → XD-5（数据结构）→ XD-2（文件系统页缓存）；Tauri 的 Rust 后端 → XD-4（系统编程语言的内存安全模型）。

## 实现（Implementation）

### 完整实例：Vue 3 + Electron + Spring Boot + SQLite 全栈离线应用

```
用户双击 MyApp.exe
  │
  ├─→ ① Electron 主进程启动
  │     └─ child_process.exec('java -jar app.jar --server.port=0')
  │         └─ Spring Boot 随机端口启动（如 54321）
  │
  ├─→ ② Spring Boot 连接 SQLite
  │     └─ jdbc:sqlite:./data.db（如果文件不存在则自动创建）
  │
  ├─→ ③ Electron 创建 BrowserWindow
  │     └─ 加载 Vue 3 打包的 dist/index.html
  │
  ├─→ ④ Vue 3 通过 axios 请求 http://localhost:54321/api/xxx
  │     └─ Spring Boot 处理业务逻辑 → 读写 SQLite → 返回 JSON
  │
  └─→ ⑤ 用户关闭窗口
        └─ app.on('before-quit') → javaProcess.kill() → 干净退出
```

### Electron 主进程代码（关键生命周期）

```javascript
// ① 引入依赖
const { app, BrowserWindow } = require('electron');
const { exec } = require('child_process');
const path = require('path');

let javaProcess = null;  // ② 持有 Java 进程引用，用于退出时清理

function startSpringBoot() {
    // ③ 启动 Spring Boot（server.port=0 自动分配端口）
    javaProcess = exec('java -jar app.jar --server.port=0', (error, stdout) => {
        if (error) console.error('Spring Boot 启动失败:', error);
    });
}

function createWindow() {
    const win = new BrowserWindow({ width: 1200, height: 800 });
    win.loadFile('dist/index.html');  // ④ 加载 Vue 3 前端页面
}

app.whenReady().then(() => {
    startSpringBoot();               // ⑤ 先启后端
    setTimeout(createWindow, 3000);  // ⑥ 等后端启动完再开窗口
});

// ⑦ 用户关闭窗口时杀死 Java 进程（关键！否则进程残留）
app.on('before-quit', () => {
    if (javaProcess) javaProcess.kill('SIGTERM');
});
```

### Spring Boot 配置（离线优化三件套）

```yaml
# ① 随机端口 — 防止 8080 被占用导致启动失败
server:
  port: 0

# ② SQLite 文件数据库 — 零安装，数据就是 .db 文件
spring:
  datasource:
    url: jdbc:sqlite:./data.db
    driver-class-name: org.sqlite.JDBC

# ③ 关闭不必要的 Web 功能
  jpa:
    database-platform: org.sqlite.hibernate.dialect.SQLiteDialect
    hibernate:
      ddl-auto: update  # 自动建表
```

```xml
<!-- pom.xml 添加 SQLite 依赖 -->
<dependency>
    <groupId>org.xerial</groupId>
    <artifactId>sqlite-jdbc</artifactId>
    <version>3.45.1.0</version>
</dependency>
```

> **💡 补充**：源文件提到 "最完美的落地组合是 Vue 3 + Tauri/Electron + Spring Boot + SQLite"。如果你对体积敏感，用 Tauri（Rust 内核，~5MB）替代 Electron（Chromium 内核，~200MB）。但 Tauri 的学习曲线更高（需要 Rust 基础）。

### 关键参数/配置说明

| 配置项 | 推荐值 | 原因 |
|--------|--------|------|
| `server.port` | `0` | 自动分配空闲端口，避免 8080 冲突 |
| `spring.datasource.url` | `jdbc:sqlite:./data.db` | 相对于 exe 目录，用户数据随身携带 |
| SQLite 并发 | 单连接/WAL 模式 | SQLite 默认不支持高并发写入，桌面应用单用户足矣 |
| Electron `child_process` | `exec`（非 spawn） | exec 自带 shell，兼容性更好 |
| 退出清理 | `javaProcess.kill('SIGTERM')` | 防止关闭窗口后 Java 进程残留 |
