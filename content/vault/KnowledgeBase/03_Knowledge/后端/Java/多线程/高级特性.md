## 一、守护线程

> 守护线程是为用户线程服务的，当所有用户线程结束时，守护线程自动终止。

```java
Thread t = new BackThread();
t.setDaemon(true);  // 设置为守护线程（必须在 start 前调用）
t.start();
// 主线程结束 → 守护线程也随之结束

class BackThread extends Thread {
    public void run() {
        int i = 0;
        while (true) {
            System.out.println("守护线程--->" + (++i));
            Thread.sleep(1000);
        }
    }
}
```

**典型守护线程**：GC 垃圾回收线程。

## 二、定时器（Timer）

> 间隔特定时间执行特定程序。Java 原生 Timer 是基础方案，实际开发主流使用 **SpringTask** 框架。

```java
import java.util.Timer;
import java.util.TimerTask;
import java.text.SimpleDateFormat;
import java.util.Date;

Timer timer = new Timer();
SimpleDateFormat sdf = new SimpleDateFormat("yyyy-MM-dd HH:mm:ss SSS");

timer.schedule(
    new TimerTask() {           // TimerTask 实现了 Runnable
        int i = 0;
        @Override
        public void run() {
            System.out.println("定时器第" + (++i) + "次执行，时间：" + sdf.format(new Date()));
        }
    },
    firstTime,    // 首次执行时间
    1000 * 10     // 每 10 秒执行一次
);
```

**schedule 方法**：`schedule(TimerTask task, Date firstTime, long period)`

## 三、wait 和 notify（生产者-消费者模式）

> wait、notify、notifyAll 是 **Object** 类的方法（不是 Thread 的方法），必须在 synchronized 块内调用。

### 核心方法对比

| 方法 | 调用者 | 效果 |
|------|--------|------|
| `obj.wait()` | 当前线程 | 让当前线程进入**等待**，并**释放** obj 对象的锁 |
| `obj.notify()` | 当前线程 | **唤醒** obj 上等待的一个线程，但**不释放**锁 |
| `obj.notifyAll()` | 当前线程 | **唤醒** obj 上等待的所有线程 |

### 生产者-消费者完整示例

```java
public class ShengChanZheXiaoFeiZhe {
    public static void main(String[] args) {
        KuCun c = new KuCun(50);   // 共享库存对象
        Thread ts = new ThreadShengChan(c);
        Thread tx = new ThreadXiaoFei(c);
        ts.start();
        tx.start();
    }
}

class KuCun {
    private Integer c;
    public KuCun(Integer c) { this.c = c; }
    public Integer getC() { return c; }
    public void setC(Integer c) { this.c = c; }
}

class ThreadShengChan extends Thread {
    KuCun c;
    public void run() {
        while (true) {
            synchronized (c) {
                if (c.getC() % 2 == 0 || c.getC() == 100) {
                    c.wait();  // 偶数或满仓 → 停止生产，等待
                }
                c.setC(c.getC() + 1);
                Thread.sleep(2000);
                System.out.println("生产者 → 当前库存：" + c.getC());
                c.notifyAll();  // 唤醒消费者
            }
        }
    }
}

class ThreadXiaoFei extends Thread {
    KuCun c;
    public void run() {
        while (true) {
            synchronized (c) {
                if (c.getC() == 0 || c.getC() % 3 == 0) {
                    c.wait();  // 零库存或能被3整除 → 停止消费，等待
                }
                c.setC(c.getC() - 2);
                Thread.sleep(2000);
                System.out.println("消费者 → 当前库存：" + c.getC());
                c.notifyAll();  // 唤醒生产者
            }
        }
    }
}
```

### 关键规则
- `wait()` 和 `notify()` 必须在 `synchronized` 代码块内使用
- `wait()` 会**释放锁**，`notify()` **不释放锁**
- 调用 `sleep()` 会让线程阻塞，但**不释放锁**

## 四、异步 vs 同步编程模型

| 模型 | 特点 | 适用场景 |
|------|------|----------|
| 异步编程 | 多线程并发，谁也不等谁 | 高并发、高性能要求 |
| 同步编程 | 排队执行，顺序保证 | 数据安全优先 |
