## 核心概念
> 一个进程可以有多个线程，线程是进程中的执行单元。多线程共享堆和方法区，但每个线程拥有独立的栈，目的是提高程序处理效率。

## 一、进程与线程

- **进程**：一个软件/应用就是一个进程
- **线程**：进程中的一个执行场景/执行单元
- Java 程序启动后至少有两个线程：**main 线程** + **GC 垃圾回收线程**

### 内存模型
```
堆内存（Heap）   →  所有线程共享
方法区（Method） →  所有线程共享
栈内存（Stack）  →  每个线程独立拥有一个栈
```

## 二、线程的三种实现方式

### 方式一：继承 Thread 类
```java
class MyThread extends Thread {
    @Override
    public void run() {
        System.out.println("子线程执行");
    }
}

// 使用
MyThread thread = new MyThread();
thread.start();  // 启动线程（JVM 开辟新栈空间 → 自动调用 run 方法）
```
> `start()` 方法的作用：在 JVM 中开辟新的栈空间，启动成功后的线程自动调用 run 方法。start() 执行完毕，该方法即结束使命。

### 方式二：实现 Runnable 接口（推荐）
```java
class MyRunnable implements Runnable {
    @Override
    public void run() {
        System.out.println("子线程执行");
    }
}

// 使用
Thread t = new Thread(new MyRunnable());
t.start();

// 或使用匿名内部类
Thread t = new Thread(new Runnable() {
    @Override
    public void run() { /* ... */ }
});
```
> **推荐方式二**：面向接口编程，类还可以继承其他类，扩展性更好。

### 方式三：实现 Callable 接口（JDK5+，有返回值）
```java
FutureTask task = new FutureTask(new Callable() {
    @Override
    public Object call() throws Exception {  // call 相当于 run，但有返回值
        System.out.println("call begin");
        Thread.sleep(3000);
        return 100 + 200;
    }
});

Thread t = new Thread(task);
t.start();

// 获取返回值（会阻塞当前线程！）
Object result = task.get();   // 300
System.out.println("后续代码"); // 等 t 线程结束才执行
```

| 方式 | 返回值 | 抛异常 | 推荐度 |
|------|--------|--------|--------|
| 继承 Thread | 无（void） | 不可抛受检异常 | ⭐⭐ |
| Runnable | 无（void） | 不可抛受检异常 | ⭐⭐⭐⭐⭐ |
| Callable | 有（泛型） | 可抛异常 | ⭐⭐⭐（需要返回值时） |

**Callable 的 trade-off**：能获取返回值，但 `get()` 方法会让当前线程阻塞等待，效率较低。

## 三、线程生命周期

```
新建态 --start()--> 就绪态 <---> 运行态 --run()结束--> 死亡态
                      ^              |
                      |   sleep/yield/等待锁
                      |              v
                      +---- 阻塞态 --+
```

线程的运行顺序不确定，取决于 CPU 调度。

## 四、线程常用方法

| 方法 | 说明 |
|------|------|
| `setName(String)` / `getName()` | 设置/获取线程名（默认为 Thread-0, Thread-1...） |
| `static currentThread()` | 获取当前线程对象 |
| `static sleep(long ms)` | 让当前线程休眠（阻塞），放弃 CPU 时间片 |
| `interrupt()` | 终止线程的睡眠（不是终止线程执行！） |
| `setPriority(int)` / `getPriority()` | 优先级（1低 ~ 5默认 ~ 10高） |
| `static yield()` | 让位，当前线程从运行态回到就绪态 |
| `join()` | 合并线程，当前线程等待调用 join 的线程执行完毕 |

### sleep 面试题
```java
Thread t = new MyThread();
t.setName("aa");
t.start();
t.sleep(1000 * 5);  // 谁在休眠？主线程！
// 因为 sleep 是静态方法，和对象无关，始终是 Thread.sleep() = 当前线程休眠
```

### 合理终止线程（stop 已过时）
```java
class MyRunnable implements Runnable {
    boolean run = true;  // 打布尔标记

    @Override
    public void run() {
        if (run) {
            // 正常执行
        } else {
            // 保存数据...
            return;  // 安全退出
        }
    }
}
// 外部设置 run = false 即可安全终止
```
> `stop()` 已过时（强行终止，数据可能丢失），用布尔标记是正确做法。
