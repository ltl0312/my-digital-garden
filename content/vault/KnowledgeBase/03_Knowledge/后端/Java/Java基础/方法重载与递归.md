## 核心概念
> 方法重载（Overload）让同名方法处理不同类型/数量的参数；递归以自调用的方式解决分治问题，但需谨慎控制深度以防栈溢出。

---

## 一、方法执行内存分析
JVM 内存三区域：
- **栈（Stack）**：存储局部变量，每个线程一个栈
- **堆（Heap）**：存储 `new` 出来的对象
- **方法区（Method Area）**：存储类信息、静态变量、常量池

---

## 二、方法重载（Overload）

### 三个必要条件
1. 在**同一个类**中
2. **方法名相同**
3. **参数列表不同**（数量、顺序、类型至少一项不同）

### 实际应用：统一打印方法
```java
class U {
    public static void p(byte b)    { System.out.println(b); }
    public static void p(short b)   { System.out.println(b); }
    public static void p(int b)     { System.out.println(b); }
    public static void p(long b)    { System.out.println(b); }
    public static void p(float b)   { System.out.println(b); }
    public static void p(double b)  { System.out.println(b); }
    public static void p(boolean b) { System.out.println(b); }
    public static void p(char b)    { System.out.println(b); }
}
```

> **注意**：方法重载只看参数列表，不看返回值类型。返回值不同的同名同参方法不构成重载，编译会报错。

## 三、方法递归

### 核心要点
- 递归很耗费栈内存，能不用尽量不用
- **必须有明确的结束条件**，否则会无限递归
- 无限递归会导致 **`java.lang.StackOverflowError`**（这是个 Error，不是 Exception，JVM 直接停止工作）

### 经典示例：累加与阶乘
```java
// 算 1~N 的和
public static int sum(int N) {
    if (N == 1) return 1;
    return N + sum(N - 1);
}

// 算 1~N 的阶乘
public static int mul(int N) {
    if (N == 1) return 1;
    return N * mul(N - 1);
}
```

### 递归 vs 迭代
| 维度 | 递归 | 迭代（循环） |
|------|------|-------------|
| 可读性 | 代码简洁，思路清晰 | 代码稍复杂 |
| 性能 | 每次调用创建栈帧，开销大 | 无额外栈帧开销 |
| 风险 | 栈溢出风险 | 无此风险 |

> 实际开发中，能用迭代（循环）解决的问题，优先使用迭代而非递归。
