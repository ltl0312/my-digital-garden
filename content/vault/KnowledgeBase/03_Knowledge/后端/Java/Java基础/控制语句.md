## 核心概念
> switch 语句是对多分支条件判断的优雅替代，支持 int/String/枚举 类型，case 穿透现象是排错的关键知识点。

## switch 语法结构
```java
switch (int或String类型的字面值或变量) {
    case 值1:
        java语句;
        break;   // 如果没有 break，会继续执行下一个 case（case穿透）
    case 值2:
        java语句;
        break;
    default:
        java语句;
}
```

## 关键规则
- **支持的类型**：int、String、枚举；byte / short / char 也可以，因为存在自动类型转换
- **版本历史**：Java 6 之前只能用 int，后续版本才支持 String 和枚举
- **case 可以合并**：多个 case 共享同一段处理逻辑
- **case 穿透**：如果 case 分支没有 `break`，会继续执行下一个 case 的内容（无论是否匹配）

```java
// case 合并示例
int i = 3;
switch (i) {
    case 1: case 2: case 3: case 10:
        System.out.println("Test Code!");
        break;
}
```

## Java 标准输入
```java
// 方式一：Scanner（推荐，最常用）
java.util.Scanner scanner = new java.util.Scanner(System.in);
int num = scanner.nextInt();      // 读取整数
String str = scanner.next();      // 读取字符串（不含空格）
String line = scanner.nextLine(); // 读取整行

// 方式二：传统 BIO
InputStreamReader is = new InputStreamReader(System.in);

```

## 实战：简单计算器
```java
public class SimpleComputer {
    public static void main(String[] args) {
        java.util.Scanner scanner = new java.util.Scanner(System.in);
        System.out.println("请输入第一个数字");
        int a = scanner.nextInt();
        System.out.println("请输入运算符");
        String fuhao = scanner.next();
        System.out.println("请输入第二个数字");
        int b = scanner.nextInt();
        switch (fuhao) {
            case "+":
                System.out.println(a + "+" + b + "=" + (a + b));
                break;
            case "-":
                System.out.println(a + "-" + b + "=" + (a - b));
                break;
            case "*":
                System.out.println(a + "*" + b + "=" + (a * b));
                break;
            case "/":
                System.out.println(a + "/" + b + "=" + (a / b));
                break;
            case "%":
                System.out.println(a + "%" + b + "=" + (a % b));
                break;
        }
    }
}
```
