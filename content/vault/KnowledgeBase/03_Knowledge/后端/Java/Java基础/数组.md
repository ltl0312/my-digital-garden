## 核心概念
> 数组是存储在堆内存中的、长度不可变的、元素地址连续的数据容器。其检索效率极高的优势来源于内存连续性，但增删效率低的劣势也源于此。

## 一、数组基础

- 存储在**堆内存**中
- 一旦创建，**长度不可变**
- `length` 属性返回数组长度（是属性不是方法！）

### 数组的初始化
```java
// 静态初始化
int[] a = {1, 2, 3};

// 动态初始化
int[] a = new int[5];  // 默认值：[0, 0, 0, 0, 0]

// 匿名数组（直接传入）
System.out.println(new int[]{1, 2, 3});
```

## 二、数组的核心优缺点

### 优点：检索效率极高
```
为什么检索快？因为三个条件同时满足：
1. 每个元素的内存地址在空间上是连续的
2. 每个元素占用的内存大小相同
3. 知道第一个元素的内存地址

→ 通过数学公式直接计算任意元素的位置：
  第 N 个元素地址 = 首地址 + (N-1) × 每个元素大小

→ 100 个元素的数组和 100 万个元素的数组，检索效率一样！O(1)
```

### 缺点
| 缺点 | 原因 |
|------|------|
| 随机增删效率低 | 增删中间元素时，后续所有元素需整体前移/后移 |
| 不能存储大数据量 | 内存中很难找到一大块连续的地址空间 |
| 扩容效率低 | 需要创建新数组并拷贝全部元素 |

> **例外**：向数组末尾添加/删除元素，不涉及元素移动，效率不受影响。

## 三、数组扩容
```java
// 扩容的本质：创建更大的新数组，拷贝原数据
int[] src = {1, 2, 3, 4, 5};
int[] dest = new int[src.length * 2];     // 新数组容量翻倍
System.arraycopy(src, 0, dest, 0, src.length);  // 拷贝
// arraycopy(源数组, 源起始位置, 目标数组, 目标起始位置, 拷贝长度)
```

**ArrayList 的扩容机制（1.5 倍）**本质上就是数组扩容的封装。

## 四、二维数组
```java
int[][] a = new int[2][2];  // 2行2列
a[0][0] = 1;                // 第一个一维数组的第一个元素

// 静态初始化
int[][] b = {{1, 2, 3}, {4, 5, 6}, {7, 8, 9}};
```
