## 核心概念
> Java 运算符分为算数、关系、逻辑、赋值、位运算等几大类，其中逻辑运算符中的「短路」机制是最容易被面试问到的核心点。

## 运算符分类

### 算数运算符
`+  -  *  /  %  ++  --`

### 关系运算符
`>  <  >=  <=  ==  !=` — 结果都是 boolean 类型

### 逻辑运算符（重点）
| 运算符 | 含义 | 短路特性 |
|--------|------|----------|
| `&`    | 逻辑与 | 无短路，两边都执行 |
| `&&`   | 短路与 | 左边为 false 则右边不执行 |
| `\|`   | 逻辑或 | 无短路，两边都执行 |
| `\|\|` | 短路或 | 左边为 true 则右边不执行 |
| `!`    | 逻辑非 | - |
| `^`    | 逻辑异或 | 两边算子不一样就是 true |

**要求两边都是 boolean 类型，最终结果也是 boolean 类型。**

### 短路 vs 非短路的经典对比
```java
int x = 10;
int y = 8;
System.out.println(x < y & ++x < y);  // 左边是 false，但 & 右边的 ++x 仍然执行
System.out.println(x);                 // 输出 11，因为 ++x 被执行了

// ====== 对比 ======

int x = 10;
int y = 8;
System.out.println(x < y && ++x < y); // 左边是 false，&& 直接短路，右边不执行
System.out.println(x);                 // 输出 10，因为 ++x 没有被执行
```

**`||` 和 `|` 的短路逻辑同理。** 实际开发中优先使用 `&&` 和 `||`，既安全又高效。

### 赋值运算符
`=  +=  -=  *=  /=  %=`

### 字符串连接运算符
`+` — 当至少一个操作数为 String 时，`+` 执行字符串拼接而非数学加法。

### 三元运算符（条件运算符）
`条件表达式 ? 表达式1 : 表达式2`
