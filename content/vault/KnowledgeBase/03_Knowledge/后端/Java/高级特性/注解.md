## 核心概念
> 注解是一种引用数据类型，编译后生成 .class 文件。它通过元注解控制可出现在哪里、保留到何时，配合反射在框架中发挥核心作用。

## 一、注解基础

### 基本定义与使用
```java
// 定义注解
public @interface MyAnnotation {
}

// 使用方法：在需要的地方加 @注解名
@MyAnnotation                   // 类上
class DoSome {
    @MyAnnotation               // 属性上
    int a;

    @MyAnnotation               // 方法上
    public void doSome() {
        @MyAnnotation int b;    // 局部变量上
    }
}
@MyAnnotation                   // 接口上
interface MyInterface {}
@MyAnnotation                   // 枚举上
enum Season {}
@MyAnnotation                   // 注解上（注解可修饰注解）
@interface OtherAnnotation {}
```

## 二、JDK 自带注解

### @Override
表示方法重写，**仅供编译器检查**（编译期遇到该注解 → 检查是否真的重写了父类方法，没有则报错）。

```java
// @Override 源代码
@Target(ElementType.METHOD)
@Retention(RetentionPolicy.SOURCE)   // 只保留在源文件中
public @interface Override {}
```

### @Deprecated
标记已过时的元素。

## 三、元注解（注解的注解）

### @Target
指定被修饰的注解可以出现在哪些位置：
```java
@Target({ElementType.TYPE, ElementType.METHOD, ElementType.FIELD})
// 可出现在：类、方法、属性上
```

### @Retention
指定被修饰的注解保留到哪个阶段：

| 值 | 说明 |
|----|------|
| `RetentionPolicy.SOURCE` | 只保留在 Java 源文件中 |
| `RetentionPolicy.CLASS` | 保留到 class 文件中（默认） |
| `RetentionPolicy.RUNTIME` | 保留到 class 文件中，且**可被反射读取** |

> **只有设为 RUNTIME，反射才能读取到该注解！** 这是框架中自定义注解的前提。

## 四、注解中定义属性

```java
@interface MyAnnotation {
    String name() default "ss";     // String 类型属性，默认值
    String[] ss();                   // 数组类型属性
    Season[] season();              // 枚举类型数组
}
```

### 使用时的赋值
```java
@MyAnnotation(name = "sss", ss = "ssss")  // 数组只有一个元素时 {} 可省略
public void doSome() {}
```

### value 属性的特权
如果注解只有一个属性且名为 `value`，使用时可以省略属性名：
```java
@interface MyAnnotation {
    String value();
}
@MyAnnotation("直接写值")  // 等价于 @MyAnnotation(value = "直接写值")
```

### 注解属性的合法类型
`byte, short, int, long, float, double, boolean, char, String, Class, 枚举类型` 及这些类型的**数组**。

## 五、反射读取注解（实战核心）

```java
// ==== 步骤1：定义注解 ====
@Target(ElementType.TYPE)
@Retention(RetentionPolicy.RUNTIME)  // 必须 RUNTIME！
@interface MyAnnotation {
    String username() default "";
    String password() default "";
}

// ==== 步骤2：使用注解 ====
@MyAnnotation(username = "admin", password = "123")
public class User {
}

// ==== 步骤3：反射读取注解 ====
Class c = Class.forName("User");

// 判断类上是否有某个注解
if (c.isAnnotationPresent(MyAnnotation.class)) {
    MyAnnotation ann = (MyAnnotation) c.getAnnotation(MyAnnotation.class);
    System.out.println(ann.username());  // "admin"
    System.out.println(ann.password());  // "123"
}

// 读取方法上的注解
Method method = c.getDeclaredMethod("doSome");
if (method.isAnnotationPresent(MyAnnotation.class)) {
    MyAnnotation ann = method.getAnnotation(MyAnnotation.class);
    // 读取属性值...
}
```

## 六、注解在开发中的作用（实战案例）

**需求：** 有一个 @ID 注解，只能出现在类上。被标注的类必须有一个 `int id` 属性，没有就报错。

```java
// 定义注解
@Target(ElementType.TYPE)
@Retention(RetentionPolicy.RUNTIME)
@interface ID {}

// 使用注解
@ID
class User {
    int id;
    String name;
}

// 验证逻辑（编译期检查）
public static void panDuan(String className) throws MyException {
    Class clazz = Class.forName(className);
    if (clazz.isAnnotationPresent(ID.class)) {
        Field[] fields = clazz.getDeclaredFields();
        for (Field field : fields) {
            if ("id".equals(field.getName())
                && "int".equals(field.getType().getSimpleName())) {
                return;  // 符合要求
            }
        }
        throw new MyException("语法错误：带 @ID 的类必须有 int id 属性");
    }
}
```

> 注解在框架中的本质作用：**简化配置、减少样板代码、编译期检查、运行时动态行为。**
