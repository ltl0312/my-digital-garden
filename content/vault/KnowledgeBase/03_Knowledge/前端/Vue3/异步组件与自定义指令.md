# Vue 3 异步组件、自定义指令与插件

## 📍 知识体系定位
- **所属技术栈**：前端 Vue 3
- **所在层级**：L1 框架核心 → 高级特性
- **上游依赖**：<a href="obsidian://open?file=响应式引擎与CompositionAPI">Vue3-响应式引擎与CompositionAPI</a>、<a href="obsidian://open?file=组件通信与插槽">Vue3-组件通信与插槽</a>
- **下游延伸**：Nuxt.js 自动导入、VueUse 工具库、企业级插件生态
- **同级技术**：React.lazy + Suspense、Angular Directive

## 概述（Overview）
> **异步组件（defineAsyncComponent）** 实现按需加载（代码分割），仅在需要时从服务器获取组件代码。**自定义指令（Custom Directives）** 封装可复用的 DOM 操作逻辑（如自动聚焦、权限控制）。**插件（Plugins）** 通过 `app.use()` 为整个应用添加全局功能（i18n、全局组件、全局属性）。

## 实现（Implementation）

### defineAsyncComponent

```javascript
import { defineAsyncComponent } from 'vue'
// 基本用法：import() 返回 Promise，Vite/webpack 自动做代码分割
const AsyncComp = defineAsyncComponent(() => import('./HeavyComponent.vue'))
// 带配置的高级用法
const AsyncCompWithOpts = defineAsyncComponent({
    loader: () => import('./Chart.vue'),
    loadingComponent: Spinner,    // 加载中显示的组件
    errorComponent: ErrorDisplay, // 加载失败显示的组件
    delay: 200,                   // 延迟多久才显示 loading（防闪烁）
    timeout: 5000                 // 超时时间（毫秒）
})
```

### 自定义指令

```vue
<script setup>
// 局部指令：以 v 开头的驼峰变量
const vFocus = {
    mounted: (el) => el.focus()
}

const vHighlight = {
    // 生命周期钩子
    created(el, binding) { },
    mounted(el, binding) { el.style.backgroundColor = binding.value; },
    updated(el, binding) { el.style.backgroundColor = binding.value; },
    unmounted(el) { /* 清理 */ }
}
// binding.value: 指令绑定的值
// binding.modifiers: 修饰符对象（如 v-demo.foo.bar → {foo:true, bar:true}）
</script>
<template>
    <input v-focus />
    <p v-highlight="'#ff0'">高亮文字</p>
</template>
```

### 全局注册指令和插件

```javascript
// main.js
const app = createApp(App)

// 注册全局指令
app.directive('focus', {
    mounted(el) { el.focus() }
})

// 注册插件
app.use(router).use(pinia).use(i18nPlugin, { locale: 'zh-CN' })
app.mount('#app')
```

### 编写插件

```javascript
// plugins/i18n.js
export default {
    install(app, options) {
        // 全局属性
        app.config.globalProperties.$translate = (key) => translations[key]
        // 全局依赖
        app.provide('i18n', options)
        // 全局组件
        app.component('GlobalButton', Button)
        // 全局指令
        app.directive('permission', permissionDirective)
    }
}

// 使用插件
import i18n from './plugins/i18n'
app.use(i18n, { locale: 'zh-CN' })
```

> **💡 补充**：异步组件的典型使用场景——路由懒加载（`const Home = () => import('@/views/Home.vue')`）、大型图表组件、富文本编辑器等重型库的按需导入。
