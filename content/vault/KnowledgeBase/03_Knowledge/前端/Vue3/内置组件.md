# Vue 3 内置组件

## 📍 知识体系定位
- **所属技术栈**：前端 Vue 3
- **所在层级**：L1 框架核心 → 内置组件
- **上游依赖**：<a href="obsidian://open?file=响应式引擎与CompositionAPI">Vue3-响应式引擎与CompositionAPI</a>、<a href="obsidian://open?file=模板语法与指令">Vue3-模板语法与指令</a>
- **下游延伸**：GSAP 动画库 + Transition 组合、路由级缓存
- **同级技术**：React Suspense + lazy、Angular ng-template

## 概述（Overview）
> Vue 3 提供 5 个无需注册即可使用的内置组件：**`<Transition>`/`<TransitionGroup>`**（进入/离开动画）、**`<KeepAlive>`**（缓存组件实例避免销毁）、**`<Teleport>`**（渲染到 DOM 树外部指定节点）、**`<Suspense>`**（协调异步依赖加载）、**`<component :is>`**（动态渲染不同组件）。

## 实现（Implementation）

### `<Transition>`：单元素/组件动画

```html
<Transition name="fade" mode="out-in" appear>
    <div v-if="show">Hello</div>
</Transition>

<style>
/* name="fade" → 对应类名自动生成 */
.fade-enter-active, .fade-leave-active { transition: opacity 0.5s ease; }
.fade-enter-from, .fade-leave-to { opacity: 0; }

/* JS 钩子 */
@before-enter, @enter, @after-enter, @leave 等
</style>
```

### `<KeepAlive>`：组件缓存

```html
<KeepAlive :include="['CompA', 'CompB']" :exclude="['CompC']" :max="10">
    <component :is="currentComponent" />
</KeepAlive>
<!-- max: LRU 算法移除最久未使用的（超过上限时） -->
<!-- 被缓存的组件需有 name（defineOptions 或自动推断） -->
```

### `<Teleport>`：传送门

```html
<!-- 将内容渲染到 <body> 下（常用于 Modal/Toast） -->
<Teleport to="body">
    <div class="modal">弹窗内容</div>
</Teleport>
<!-- disabled 属性动态切换 -->
<Teleport to="body" :disabled="isMobile">
    <div>移动端禁用传送</div>
</Teleport>
```

### `<Suspense>`：异步加载协调

```html
<Suspense>
    <template #default>
        <AsyncDashboard />  <!-- 含顶层 await 的组件 -->
    </template>
    <template #fallback>
        <LoadingSkeleton /> <!-- 加载中展示 -->
    </template>
</Suspense>
```

### `<component :is>`：动态组件

```html
<component :is="currentTab" />  <!-- is 可以是组件名字符串或组件对象 -->
```

### 内置组件应用场景速查

| 组件 | 典型场景 |
|------|---------|
| `<Transition>` | 弹窗淡入淡出、列表项滑入、路由切换动画 |
| `<KeepAlive>` | Tab 切换不销毁表单、列表-详情来回保持滚动位置 |
| `<Teleport>` | Modal 弹窗、全屏 Loading、Toast 通知 |
| `<Suspense>` | 异步组件加载骨架屏、代码分割后的 loading |
| `<component :is>` | Tab 切换面板、多步骤表单 |

> **💡 补充**：`<KeepAlive>` 缓存组件时触发 `onActivated`/`onDeactivated` 替代 `onMounted`/`onUnmounted`。被缓存组件内的定时器和全局事件要在 `onDeactivated` 中暂停，`onActivated` 中恢复。
