# Vue 3 组件通信 — 环境配置与项目初始化

## 前置条件
- Vue 3 项目（参考 <a href="obsidian://open?file=模板语法-环境配置与项目初始化">Vue3-模板语法-环境配置与项目初始化</a>）

## Step 1: Vue DevTools 组件通信调试

安装 Vue DevTools 浏览器扩展（v7+）→ `F12` → Vue 标签：
- **Components** 面板：选中组件 → 右侧查看 Props、路由参数、注入的数据
- **Timeline** 面板：追踪 emit 事件触发时序
- **Pinia** 面板：查看全局 Store 状态

## Step 2: 验证组件通信

```vue
<!-- Parent.vue -->
<script setup>
import { ref } from 'vue'
import Child from './Child.vue'
const msg = ref('Hello from parent')
function onUpdate(val) { msg.value = val }
</script>
<template><Child :message="msg" @update="onUpdate" /></template>
```
Vue DevTools 中选中 Child → 查看 Props 面板 → 确认 `message` 值为 `"Hello from parent"`。

## Step 3: provide/inject 调试

在 Vue DevTools Components 面板中，选中后代组件 → 右侧 "Inject" 区域显示所有 injected 的 key 和值。

## 常见问题

1. **Props 更新子组件不响应**：确认 prop 是响应式变量（ref/reactive），不是静态值。
2. **provide 的值后代取不到**：provide 必须在 setup 同步执行，不能在异步回调中 provide。
3. **插槽内容不渲染**：确认子组件有 `<slot>` 占位，且插槽名称（name）与父组件 `#name` 一致。
