# Vue 3 模板语法 — 环境配置与项目初始化

## 信息来源
- **Vue 3 官方**：https://cn.vuejs.org/（✅ 可访问）
- **Vite**：https://vitejs.dev/（✅ 可访问）

## 前置条件
- Node.js 18+（参考 <a href="obsidian://open?file=基础语法-环境配置与项目初始化">JavaScript-基础语法-环境配置与项目初始化</a>）

## Step 1: 创建 Vue 项目

```bash
npm create vue@latest my-vue-app
cd my-vue-app && npm install && npm run dev
```
按提示选择：TypeScript ✅ / JSX ✅ / Vue Router ✅ / Pinia ✅ / ESLint ✅

## Step 2: 推荐 VS Code 扩展

- **Vue - Official**（Volar）：替换 Vetur，Vue 3 + TS 核心扩展
- **Vue VSCode Snippets**：快速代码片段

## Step 3: 验证

浏览器打开 `http://localhost:5173` → 看到 Welcome 页面 → 编辑 `App.vue` → 热更新即时生效。

## Step 4: 最小组件示例

```vue
<script setup>
import { ref } from 'vue'
const count = ref(0)
</script>
<template>
  <button @click="count++">Clicked {{ count }} times</button>
</template>
```
保存 → 浏览器自动刷新 → 点击按钮 count 递增。

## 常见问题

1. **`ref` 在模板中不需要 `.value`**：模板编译时自动解包。
2. **Vue DevTools 不显示**：安装 Vue DevTools 浏览器扩展（v7+ 支持 Vue 3）。
3. **`@` 别名路径不识别**：需要在 `vite.config.ts` 中配置 alias。
