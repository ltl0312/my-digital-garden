# Vue 3 内置组件 — 环境配置

## Step 1: Transition 调试

Chrome DevTools → Animations 面板（`⋮` → More tools → Animations）→ 触发 Transition → 可逐帧查看 CSS 过渡和动画执行。

## Step 2: KeepAlive 验证

Vue DevTools Components 面板 → 被 KeepAlive 缓存的组件显示为 "inactive" 状态 → 切换组件后状态保留（输入框内容不丢失）。

## Step 3: Teleport 验证

```html
<Teleport to="body"><div class="modal">弹窗</div></Teleport>
```
DevTools Elements 面板 → 在 `<body>` 末尾找到传送的元素（而非组件原位置）。

## 常见问题

1. **Transition 动画不触发**：确认元素是 `v-if`/`v-show` 控制显隐，或组件通过 `<component :is>` 切换。
2. **KeepAlive 缓存失效**：被缓存组件必须有 `name` 选项（defineOptions 或自动推断），且未在 `exclude` 列表中。
