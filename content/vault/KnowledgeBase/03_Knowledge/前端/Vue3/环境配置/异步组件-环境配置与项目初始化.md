# Vue 3 异步组件与插件 — 环境配置

## Step 1: 代码分割验证

```bash
npm run build  # Vite 构建项目
# 检查 dist/assets/ 目录 → 应有独立 chunk 文件（如图表组件的单独 JS）
```
Chrome DevTools Network 面板 → 访问页面 → 切换路由 → 看到额外的 JS chunk 被懒加载（名称类似 `Chart-abc123.js`）。

## Step 2: 自定义指令验证

```vue
<script setup>
const vFocus = { mounted: (el) => el.focus() }
</script>
<template><input v-focus /></template>
```
页面加载后 → input 自动获得焦点（光标在输入框内闪烁）。

## Step 3: 插件验证

```javascript
// main.js
app.use(myPlugin, { option: 'value' })
// Console 中检查 app.config.globalProperties 是否有插件注入的属性
```

## 常见问题

1. **异步组件白屏**：忘配 loadingComponent → 网络慢时白屏。设置 `delay: 200` 避免闪烁。
2. **自定义指令不生效**：变量名必须以 `v` 开头（驼峰），模板中自动转为 `v-xxx` 格式。
3. **app.use() 顺序错误**：Router 必须在 Pinia 之前安装，确保路由守卫能访问 Store。
