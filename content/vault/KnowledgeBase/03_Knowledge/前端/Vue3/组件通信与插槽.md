# Vue 3 组件通信与插槽

## 📍 知识体系定位
- **所属技术栈**：前端 Vue 3
- **所在层级**：L1 框架核心 → 组件通信
- **上游依赖**：<a href="obsidian://open?file=响应式引擎与CompositionAPI">Vue3-响应式引擎与CompositionAPI</a>、<a href="obsidian://open?file=模板语法与指令">Vue3-模板语法与指令</a>
- **下游延伸**：Vue Router 路由通信、Pinia 全局状态共享
- **同级技术**：React Props + Context、Angular @Input/@Output

## 概述（Overview）
> Vue 3 组件通信有五层机制：**Props Down**（父→子，defineProps）、**Events Up**（子→父，defineEmits）、**Slots**（父→子模板注入）、**provide/inject**（祖先→任意后代跨层级）、**defineModel**（Vue 3.4+ 简化 v-model 双向绑定）。`useAttrs` 处理未声明为 props 的透传属性，`defineExpose` 控制子组件暴露给父组件的内容。

## 实现（Implementation）

### Props：defineProps

```vue
<!-- 父组件 -->
<Child :title="pageTitle" :count="5" />

<!-- 子组件 -->
<script setup>
// 运行时声明
const props = defineProps({ title: String, likes: Number })
// TS 类型声明
const props = defineProps<{ title: string; count?: number }>()
// 带默认值（Vue 3.3+）
const props = withDefaults(defineProps<{ title: string; count?: number }>(), { count: 0 })
// Vue 3.5+ 响应式 Props 解构
const { title, count = 0 } = defineProps<{ title: string; count?: number }>()
</script>
```

### Emits：defineEmits

```vue
<script setup>
// 运行时声明
const emit = defineEmits(['change', 'delete'])
// TS 声明（Vue 3.3+ 简洁写法）
const emit = defineEmits<{ change: [id: number]; update: [value: string] }>()
emit('change', 123)
</script>
```

### v-model 组件通信（defineModel，Vue 3.4+）

```vue
<!-- 父组件 -->
<Child v-model="msg" />
<Child v-model:title="titleMsg" />

<!-- 子组件 -->
<script setup>
const model = defineModel({ type: String, default: '' })
const title = defineModel('title', { type: String })
// 修改即触发 update:modelValue / update:title
model.value = 'New Value'
</script>
<template><input v-model="model" /></template>
```

### 插槽 Slots

```vue
<!-- 子组件 -->
<template>
  <div class="container">
    <header><slot name="header">默认标头</slot></header>
    <main><slot>默认内容</slot></main>              <!-- 默认插槽 -->
    <footer><slot name="footer"></slot></footer>
    <!-- 作用域插槽：向父组件暴露子组件数据 -->
    <ul><slot name="item" v-for="item in items" :item="item" :index="index" /></ul>
  </div>
</template>

<!-- 父组件 -->
<Child>
  <template #header><h1>{{ title }}</h1></template>
  <p>默认插槽内容（无需 template 包裹）</p>
  <template #footer>Footer content</template>
  <template #item="{ item, index }">{{ index }}: {{ item.name }}</template>
</Child>
```

### 依赖注入：provide / inject

```javascript
// 祖先组件
import { provide, ref } from 'vue'
const theme = ref('dark')
provide('theme', theme)           // 建议 key 用 Symbol('theme')

// 后代组件（任意层级）
import { inject } from 'vue'
const theme = inject('theme', 'light')  // 第二个参数为默认值
```

### 透传 Attributes：useAttrs

```vue
<script setup>
import { useAttrs } from 'vue'
const attrs = useAttrs()  // 获取未声明为 props/emits 的属性（class, style, id 等）
defineOptions({ inheritAttrs: false })  // 禁用自动继承到根元素
</script>
<template><div v-bind="$attrs">手动绑定到特定元素</div></template>
```

> **💡 补充**：通信方案选择指南——父→子用 props，子→父用 emits，跨多层用 provide/inject（或 Pinia），模板注入用 slots，简单双向绑定用 defineModel。
