# Vue 3 模板语法与指令

## 📍 知识体系定位
- **所属技术栈**：前端 Vue 3
- **所在层级**：L1 框架核心 → 模板语法
- **上游依赖**：<a href="obsidian://open?file=基础语法与文档结构">HTML5-基础语法与文档结构</a>、<a href="obsidian://open?file=基础语法与数据类型">JavaScript-基础语法与数据类型</a>
- **下游延伸**：Vue 3 组件开发、自定义指令
- **同级技术**：React JSX、Angular 模板语法

## 概述（Overview）
> Vue 使用基于 HTML 的模板语法，通过 `v-` 前缀指令（Directives）将 DOM 元素绑定到响应式数据。核心指令覆盖：数据输出（`{{ }}`/v-text/v-html）、属性绑定（v-bind）、事件监听（v-on）、双向绑定（v-model）、条件渲染（v-if/v-show）、列表渲染（v-for）、插槽（v-slot）。

## 设计初衷（Motivation）

### 设计思想
Vue 模板语法的设计哲学是"声明式渲染"——你声明"当数据 X 变化时，DOM 应该变成 Y"，Vue 负责计算最小的 DOM 更新。这与 jQuery 的"命令式 DOM 操作"形成对比。Vue 模板在编译阶段被转化为优化的渲染函数（Virtual DOM），`v-memo` 等编译时优化指令进一步减少不必要的 DOM 更新。

### 跨学科溯源
- v-if/v-for 编译 → <a href="obsidian://open?file=XD-4 编程语言与编译">XD-4 编程语言与编译</a>（模板编译为 VNode 树：parse → transform → generate 三阶段）
- `v-memo` 缓存 → <a href="obsidian://open?file=XD-5 数据结构与算法">XD-5 数据结构与算法</a>（记忆化 Memoization：依赖数组不变则跳过子树渲染）

## 实现（Implementation）

### 数据输出：`{{ }}` / v-text / v-html

```html
<span>{{ count + 1 }}</span>           <!-- 插值，支持 JS 表达式 -->
<span v-text="msg"></span>             <!-- 同 {{ }}，替换全部内容 -->
<!-- ⚠ v-html 有 XSS 风险！绝不对用户输入使用 -->
<div v-html="rawHtml"></div>
```

### v-bind（简写 `:`）：属性动态绑定

```html
<img :src="imageSrc" />
<button :disabled="isDisabled">按钮</button>
<button :[key]="value">动态属性名</button>      <!-- 属性名也可动态 -->
<div v-bind="objectOfAttrs">批量绑定</div>      <!-- 绑定对象 -->
<!-- 修饰符：.camel .prop .attr -->
```

**Class 与 Style 绑定**：
```html
<!-- Class：对象语法 + 数组语法 -->
<div :class="{ active: isActive, 'text-danger': hasError }"></div>
<div :class="[activeClass, errorClass]"></div>

<!-- Style：对象语法 + 数组语法（自动加浏览器前缀） -->
<div :style="{ color: activeColor, fontSize: fontSize + 'px' }"></div>
<div :style="[baseStyles, overridingStyles]"></div>
```

### v-on（简写 `@`）：事件绑定

```html
<button @click="counter++">+1</button>
<button @click="handleClick('hello', $event)">传参</button>

<!-- 事件修饰符（可链式调用） -->
@click.stop.prevent   <!-- 阻止冒泡 + 阻止默认 -->
@click.once           <!-- 只触发一次 -->
@keyup.enter          <!-- 按键：.enter .tab .delete .esc .space -->
@click.ctrl           <!-- 系统键：.ctrl .alt .shift .meta .exact -->
@click.left           <!-- 鼠标：.left .right .middle -->
```

### v-model：双向绑定

```html
<input v-model="text" />                <!-- text/textarea -->
<input type="checkbox" v-model="checked" />
<select v-model="selected">...</select>

<!-- 修饰符 -->
v-model.lazy     <!-- change 事件而非 input 事件时同步 -->
v-model.number   <!-- 自动 parseFloat -->
v-model.trim     <!-- 自动去除首尾空格 -->
```

### v-if / v-show：条件渲染

```html
<h1 v-if="awesome">Vue is awesome!</h1>
<h1 v-else-if="good">Not bad</h1>
<h1 v-else>Oh no 😢</h1>
<!-- v-if 支持 <template> 包裹，v-show 不支持 -->
<!-- 频繁切换用 v-show（display:none），不频繁用 v-if（销毁/重建） -->
```

### v-for：列表渲染

```html
<!-- 数组：必须绑定 :key（用唯一 ID，不用 index） -->
<li v-for="(item, index) in items" :key="item.id">{{ item.name }}</li>
<!-- 对象 -->
<li v-for="(value, key, index) in object" :key="key">{{ key }}: {{ value }}</li>
<!-- 整数（从 1 开始） -->
<span v-for="n in 10" :key="n">{{ n }}</span>
```

### 其他编译优化指令

```html
<!-- v-slot（简写 #）：具名插槽 -->
<template #header>...</template>

<!-- v-pre：跳过编译，显示原始 {{ }}  -->
<span v-pre>{{ this will not be compiled }}</span>

<!-- v-once：只渲染一次，后续视为静态 -->
<div v-once>{{ expensiveCalculation() }}</div>

<!-- v-memo（Vue 3.2+）：依赖不变则跳过子树重新渲染 -->
<div v-memo="[valueA, valueB]">{{ heavyComponent }}</div>

<!-- v-cloak：编译完成前隐藏，防闪烁（配合 CSS [v-cloak] { display: none }） -->
<div v-cloak>{{ message }}</div>
```

> **💡 补充**：`v-if` 和 `v-for` **不推荐放在同一元素上**。Vue 3 中 `v-if` 优先级高于 `v-for`，导致 `v-if` 无法访问 `v-for` 作用域内的变量。解决方案：用 `<template>` 包裹 `v-for`，外层放 `v-if`。
