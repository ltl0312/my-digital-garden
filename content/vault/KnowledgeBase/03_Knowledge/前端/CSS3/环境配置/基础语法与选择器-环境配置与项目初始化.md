# CSS3 基础语法与选择器 — 环境配置与项目初始化

## 信息来源
- **官方文档**：https://developer.mozilla.org/zh-CN/docs/Web/CSS（✅ 可访问）

## 前置条件
- VS Code + Live Server（参考 <a href="obsidian://open?file=基础语法-环境配置与项目初始化">HTML5-基础语法-环境配置与项目初始化</a>）
- 已创建 HTML 项目

## Step 1: 推荐 VS Code 扩展

- **CSS IntelliSense**：类名、ID 的智能补全
- **Stylelint**：CSS 代码规范和错误检查
- **Color Highlight**：颜色值在编辑器中显示实际色块

## Step 2: 验证

创建 `test.html` 和 `style.css`：
```html
<!-- test.html -->
<link rel="stylesheet" href="style.css">
<h1 class="title">Hello CSS</h1>
```
```css
/* style.css */
.title { color: #3498db; font-size: 24px; }
```
Live Server 打开 → 标题显示为蓝色 24px → CSS 加载成功。

## Step 3: CSS 项目文件结构

```

│   ├── variables.css    ← CSS 变量定义
│   └── style.css        ← 主样式文件

    ├── images/
    └── fonts/
```

## Step 4: 最小可运行示例

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>CSS 选择器示例</title>
    <style>
        /* 基础选择器 */
        * { box-sizing: border-box; margin: 0; padding: 0; }
        body { font-family: system-ui; padding: 2rem; }
        h1 { color: #2c3e50; }
        .highlight { background: #fff3cd; padding: 0.25em 0.5em; }
        #special { border: 2px dashed #e74c3c; padding: 1rem; }

        /* 结构伪类 */
        li:first-child { font-weight: bold; }
        li:nth-child(odd) { background: #f8f9fa; }

        /* 伪元素 */
        blockquote::before { content: "「"; color: #ccc; }
        blockquote::after { content: "」"; color: #ccc; }

        /* 状态伪类 */
        a:hover { color: #e74c3c; }
    </style>
</head>
<body>
    <h1>CSS 选择器演示</h1>
    <p>这是一段包含<span class="highlight">高亮文字</span>的段落。</p>
    <div id="special">这个 div 用 ID 选择器匹配</div>
    <ul>
        <li>第1项（被 :first-child 加粗）</li>
        <li>第2项</li>
        <li>第3项（奇数行有背景色）</li>
    </ul>
    <blockquote>伪元素自动加了引号</blockquote>
    <p><a href="#">悬停变红</a></p>
</body>
</html>
```

## Step 5: 核心配置

| 配置项 | 推荐值 | 原因 |
|--------|--------|------|
| CSS Reset | `*, *::before, *::after { box-sizing: border-box; }` | 统一盒模型计算 |
| 选择器特异性管理 | 优先使用类选择器，避免 ID 选择器用于样式 | 保持低特异性，易于覆盖 |
| 格式化工具 | Prettier | 统一代码风格 |

## 常见问题

1. **样式不生效**：检查选择器是否拼写错误、CSS 文件路径是否正确、是否有更高特异性的规则覆盖。
2. **中文乱码**：CSS 文件顶部加 `@charset "UTF-8";`，或确保文件保存为 UTF-8 编码。
3. **`:nth-child` 不按预期工作**：nth-child 计数所有类型的兄弟元素，不只是同标签类型。如需同类型计数，用 `:nth-of-type`。
