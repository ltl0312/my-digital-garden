## Step 1: 现代 CSS Reset 模板

```css
/* 保存为 reset.css */
*, *::before, *::after {
    box-sizing: border-box;
    margin: 0;
    padding: 0;
}

html {
    font-size: 16px;                    /* 基准 rem = 16px */
    -webkit-text-size-adjust: 100%;     /* 防止 iOS 横屏字体放大 */
}

body {
    font-family: -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto,
                 "Helvetica Neue", Arial, sans-serif;
    line-height: 1.5;
    -webkit-font-smoothing: antialiased; /* macOS 字体平滑 */
    -moz-osx-font-smoothing: grayscale;
}

img, picture, video, canvas, svg {
    display: block;
    max-width: 100%;
}
```

## Step 2: 引入自定义字体

```css
/* 在 variables.css 或 style.css 顶部 */
@font-face {
    font-family: 'MyFont';
    src: url('../assets/fonts/myfont.woff2') format('woff2'),
         url('../assets/fonts/myfont.woff') format('woff');
    font-weight: 400;
    font-style: normal;
    font-display: swap;  /* 先用系统字体，加载完后替换（避免 FOIT） */
}
```

## Step 3: 验证盒模型

**Chrome DevTools** → Elements → 选中元素 → Computed 面板：
- 确认 `box-sizing` 值为 `border-box`
- 查看元素的盒模型图示（content/padding/border/margin 分层显示）
- 悬停在元素上查看 margin（橙色）和 padding（绿色）高亮

## Step 4: 最小可运行示例

```html
<style>
    .card {
        box-sizing: border-box;
        width: 300px;
        padding: 20px;
        border: 2px solid #ddd;
        border-radius: 8px;
        margin: 0 auto;
        font-family: system-ui;
        line-height: 1.6;
    }
    .card h2 {
        font-size: 1.25rem;
        font-weight: 600;
        margin-bottom: 0.5rem;
    }
    .card p {
        color: #666;
        /* 超长单词换行 */
        overflow-wrap: break-word;
    }
    .ellipsis-text {
        width: 200px;
        white-space: nowrap;
        overflow: hidden;
        text-overflow: ellipsis;
    }
</style>

<div class="card">
    <h2>盒模型演示卡片</h2>
    <p>width: 300px 包含 padding(20px×2) + border(2px×2) → 内容区自动缩小到 256px</p>
    <p class="ellipsis-text">这是一段非常长的文本用于演示省略号效果</p>
</div>
```

## 常见问题

1. **`margin: 0 auto` 不居中**：元素必须有明确宽度（width），且不能是行内元素（display 需为 block）。
2. **外边距合并（Margin Collapse）**：相邻块级元素的上 margin 和下 margin 会合并取最大值。解决方案：使用 `padding` 替代、或加 `border`/`padding` 隔开、或用 Flexbox/Grid 布局。
3. **`text-overflow: ellipsis` 不生效**：三个条件缺一不可——`overflow: hidden`、`white-space: nowrap`、元素有固定宽度。
