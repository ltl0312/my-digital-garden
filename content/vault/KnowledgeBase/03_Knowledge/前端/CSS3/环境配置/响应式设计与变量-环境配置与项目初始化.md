## Step 2: 验证媒体查询

```html
<style>
    body { padding: 1rem; }
    .indicator {
        padding: 1rem; text-align: center; border-radius: 4px;
    }
    /* 手机 */
    @media (max-width: 767px)  { .indicator { background: #e74c3c; } .indicator::after { content: ' ≤ 767px 手机'; } }
    /* 平板 */
    @media (min-width: 768px) and (max-width: 1023px) { .indicator { background: #f39c12; } .indicator::after { content: ' 768-1023px 平板'; } }
    /* 桌面 */
    @media (min-width: 1024px) { .indicator { background: #2ecc71; } .indicator::after { content: ' ≥ 1024px 桌面'; } }
</style>
<div class="indicator"></div>
```
拖动浏览器窗口宽度 → 颜色和文字随断点切换。

## Step 3: CSS 变量主题切换模板

```css
/* variables.css — 主题变量定义 */
:root {
    /* 间距 */
    --spacing-xs: 4px;
    --spacing-sm: 8px;
    --spacing-md: 16px;
    --spacing-lg: 24px;
    --spacing-xl: 32px;

    /* 颜色（会被深色模式覆盖） */
    --color-bg: #ffffff;
    --color-text: #333333;
    --color-primary: #3498db;
    --color-border: #e0e0e0;

    /* 圆角 */
    --radius-sm: 4px;
    --radius-md: 8px;
    --radius-lg: 16px;

    /* 阴影 */
    --shadow-sm: 0 1px 2px rgba(0,0,0,0.05);
    --shadow-md: 0 4px 6px rgba(0,0,0,0.1);
}

/* 深色模式 */
@media (prefers-color-scheme: dark) {
    :root {
        --color-bg: #1a1a2e;
        --color-text: #e0e0e0;
        --color-primary: #5dade2;
        --color-border: #333;
    }
}

/* 使用变量 */
body {
    background: var(--color-bg);
    color: var(--color-text);
}
```

## Step 4: DevTools 实时调试

1. `F12` → Elements → Styles 面板底部 → 查看 `--variable` 定义
2. Computed 面板 → 展开查看变量的实际计算值
3. Console 中执行：`getComputedStyle(document.documentElement).getPropertyValue('--color-bg')` 读取变量当前值
4. Console 中修改：`document.documentElement.style.setProperty('--color-primary', '#e74c3c')` → 页面实时变色

## 常见问题

1. **`var()` 回退值不生效**：`var(--undefined-var, fallback)` 只在变量**未定义**时使用回退值，如果变量定义了但值是无效的（如 `--color: notAColor`），回退值不会触发。变量值本身必须有效。
2. **`@media` 断点重叠冲突**：用 `min-width` 移动优先策略避免冲突；如果必须混用 min/max，注意断点边界（如 768px 同时匹配 `max-width: 768px` 和 `min-width: 768px`）。
3. **CSS 变量不继承**：所有 CSS 变量默认继承。如果子元素不显示变量值，检查是否有更高特异性的规则覆盖了该属性。
