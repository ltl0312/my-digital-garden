# CSS3 变形过渡与动画 — 环境配置与项目初始化

- Chrome DevTools Animations 面板

## Step 1: Chrome DevTools 动画调试

1. `F12` → 右上角 `⋮` → More tools → **Animations**
2. 刷新页面 → Animations 面板捕获所有 CSS 动画和过渡
3. 时间轴可以：
   - 拖动播放头逐帧查看
   - 调整播放速度（25%/10%）
   - 查看每个关键帧的样式快照
4. Rendering 面板（`⋮` → More tools → Rendering）：
   - 勾选 "Paint flashing" → 绿色闪烁表示触发重绘的区域
   - 勾选 "Layer borders" → 橙色边框表示 GPU 合成层

## Step 2: 性能验证

```css
/* ✅  GOOD：只动画 transform + opacity（GPU 加速） */
.good {
    transition: transform 0.3s, opacity 0.3s;
}
.good:hover {
    transform: translateY(-4px);
    opacity: 0.8;
}

/* ❌ BAD：动画 width（触发布局重排，可能卡顿） */
.bad {
    transition: width 0.3s;
}
.bad:hover {
    width: 120%;
}
```

DevTools Performance 面板录制 hover 动画 → 确认 `.good` 没有 Layout/Paint 紫色条，`.bad` 有。

## Step 3: `prefers-reduced-motion` 无障碍适配

```css
/* 尊重用户的系统动画偏好设置 */
@media (prefers-reduced-motion: reduce) {
    *,
    *::before,
    *::after {
        animation-duration: 0.01ms !important;
        animation-iteration-count: 1 !important;
        transition-duration: 0.01ms !important;
    }
}
```

## Step 4: 最小可运行示例

```html
<style>
    /* 关键帧：从左滑入 + 淡入 */
    @keyframes slideUp {
        from { transform: translateY(30px); opacity: 0; }
        to   { transform: translateY(0); opacity: 1; }
    }

    .animate-card {
        animation: slideUp 0.6s ease-out both;
        background: #fff;
        border-radius: 8px;
        padding: 1.5rem;
        box-shadow: 0 2px 12px rgba(0,0,0,0.1);
        transition: transform 0.2s ease, box-shadow 0.2s ease;
    }
    .animate-card:hover {
        transform: translateY(-4px) scale(1.02);
        box-shadow: 0 8px 24px rgba(0,0,0,0.15);
    }

    /* 骨架屏闪烁效果 */
    @keyframes shimmer {
        0%   { background-position: -200% 0; }
        100% { background-position: 200% 0; }
    }
    .skeleton {
        background: linear-gradient(90deg, #eee 25%, #f5f5f5 50%, #eee 75%);
        background-size: 200% 100%;
        animation: shimmer 1.5s infinite;
        border-radius: 4px;
        height: 16px;
    }
</style>

<div class="animate-card">
    <h3>动画卡片</h3>
    <p>页面加载时从下方滑入，hover 时上浮。</p>
</div>
<div class="skeleton" style="width: 60%;"></div>
```

## 常见问题

1. **动画不流畅（掉帧）**：检查是否动画化了 `width`/`height`/`top`/`left` 等布局属性。改用 `transform` 替代。
2. **`@keyframes` 不生效**：确认 `animation-name` 与 `@keyframes` 名称完全一致（区分大小写）；检查是否被其他规则覆盖。
3. **`display` 无法过渡**：`display: none` → `display: block` 不触发过渡。变通方案：用 `opacity` + `pointer-events` 或 `visibility` 配合 `transition-delay`。
