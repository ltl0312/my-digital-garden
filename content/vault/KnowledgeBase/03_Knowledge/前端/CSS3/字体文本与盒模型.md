# CSS3 字体、文本与盒模型

## 📍 知识体系定位
- **所属技术栈**：前端 Vue 3
- **所在层级**：L0 三件套 → CSS3 → 文本样式与盒模型
- **上游依赖**：<a href="obsidian://open?file=基础语法与选择器">CSS3-基础语法与选择器</a>、<a href="obsidian://open?file=基础语法与文档结构">HTML5-基础语法与文档结构</a>
- **下游延伸**：CSS 排版与布局（Flexbox/Grid）、响应式字体（clamp()）
- **同级技术**：<a href="obsidian://open?file=文本排版与链接标签">HTML-文本排版与链接标签</a>（HTML 文本语义）、Web 字体服务（Google Fonts）

## 概述（Overview）
> CSS 字体与文本属性控制文字的"长相"（字体、大小、粗细）和"排布"（对齐、行高、溢出）；盒模型定义了每个 HTML 元素的矩形占用空间——由内容（content）、内边距（padding）、边框（border）、外边距（margin）四层组成。`box-sizing: border-box` 改变了这个计算规则。

## 设计初衷（Motivation）

### 历史演进
- **前身技术**：CSS1 时期，盒子宽高只算内容区域（content-box）。开发者定义 `width: 200px; padding: 20px;`，元素实际占 240px。这导致布局计算极其痛苦。
- **为什么前身被淘汰**：content-box 默认值不符合直觉——没有人希望"我设了 200px 宽，结果占 240px"。
- **本技术的核心突破**：CSS3 引入 `box-sizing: border-box`，width 和 height 包含 padding 和 border。这已成为现代 CSS Reset 的标配（`* { box-sizing: border-box; }`）。
- **为什么是它活下来了**：border-box 让"我设宽度 = 实际占宽度"，极大地简化了布局心智模型。它借鉴了 IE6 的 quirks mode 盒模型（历史的讽刺——IE 的"bug"反而是对的）。

> ⚠️ **版本兼容性**：`box-sizing` 在 IE8+ 支持。`text-overflow: ellipsis` 在 IE6+ 支持。现代项目无需担心兼容性。

### 设计思想
盒模型的设计反映了"声明式布局"的核心矛盾：你声明的是哪个宽度？CSS WG 的妥协方案是提供 `box-sizing` 切换，而非强制改变默认值（为了不破坏已有网页）。这是 Web 平台"永不破坏向后兼容"原则的经典案例。

### 跨学科溯源
- 盒模型四层结构 → XD-1（数字系统：内存布局中 struct 的字段排列与 padding 对齐概念）
- `@font-face` 自定义字体 → XD-3（计算机网络：HTTP 请求加载 .woff2 字体文件，浏览器缓存策略）

## 实现（Implementation）

### 字体属性

```css
body {
    /* ① 字体系列：按优先级回退，最后用通用字体族 */
    font-family: "Helvetica Neue", Arial, sans-serif;

    /* ② 字体大小：px/em/rem/%/vw/vh */
    font-size: 16px;

    /* ③ 字重：normal(400) / bold(700) / 100-900 */
    font-weight: 600;

    /* ④ 风格：normal / italic(斜体) / oblique(倾斜) */
    font-style: normal;
}

/* ⑤ CSS3 自定义网络字体 */
@font-face {
    font-family: 'MyCustomFont';
    src: url('myfont.woff2') format('woff2'),
         url('myfont.woff') format('woff');
    font-weight: 400;
}
```

### 文本属性

```css
.text-demo {
    color: #333;                    /* 文本颜色 */
    text-align: justify;            /* 对齐：left/right/center/justify两端对齐 */
    text-decoration: underline;     /* 修饰：none/underline/line-through */
    line-height: 1.5;               /* 行高：推荐无单位数字（相对字体大小） */
    letter-spacing: 0.05em;         /* 字符间距 */
    word-spacing: 0.1em;            /* 单词间距 */

    /* CSS3 新增文本特性 */
    text-shadow: 2px 2px 4px rgba(0,0,0,0.5); /* 水平偏移 垂直偏移 模糊 颜色 */
    overflow: hidden;               /* 配合 text-overflow 必须设置 */
    white-space: nowrap;            /* 强制单行 */
    text-overflow: ellipsis;        /* 溢出显示省略号 ... */
    overflow-wrap: break-word;      /* 长单词允许在单词内换行 */
    word-break: break-all;          /* 允许在任何字符间换行（适合 URL/代码） */
}
```

### 盒模型：box-sizing 的关键差异

```css
/* ① content-box（默认）：width = 内容宽度 */
.content-box-demo {
    box-sizing: content-box;
    width: 200px;
    padding: 20px;
    border: 5px solid #333;
    /* 实际占用 = 200 + 20*2 + 5*2 = 250px */
}

/* ② border-box（推荐）：width = 内容+padding+border */
.border-box-demo {
    box-sizing: border-box;
    width: 200px;
    padding: 20px;
    border: 5px solid #333;
    /* 实际占用 = 200px（内容自动缩小到 150px） */
}

/* ③ 现代 CSS Reset 标配 */
*, *::before, *::after {
    box-sizing: border-box;
}
```

### margin 与 padding 简写

```css
/* 四值：上 右 下 左（顺时针） */
margin: 10px 20px 10px 20px;
/* 三值：上 左右 下 */
padding: 10px 20px 10px;
/* 二值：上下 左右 */
margin: 10px 20px;
/* 单值：四边相同 */
padding: 10px;
/* 水平居中（块级元素） */
margin: 0 auto;
```

> **💡 补充**：`margin` 垂直方向会发生**外边距合并（Margin Collapse）**——相邻块级元素的上下 margin 会合并取最大值，而非叠加。这是 CSS 中最常见的坑之一。
