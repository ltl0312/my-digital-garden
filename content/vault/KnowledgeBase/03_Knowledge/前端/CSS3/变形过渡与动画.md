# CSS3 变形、过渡与动画

## 📍 知识体系定位
- **所属技术栈**：前端 Vue 3
- **所在层级**：L0 三件套 → CSS3 → 动画体系
- **上游依赖**：<a href="obsidian://open?file=基础语法与选择器">CSS3-基础语法与选择器</a>（用伪类 :hover 触发过渡）、<a href="obsidian://open?file=字体文本与盒模型">CSS3-字体文本与盒模型</a>
- **下游延伸**：Web Animation API（JS 控制动画）、GSAP 动画库、Lottie 动画
- **同级技术**：Canvas 动画（像素级动画）、SVG 动画（`<animate>` 标签）

## 概述（Overview）
> CSS3 提供了三层动画抽象——**变形（Transform）**：改变元素的形状和位置（旋转、缩放、平移、倾斜）；**过渡（Transition）**：在状态切换时（如 :hover）自动平滑插值；**动画（Animation）**：通过 `@keyframes` 定义任意复杂的关键帧序列，可自动播放、循环、暂停。

## 设计初衷（Motivation）

### 历史演进
- **前身技术**：CSS2 时代，网页动效完全依赖 JavaScript（jQuery .animate()）或 Flash。JS 动画运行在主线程，会阻塞 UI；Flash 是封闭插件。
- **为什么前身被淘汰**：JS 动画性能差（主线程阻塞导致卡顿），且需要大量代码实现缓动函数和帧管理。Flash 已死。
- **本技术的核心突破**：CSS3 将动画原语内置到浏览器渲染引擎中。`transform` 和 `opacity` 的动画在**合成器线程**执行，不阻塞主线程，可以达到 60fps。`@keyframes` 让声明式定义复杂动画序列成为可能。
- **为什么是它活下来了**：硬件加速（GPU 合成）、声明式（无需 JS）、`will-change` 提示浏览器提前优化图层。几乎所有现代 Web 动效的基础。

> ⚠️ **版本兼容性**：`transform`、`transition` 在 IE10+ 支持（需 -ms- 前缀），`animation` 在 IE10+ 支持。现代浏览器（Chrome/Firefox/Safari/Edge）均无需前缀。

### 设计思想
CSS 动画的设计哲学是"声明式动效"——你只需声明开始状态、结束状态、持续时间和缓动曲线，浏览器负责帧间的计算和渲染。这与 JS 动画的"命令式"（每帧手动计算位置）形成对比。关键在于 `transform` 和 `opacity` 只触发**合成**（composite）而非**重排**（reflow），这是 60fps 的性能秘诀。

### 跨学科溯源
- `transform` 矩阵运算 → XD-5（线性代数：translate/rotate/scale/skew 对应 4×4 齐次坐标变换矩阵）→ XD-1（GPU 中的矩阵乘法单元）
- `transition-timing-function` 贝塞尔曲线 → XD-5（计算机图形学：三次贝塞尔曲线的参数方程 `B(t) = (1-t)³P₀ + 3(1-t)²tP₁ + 3(1-t)t²P₂ + t³P₃`）
- `animation` 关键帧插值 → XD-5（数值计算：线性插值 lerp，颜色空间插值）

## 实现（Implementation）

### Transform（2D/3D 变形）

```css
.box {
    /* ① 平移：相对于自身尺寸的百分比 */
    transform: translate(50px, 50%);
    transform: translateX(50px);
    transform: translateY(-10px);

    /* ② 缩放：1=原始，0.5=缩小一半，2=放大一倍 */
    transform: scale(1.2);
    transform: scale(1.5, 0.8);     /* 水平1.5倍，垂直0.8倍 */

    /* ③ 旋转：正数顺时针 */
    transform: rotate(45deg);
    transform: rotate(-90deg);

    /* ④ 倾斜 */
    transform: skew(10deg, 5deg);

    /* ⑤ 组合变形（空格分隔，从右向左应用） */
    transform: translate(50px, 100px) rotate(45deg) scale(1.2);

    /* ⑥ 变形原点（默认 50% 50% 即中心） */
    transform-origin: top left;      /* 关键词 */
    transform-origin: 0 0;           /* 像素/百分比 */

    /* ⑦ 3D 属性 */
    transform: rotateX(45deg) rotateY(30deg);
    /* 父元素上设置 3D 环境 */
    perspective: 500px;              /* 视距：值越小 3D 效果越强 */
    transform-style: preserve-3d;    /* 保留子元素的 3D 空间 */
    backface-visibility: hidden;     /* 隐藏元素背面（卡片翻转常用） */
}
```

### Transition（过渡）

```css
/* ① 完整语法 */
.button {
    background: #3498db;
    transition-property: background, transform;
    transition-duration: 0.3s, 0.2s;
    transition-timing-function: ease-in-out;
    transition-delay: 0s;
    /* 简写：property duration timing-function delay */
    transition: all 0.3s ease-in-out;
}

.button:hover {
    background: #2980b9;
    transform: scale(1.05);
}

/* ② 缓动函数速查 */
/* ease:         慢→快→慢（默认，自然感） */
/* linear:       匀速（机械感） */
/* ease-in:      慢→快（入场感） */
/* ease-out:     快→慢（刹车感） */
/* ease-in-out:  慢→快→慢（对称） */
/* cubic-bezier(x1,y1,x2,y2): 自定义贝塞尔曲线 */
```

### Animation（关键帧动画）

```css
/* ① 定义关键帧 */
@keyframes slideIn {
    from {  /* 或 0% */
        transform: translateX(-100%);
        opacity: 0;
    }
    60% {
        transform: translateX(10px);
    }
    to {    /* 或 100% */
        transform: translateX(0);
        opacity: 1;
    }
}

/* ② 调用动画 */
.animated {
    animation-name: slideIn;
    animation-duration: 1s;
    animation-timing-function: ease-out;
    animation-delay: 0s;
    animation-iteration-count: 1;        /* 数字 或 infinite(无限) */
    animation-direction: alternate;       /* normal|reverse|alternate|alternate-reverse */
    animation-fill-mode: forwards;        /* none|forwards(停在最后一帧)|backwards|both */
    animation-play-state: running;        /* running|paused */
    /* 简写：name duration timing-function delay count direction fill-mode */
    animation: slideIn 1s ease-out 0s 1 forwards;
}

/* ③ 暂停动画（hover 时） */
.animated:hover {
    animation-play-state: paused;
}
```

> **💡 补充**：性能黄金法则——只动画化 `transform` 和 `opacity`。这两个属性触发**合成（Composite）**阶段，不触发重排（Layout）或重绘（Paint），由 GPU 在合成器线程处理，可稳定 60fps。动画 `width`、`height`、`top`、`left` 会触发重排，可能导致卡顿。

### 动画性能层对比

| CSS 属性 | 触发阶段 | 性能 |
|----------|---------|------|
| `transform` | Composite only | ⚡ 最佳（GPU 加速） |
| `opacity` | Composite only | ⚡ 最佳（GPU 加速） |
| `background-color` | Paint + Composite | 🟡 可接受 |
| `box-shadow` | Paint + Composite | 🟡 需注意（模糊计算开销大） |
| `width` / `height` | Layout + Paint + Composite | 🔴 避免动画化 |
| `top` / `left` | Layout + Paint + Composite | 🔴 避免动画化 |
