# CSS3 响应式设计、变量与颜色

## 📍 知识体系定位
- **所属技术栈**：前端 Vue 3
- **所在层级**：L0 三件套 → CSS3 → 工程化特性
- **上游依赖**：<a href="obsidian://open?file=基础语法与选择器">CSS3-基础语法与选择器</a>、<a href="obsidian://open?file=Flexbox与Grid现代布局">CSS3-Flexbox与Grid现代布局</a>
- **下游延伸**：CSS 容器查询（@container）、CSS 嵌套（Nesting）、Tailwind CSS 响应式工具类
- **同级技术**：JavaScript resize 监听（ResizeObserver）、移动端 viewport 适配

## 概述（Overview）
> **媒体查询（@media）**根据设备特性（宽度、方向、分辨率）条件性地应用样式，是实现响应式设计的核心机制。**CSS 变量（Custom Properties）**是原生支持的动态变量系统，支持运行时修改和级联继承。**RGBA/HSLA** 颜色函数引入 Alpha 通道，实现透明度控制。

## 设计初衷（Motivation）

### 历史演进
- **前身技术**：媒体查询前，响应式设计依赖 JavaScript 检测屏幕宽度并动态添加 class，或使用 `user-agent` 嗅探做设备判断。CSS 变量出现前，开发者使用 Sass/Less 变量（编译时）、或 CSS 预处理器的 `$` 变量——但是编译后变成静态值，无法在运行时修改。
- **为什么前身被淘汰**：JS 方案耦合度高且容易出错（UA 嗅探不准确）。预处理器变量是编译时的——无法在浏览器中动态改变值（如深色模式切换）。
- **本技术的核心突破**：CSS 变量可以在运行时通过 JS 修改（`element.style.setProperty('--var', 'value')`），支持级联继承，浏览器原生解析。媒体查询新增 `prefers-color-scheme` 特性，原生支持深色模式检测。
- **为什么是它活下来了**：CSS 变量 + 媒体查询 = 纯 CSS 实现主题切换。所有现代浏览器原生支持，零编译步骤。

### 设计思想
CSS 变量的设计体现了"动态级联变量"的范式——变量在 DOM 树上继承（子元素可以看到父元素定义的变量），修改根元素的变量可以瞬间改变整个页面的主题。这与预处理器变量（一次性编译）有本质不同。`prefers-color-scheme: dark` 体现的是"尊重用户偏好"的设计原则。

### 跨学科溯源
- `@media` 条件匹配 → XD-4（编程语言：类似于 if-else 条件分支，浏览器根据设备特性动态选择应用的规则块）
- CSS 变量级联 → XD-5（树结构：DOM 树上的变量查找类似于作用域链的向上查找算法）

## 实现（Implementation）

### 媒体查询（@media）

```css
/* ① 基础语法：屏幕宽度 ≤ 768px 时应用（手机端） */
@media screen and (max-width: 768px) {
    .container {
        width: 100%;
        flex-direction: column;
    }
}

/* ② 大屏样式：≥ 1200px */
@media (min-width: 1200px) {
    .container { max-width: 1140px; }
}

/* ③ 范围匹配：768px ~ 1024px（平板） */
@media (min-width: 768px) and (max-width: 1024px) {
    .sidebar { display: none; }
}

/* ④ 设备方向 */
@media (orientation: landscape) { }  /* 横屏 */
@media (orientation: portrait) { }   /* 竖屏 */

/* ⑤ 分辨率（Retina 屏幕） */
@media (min-resolution: 2dppx) { }   /* 或 -webkit-min-device-pixel-ratio: 2 */

/* ⑥ ★ 系统主题偏好（现代 CSS） */
@media (prefers-color-scheme: dark) {
    :root {
        --bg: #1a1a2e;
        --text: #eee;
    }
}
@media (prefers-color-scheme: light) {
    :root {
        --bg: #ffffff;
        --text: #333;
    }
}
```

### CSS 变量（Custom Properties）

```css
/* ① 声明：通常在 :root（<html>）中声明全局变量 */
:root {
    --primary-color: #3498db;
    --main-font-size: 16px;
    --spacing-unit: 8px;
    --box-padding: 10px 20px;
}

/* ② 使用：var(变量名, 回退值) */
.button {
    background-color: var(--primary-color);
    font-size: var(--main-font-size);
    padding: var(--spacing-unit) calc(var(--spacing-unit) * 2);
    /* 回退值：变量不存在时使用 red */
    color: var(--text-color, red);
}

/* ③ 组件级作用域（仅 .card 内生效） */
.card {
    --card-radius: 12px;
    border-radius: var(--card-radius);
}
.card .title {
    border-radius: var(--card-radius);  /* 可访问父级变量 */
}

/* ④ JavaScript 动态修改 */
/* element.style.setProperty('--primary-color', '#e74c3c'); */
```

### 颜色与透明度

```css
.colors {
    /* ① RGBA：红绿蓝(0-255) + Alpha(0-1，0=透明 1=不透明) */
    background: rgba(0, 0, 0, 0.5);      /* 半透明黑色（仅背景透明） */
    color: rgba(255, 255, 255, 0.9);      /* 不透明度 90% 的白色文字 */

    /* ② HSLA：色相(0-360) 饱和度(%) 亮度(%) + Alpha */
    color: hsla(120, 100%, 50%, 0.8);     /* 半透明纯绿色 */

    /* ③ opacity：整个元素透明（含子元素、文本、背景全透明） */
    opacity: 0.5;                          /* 0.0 到 1.0 */

    /* ④ 现代颜色函数 */
    /* rgb(0 0 0 / 0.5)  ← 新语法（空格分隔，/后为alpha） */
}
```

### 响应式设计断点参考

| 断点 | 设备类型 | 典型宽度 |
|------|---------|---------|
| 手机（竖屏） | 小型手机 | `< 576px` |
| 手机（横屏） | 大屏手机 | `≥ 576px` |
| 平板（竖屏） | iPad | `≥ 768px` |
| 平板（横屏）/ 小笔记本 | iPad Pro | `≥ 992px` |
| 桌面 | 笔记本/台式机 | `≥ 1200px` |
| 大屏 | 大显示器 | `≥ 1400px` |

> **💡 补充**：推荐使用**移动优先（Mobile First）**策略——基础样式为移动端编写，然后用 `@media (min-width: ...)` 逐级增强大屏样式。这与"渐进增强"的设计原则一致，且移动端加载的基础 CSS 更少。
