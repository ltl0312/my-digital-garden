# CSS3 基础语法与选择器

## 📍 知识体系定位
- **所属技术栈**：前端 Vue 3
- **所在层级**：L0 三件套 → CSS3
- **上游依赖**：<a href="obsidian://open?file=基础语法与文档结构">HTML5-基础语法与文档结构</a>（CSS 通过选择器匹配 HTML 元素）
- **下游延伸**：CSS 预处理器（Sass/Less）、CSS-in-JS、Tailwind CSS
- **同级技术**：HTML5（结构）、JavaScript（行为）

## 概述（Overview）
> CSS 规则由**选择器**和**声明块**组成。选择器决定了"对谁应用样式"，声明块决定了"应用什么样式"。CSS3 将选择器体系扩展到了属性匹配、结构位置、状态响应和伪元素生成四个维度。

## 设计初衷（Motivation）

### 历史演进
- **前身技术**：CSS1（1996）仅有标签、类、ID 三种选择器；CSS2（1998）增加了属性选择器和伪类（:hover, :focus）。
- **为什么前身被淘汰**：CSS2 选择器无法表达"第3个元素""属性值以某字符串开头"等精细匹配需求，开发者被迫在 HTML 中添加大量无语义的 class 来辅助选择。
- **本技术的核心突破**：CSS3 新增了结构伪类（:nth-child, :first-of-type）、属性子串匹配（[attr^=], [attr$=], [attr*=]）、否定伪类（:not()）和 UI 状态伪类，极大地减少了 HTML 中"为样式而添加的 class"。
- **为什么是它活下来了**：向后兼容——所有 CSS2 选择器在 CSS3 中完全有效。现代浏览器对 CSS3 选择器的支持率达到 99%+。

### 设计思想
CSS 选择器体现了"声明式匹配"的哲学——你不需要在 HTML 中标记"这个元素需要特殊样式"，而是用选择器描述"满足这些条件的元素，应用这些样式"。关注点从 HTML 转移到 CSS，使 HTML 保持纯净语义。

### 跨学科溯源
- CSS 选择器优先级计算 → XD-4（编程语言：特异性 Specificity 的权重算法类似于编译器中符号表的优先级解析）
- :nth-child(an+b) 公式 → XD-5（数据结构与算法：等差数列通项公式 an+b 的建模）

## 实现（Implementation）

### CSS 三种引入方式

```html
<!-- ① 行内样式（不推荐，难以维护） -->
<p style="color: blue;">文本</p>

<!-- ② 内部样式表：在 <head> 中使用 <style> 标签 -->
<style>
    p { color: red; }
</style>

<!-- ③ 外部样式表（最推荐）：通过 <link> 引入独立 .css 文件 -->
<link rel="stylesheet" href="style.css">
```

### 完整选择器速查表

**基础选择器**：
```css
* { margin: 0; }           /* 通用选择器：匹配所有元素 */
p { color: red; }           /* 标签选择器：匹配所有 <p> */
.active { font-weight: bold; }  /* 类选择器：匹配 class="active" */
#header { background: #333; }   /* ID选择器：匹配 id="header"（唯一） */
```

**组合选择器**：
```css
div p { }        /* 后代：div 内所有 p（任意层级） */
ul > li { }      /* 子代：ul 的直接子元素 li */
h1 + p { }       /* 相邻兄弟：紧跟在 h1 后的第一个 p */
h2 ~ p { }       /* 通用兄弟：h2 之后的所有同级 p */
```

**CSS3 属性选择器**：
```css
[target] { }              /* 存在属性：有 target 属性的元素 */
[type="submit"] { }       /* 精确匹配 */
[class~="btn"] { }        /* 包含空格分隔的单词 */
[href^="https"] { }       /* 前缀匹配：href 以 https 开头 ★CSS3 */
[src$=".png"] { }         /* 后缀匹配：src 以 .png 结尾 ★CSS3 */
[title*="hello"] { }      /* 子串匹配：title 包含 hello ★CSS3 */
```

**CSS3 结构伪类**：
```css
li:first-child { }        /* 父元素的第一个子元素 */
li:last-child { }         /* 父元素的最后一个子元素 */
li:nth-child(2) { }       /* 第2个子元素 */
li:nth-child(odd) { }     /* 奇数位 */
li:nth-child(even) { }    /* 偶数位 */
li:nth-child(2n+1) { }    /* 公式：an+b */
p:first-of-type { }       /* 同类型中的第一个 */
p:only-child { }          /* 唯一子元素 */
div:empty { }             /* 没有子节点（含文本） */
p:not(.intro) { }         /* 否定伪类：不匹配 .intro 的 p ★CSS3 */
```

**状态伪类**：
```css
a:link { }         /* 未访问链接 */
a:visited { }      /* 已访问链接 */
a:hover { }        /* 鼠标悬停 */
a:active { }       /* 鼠标按下时 */
input:focus { }    /* 获得焦点 */
input:checked { }  /* 选中的单选框/复选框 */
input:disabled { } /* 禁用的表单元素 */
```

**CSS3 伪元素（双冒号 ::）**：
```css
/* 必须配合 content 属性使用 */
.quote::before { content: "「"; }   /* 内容最前面插入 */
.quote::after { content: "」"; }    /* 内容最后面插入 */
p::first-letter { font-size: 2em; } /* 第一个字母 */
p::first-line { font-weight: bold; }/* 第一行 */
::selection { background: yellow; } /* 用户选中的文本 */
```

> **💡 补充**：伪元素 ::before/::after 是 CSS 中最强大的特性之一。它们无需修改 HTML 就能添加装饰性内容（图标、引号、清除浮动等）。本质上是创建了一个匿名的行内子元素。
