# TypeScript 类、枚举与高级类型

## 📍 知识体系定位
- **所属技术栈**：前端 Vue 3
- **所在层级**：L3 工程化 → TypeScript → 高级类型
- **上游依赖**：<a href="obsidian://open?file=接口与函数类型">TypeScript-接口与函数类型</a>
- **下游延伸**：Vue 3 Class API、NestJS 依赖注入、设计模式实现
- **同级技术**：Java 类与接口（名义类型）、Python 类型提示

## 概述（Overview）
> TS 增强了 ES6 的 class——引入 `public`/`protected`/`private` 访问修饰符、抽象类（`abstract`）、参数属性简写。**联合类型（`|`）**和**交叉类型（`&`）** 是 TS 最强大的类型组合工具。`enum` 定义命名常量组，`Tuple` 定义定长定类型数组。

## 实现（Implementation）

### Class 类与访问修饰符

```typescript
class Person {
    public name: string;           // public：任何地方可见（默认）
    protected age: number;         // protected：类及其子类可见
    private idCard: string;        // private：仅当前类内部可见

    // ★ 参数属性简写：构造参数前加修饰符，自动声明并赋值
    constructor(
        name: string,
        age: number,
        idCard: string,
        public readonly type: string = "Human"
    ) {
        this.name = name;
        this.age = age;
        this.idCard = idCard;
        // this.type 自动创建（public readonly）
    }
}

// 抽象类：不能 new，只能被继承
abstract class Department {
    constructor(public name: string) {}
    printName(): void { console.log("Department: " + this.name); }
    abstract printMeeting(): void;   // 抽象方法：子类必须实现
}
```

### 元组与枚举

```typescript
// 元组（Tuple）：定长 + 各位置类型固定
let tuple: [string, number];
tuple = ["hello", 10];       // ✅ OK
// tuple = [10, "hello"];    // ❌ Error: 对应位置类型不匹配

// 数字枚举（默认从 0 自增）
enum Direction { Up = 1, Down, Left, Right }  // 1, 2, 3, 4

// 字符串枚举
enum Status {
    Success = "SUCCESS",
    Failed = "FAILED",
}
```

> **💡 补充**（枚举细节）：枚举成员约定以大写字母开头、以逗号分隔。数字枚举的成员默认值是从 **0 开始的自增数值**（`enum Direction { Up, Down, Left, Right }` 中 Up=0、Down=1、Left=2、Right=3，第一个成员可显式指定起始值）；字符串枚举的值**不会自增长**，所以每个成员必须显式设置初始值。

### readonly 只读修饰符

```typescript
class Config {
    readonly id: number;                       // 仅可初始化和构造函数中赋值
    readonly tag = "default";                  // 未标注类型 → 推断为字面量 "default"（类似 const）
    readonly mode: string = "prod";            // 已标注类型 → 推断为普通 string

    constructor(id: number) {
        this.id = id;                          // ✅ 构造函数中赋值
    }
    reset() {
        // this.id = 2;                        // ❌ Error: 无法为只读属性赋值
    }
}
```

### 联合类型（|）与交叉类型（&）

```typescript
// ① 联合类型：允许多种类型之一
let val: string | number;
val = "abc";
val = 123;

// 联合类型配合字面量类型（Union of Literals）
type HttpMethod = "GET" | "POST" | "PUT" | "DELETE";
type Alignment = "left" | "center" | "right";

// ② 交叉类型：合并多个类型（常用于 Mixin）
interface A { a: number }
interface B { b: string }
type C = A & B;           // C 必须同时有 a 和 b
let obj: C = { a: 1, b: "hello" };
```

### type vs interface 选择指南

| 场景 | 推荐 | 原因 |
|------|------|------|
| 定义对象形状 | `interface` | 可声明合并、extends 更清晰 |
| 联合类型 | `type` | interface 不支持 `\|` |
| 元组 | `type` | 更简洁 |
| 函数签名 | `type` | `type Fn = (x: T) => U` |
| 需要声明合并 | `interface` | 同名 interface 自动合并属性 |

> **💡 补充**：TS 的 `private` 只在编译时检查。运行时仍可通过 `obj["idCard"]` 访问。如果需要真正的运行时私有，使用 ES2022 的 `#` 私有字段（`#idCard: string`）。
