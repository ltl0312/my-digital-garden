# TypeScript 索引签名与索引访问类型 — 环境配置

## 信息来源
- **官方文档**：https://www.typescriptlang.org/tsconfig#noUncheckedIndexedAccess（❌ 无法访问，以下基于知识库既有配置指南与已知 TS 5.x 行为总结）
- **参考文章**：
  - TypeScript Handbook — Indexed Access Types：https://www.typescriptlang.org/docs/handbook/2/indexed-access-types.html [来源: TS 官方手册]

> ⚠️ 官方文档在当前网络环境无法访问，本指南基于知识库既有 `基础语法-环境配置与项目初始化` 配置与 TS 5.x 已知行为整理。

## 前置条件
- TS 5.x 项目（索引签名与索引访问类型从 TS 2.x 起即可用，`noUncheckedIndexedAccess` 需 TS 4.1+）

## Step 1: 开启 noUncheckedIndexedAccess

```json
// tsconfig.json
{
  "compilerOptions": {
    "noUncheckedIndexedAccess": true
  }
}
```

开启后，索引签名与索引访问的返回类型自动追加 `| undefined`——数组越界、字典缺键在类型层面暴露。

## Step 2: 验证行为差异

```typescript
// 开启前：arr[i] 类型为 string（可能越界但不报错）
const arr: string[] = ["a", "b"];
const first = arr[0];          // string

// 开启后：arr[i] 类型为 string | undefined
const firstSafe = arr[0];      // string | undefined
if (firstSafe !== undefined) { // ✅ 必须判空后才能使用
    console.log(firstSafe.length);
}
```

**预期**：开启后直接使用 `arr[0].length` 会报"possibly undefined"错误。

## Step 3: 对象索引签名配合

```typescript
interface AnyObject { [key: string]: number }
const obj: AnyObject = { a: 1 };
const v = obj["b"];            // number | undefined（开启后）
if (v !== undefined) { /* 判空后使用 */ }
```

## Step 4: 最小可运行示例

```typescript
// src/indexed.ts
interface MyArray<T> { [n: number]: T }
let arr: MyArray<number> = [10, 20];
const item = arr[5];                       // number | undefined
const sum = item === undefined ? 0 : item; // 显式兜底
console.log(sum);                          // 输出: 0
```

## Step 5: 核心配置项说明

| 配置项 | 默认值 | 推荐值 | 原因 |
|--------|--------|--------|------|
| `noUncheckedIndexedAccess` | `false` | `true` | 索引访问自动含 `undefined`，越界/缺键在编译期暴露 |
| `strict` | `false` | `true` | 开启整体严格检查（此配置独立于 strict，需显式开启） |
| `noImplicitAny` | `false`（随 strict 变 true） | `true` | 索引签名的键占位符不产生隐式 any |

## 常见安装/配置问题

1. **开启后代码大面积报错**：第三方库类型中大量索引访问会突然带 `undefined`——常用 `!` 非空断言或 `??` 兜底逐步收敛，不强行关配置。
2. **仅想对数组生效、不想影响对象字典**：该开关对两者同时生效，无法分治；如无法接受，可对字典接口改用 `Record<K, T>` 并配合值域判空。
3. **TS 4.0 及以下无此配置**：升级 `typescript` 到 5.x（`npm i -D typescript@latest`）。
