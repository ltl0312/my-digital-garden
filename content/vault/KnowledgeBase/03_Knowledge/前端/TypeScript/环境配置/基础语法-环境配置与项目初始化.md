# TypeScript — 环境配置与项目初始化

## 信息来源
- **官方文档**：https://www.typescriptlang.org/docs/（✅ 可访问）
- **TS Playground**：https://www.typescriptlang.org/play（✅ 可访问，在线测试 TS）

## 前置条件
- Node.js 已安装（参考 <a href="obsidian://open?file=基础语法-环境配置与项目初始化">JavaScript-基础语法-环境配置与项目初始化</a>）

## Step 1: 安装 TypeScript

```bash
npm install -g typescript  # 全局安装 tsc 编译器
tsc --version              # 验证：Version 5.x.x
```

## Step 2: 初始化 TS 项目

```bash
mkdir ts-project && cd ts-project
tsc --init                  # 生成 tsconfig.json
```

关键 `tsconfig.json` 配置：
```json
{
  "compilerOptions": {
    "target": "ES2022",           // 编译目标 JS 版本
    "module": "ESNext",           // 模块系统
    "strict": true,               // ★ 启用所有严格检查
    "esModuleInterop": true,
    "outDir": "./dist",           // 输出目录
    "rootDir": "./src"            // 源码目录
  }
}
```

## Step 3: 验证

```bash
mkdir src
echo 'const msg: string = "Hello TS"; console.log(msg);' > src/index.ts
npx tsc                    # 编译 → dist/index.js
node dist/index.js         # 输出 "Hello TS"
```

## Step 4: VS Code 扩展

- **TypeScript**（内置，无需安装）
- **Pretty TypeScript Errors**：让 TS 错误更易读
- **Error Lens**：行内显示 TS 错误

## 常见问题

1. **`tsc` 找不到命令**：全局安装后需重启终端，或用 `npx tsc`。
2. **编译报错但 JS 仍生成**：设置 `"noEmitOnError": true` 阻止有错时生成 JS。
3. **`strict: true` 后大量报错**：strict 开启全部严格检查（`strictNullChecks`、`noImplicitAny` 等），渐进式 JS→TS 迁移时可先关掉逐个开启。
