## Step 1: 安装第三方库的 @types 声明包

```bash
# 库自带声明（axios、vue 等）→ 无需安装，自动加载
npm install axios

# 库无自带声明（lodash 等）→ 从 DefinitelyTyped 安装对应 @types 包
npm install lodash
npm install -D @types/lodash
# TS 自动加载 node_modules/@types/* 下的声明，无需额外配置
```

**预期**：`npm ls @types/lodash` 有输出；IDE 中 `_.chunk(...)` 有完整类型提示。

## Step 2: 配置声明加载范围

```json
// tsconfig.json —— 控制哪些声明文件被加载
{
  "compilerOptions": {
    "types": ["node"],                // 只加载 @types/node，其余 @types/* 不自动加载
    "moduleResolution": "bundler",    // 声明文件解析策略（Vite 项目推荐 bundler）
    "declaration": true,              // 编译时为自己的 .ts 生成 .d.ts（库作者必开）
    "declarationDir": "dist/types"    // 声明文件输出目录
  }
}
```

## Step 3: 为已有 JS 文件写声明（同目录配对）

```bash
# 项目结构：legacy.js 与 legacy.d.ts 同名同目录 → 导入时自动配对
# legacy.js      —— 已有实现，不改动
# legacy.d.ts    —— 手写声明
```

```typescript
// legacy.d.ts —— declare 声明"已存在的实现"，不产生新代码
export declare function calc(a: number, b: number): number;
```

**预期**：`import { calc } from "./legacy"` 后 `calc(1, "x")` 报类型错误。

## Step 4: 最小可运行示例（项目内共享类型）

```typescript
// types/index.d.ts
export interface ApiResult<T> { code: number; data: T; }

// src/api.ts
import { ApiResult } from "../types";   // .d.ts 后缀导入时省略
const res: ApiResult<{ id: number }> = { code: 0, data: { id: 1 } };
console.log(res.data.id);               // 输出: 1
```

## Step 5: 核心配置项说明

| 配置项 | 默认值 | 推荐值 | 原因 |
|--------|--------|--------|------|
| `types` | 全部 @types | 按需声明 | 只加载需要的全局声明，避免类型冲突 |
| `moduleResolution` | `classic`（老项目） | `bundler`/`node16` | 决定 .d.ts 查找策略，Vite 项目用 bundler |
| `declaration` | `false` | 库作者 `true` | 自动为 .ts 生成 .d.ts，发布类型包的标准方式 |
| `allowJs` | `false` | 迁移期 `true` | 允许 .js 进项目，配合 .d.ts 提供类型 |
| `checkJs` | `false` | 迁移期可选 | 对 .js 也做类型检查 |

## 常见安装/配置问题

1. **`@types/x` 装了但类型不生效**：检查 `types` 字段是否显式限定了白名单（写明后才只加载列表内）；或包名大小写/作用域不匹配（`@types/node-fetch` 对应 `node-fetch`）。
2. **`.js` 导入报 "Could not find a declaration file"**：同名 `.d.ts` 未放在同目录，或 `moduleResolution` 与模块格式不匹配（ESM 项目用 `bundler`/`node16` 而非 `node`）。
3. **发布 npm 包后用户拿到 `any`**：确认 `declaration: true` 且 `package.json` 的 `types` 字段指向生成的 `index.d.ts`（如 `"types": "dist/index.d.ts"`）。
