# TypeScript 工具类型与装饰器 — 环境配置

## 前置条件
- TS 开发环境（参考 <a href="obsidian://open?file=基础语法-环境配置与项目初始化">TypeScript-基础语法-环境配置与项目初始化</a>）

## Step 1: 装饰器配置

`tsconfig.json`：
```json
{ "compilerOptions": { "experimentalDecorators": true } }
```

## Step 2: 工具类型验证

```typescript
// Playground 中悬停查看变换后的类型
interface User { id: number; name: string; email: string; }
type A = Partial<User>;    // 悬停：{ id?: number; name?: string; ... }
type B = Pick<User, "id" | "name">;  // { id: number; name: string }
type C = Omit<User, "email">;        // { id: number; name: string }
type D = Readonly<Pick<User, "id">>; // { readonly id: number }
```

## Step 3: 实战组合示例

```typescript
// API 场景：从数据库模型取部分字段作为创建 DTO
interface UserModel { id: number; name: string; email: string; password: string; createdAt: Date; }
type CreateUserDTO = Omit<UserModel, "id" | "createdAt">;  // 不要 id 和时间
type UpdateUserDTO = Partial<Pick<UserModel, "name" | "email">>;  // 部分更新
type PublicUser = Omit<UserModel, "password">;  // 脱敏：去掉密码字段
```

## 常见问题

1. **装饰器不生效**：检查 `experimentalDecorators: true` 和 TS 版本（5.x 装饰器仍是实验性的）。
2. **`Omit` 仍保留原属性类型**：`Omit<T, K>` 不改变保留属性的类型，只做排除。如需同时修改类型，用交叉类型：`Omit<T, "a"> & { a: NewType }`。
