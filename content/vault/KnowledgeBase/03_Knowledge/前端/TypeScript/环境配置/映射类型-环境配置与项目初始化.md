## 前置条件
- TS 4.1+（键重映射 `as` 语法需 4.1；基础映射类型 2.1+ 即可）

## Step 1: 确认 TS 版本与 lib 配置

映射类型是纯编译期语法，无运行时依赖，但内置工具类型的返回类型涉及 `keyof`/模板字面量，需确保 lib 覆盖目标 ES 标准：

```json
// tsconfig.json
{
  "compilerOptions": {
    "target": "ES2022",
    "lib": ["ES2022", "DOM"],
    "strict": true
  }
}
```

## Step 2: 验证映射类型与工具类型

```typescript
// src/mapped.ts
type ProKeys = 'x' | 'y' | 'z';
type Type2 = { [Key in ProKeys]: number };
const point: Type2 = { x: 1, y: 2, z: 3 };   // ✅

// 工具类型源码验证（Partial 即映射类型）
type MyPartial<T> = { [K in keyof T]?: T[K] };
interface Todo { title: string; done: boolean }
const partialTodo: MyPartial<Todo> = { title: "buy milk" };  // ✅ done 可缺省
```

**预期**：`npx tsc --noEmit` 无错误；IDE 悬停 `MyPartial<Todo>` 显示 `{ title?: string; done?: boolean }`。

## Step 3: 键重映射验证（TS 4.1+）

```typescript
// as 重命名键：get 前缀转换
type Getters<T> = { [K in keyof T as `get${Capitalize<string & K>}`]: () => T[K] };
type Person = Getters<{ name: string }>;
// Person = { getName: () => string }
```

## Step 4: 最小可运行示例

```typescript
// src/state.ts —— 映射类型做状态机建模
type Status = "idle" | "loading" | "done";
type StatusMap = { [K in Status]: boolean };
const flags: StatusMap = { idle: true, loading: false, done: false };
console.log(flags.idle);   // 输出: true
```

## Step 5: 核心配置项说明

| 配置项 | 默认值 | 推荐值 | 原因 |
|--------|--------|--------|------|
| `target` | `ES3/ES5` | `ES2022` | 映射类型是编译期语法，但生成代码与 target 一致更安全 |
| `lib` | 随 target | 明确声明 | `keyof`/模板字面量类型依赖对应 lib 声明 |
| `strict` | `false` | `true` | 映射后类型缺失/可空问题尽早暴露 |
| `exactOptionalPropertyTypes` | `false` | 可选开启 | 让 `?` 修饰符精确区分"缺省"与"显式 undefined" |

## 常见安装/配置问题

1. **`as` 重映射报错**：TS < 4.1 不支持键重映射，先升级 `typescript@5.x`。
2. **`Capitalize` 等内置类型缺失**：模板字面量类型需要 TS 4.1+ 与 ES2015+ lib；检查 `lib` 是否包含 `ES2021` 及以上。
3. **映射类型误用于 interface 报错**：映射类型只能在 type 别名中使用，interface 中写 `[K in ...]` 直接编译报错——改为 `type` 声明。
