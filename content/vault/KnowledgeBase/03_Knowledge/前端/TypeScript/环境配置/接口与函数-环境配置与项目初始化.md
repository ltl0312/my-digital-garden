## Step 2: 最小可运行示例

```typescript
interface User {
    readonly id: number;
    name: string;
    email?: string;
}
function createUser(user: User): string {
    return `Created ${user.name} (ID: ${user.id})`;
}
console.log(createUser({ id: 1, name: "Alice" }));
```

## Step 3: 函数重载最佳实践

```typescript
// ✅ 重载签名的顺序：精确 → 宽泛
function greet(name: string): string;       // 精确：单参数
function greet(first: string, last: string): string; // 精确：双参数
function greet(...args: string[]): string { // 实现
    return args.length === 1 ? `Hi ${args[0]}` : `Hi ${args[0]} ${args[1]}`;
}
```

## 常见问题

1. **"Property does not exist on type"**：对象字面量有额外属性时报错，要么用接口定义该属性，要么用索引签名 `[key: string]: any`。
2. **函数重载实现签名不可见**：实现签名的参数类型必须是所有重载签名的联合，且不能比声明签名的类型更宽。
