# TypeScript 类与高级类型 — 环境配置

## 前置条件
- TS 开发环境（参考 <a href="obsidian://open?file=基础语法-环境配置与项目初始化">TypeScript-基础语法-环境配置与项目初始化</a>）

## Step 1: tsconfig 类相关配置

```json
{
  "compilerOptions": {
    "strictPropertyInitialization": true,  // 类属性必须初始化（配合 strictNullChecks）
    "noImplicitOverride": true,            // 重写方法必须加 override 关键字
    "useDefineForClassFields": true         // 使用 ES2022 类字段语义
  }
}
```

## Step 2: 抽象类检查

```typescript
abstract class Base {
    abstract doSomething(): void;
}
class Derived extends Base {
    doSomething() { console.log("done"); }
}
// const b = new Base();  // ❌ 编译错误：不能实例化抽象类
```

## Step 3: 最小示例

```typescript
// 联合类型 + 枚举综合示例
enum LogLevel { Debug, Info, Error }
type LogEntry = { level: LogLevel; message: string; timestamp: Date };

function log(entry: LogEntry) {
    console.log(`[${LogLevel[entry.level]}] ${entry.message}`);
}
log({ level: LogLevel.Error, message: "Fail", timestamp: new Date() });
```

## 常见问题

1. **抽象类被 new**：`tsc --noEmit` 只做类型检查，确保能捕获抽象类实例化错误。
2. **`#` 私有字段 vs `private`**：`#` 是 ES2022 硬私有（运行时保护），`private` 仅在编译时。
