# TypeScript 泛型

## 📍 知识体系定位
- **所属技术栈**：前端 Vue 3
- **所在层级**：L3 工程化 → TypeScript → 泛型

- **同级技术**：Java Generics、C++ Templates（编译期展开，概念类似但机制不同）

## 概述（Overview）
> **泛型（Generics）** 是 TS 中最像"标签语法"的特性——在定义函数、接口或类时，用类型变量 `<T>` 作为占位符，调用时再指定具体类型。泛型约束（`<T extends Interface>`）限制类型变量必须满足某个形状，实现"有约束的灵活"。

## 设计初衷（Motivation）

### 设计思想
泛型解决了"我想写一个通用的容器/函数，但要保留类型信息"的问题。没有泛型时：① 用 `any` → 丢失类型安全 ② 为每种类型写重载 → 代码爆炸。泛型的类型变量 `<T>` 在调用点被 TS 推导或显式指定，实现"一次定义，多处复用，类型安全"。

## 实现（Implementation）

### 泛型函数

```typescript
// ① 基础泛型：T 是类型变量，输入什么类型就返回什么类型
function identity<T>(arg: T): T {
    return arg;
}
let out1 = identity<string>("myString");  // 显式指定 T = string
let out2 = identity(100);                 // TS 自动推导 T = number

// ② 泛型数组
function firstElement<T>(arr: T[]): T | undefined {
    return arr[0];
}
firstElement([1, 2, 3]);        // T = number，返回 number | undefined
firstElement(["a", "b"]);       // T = string，返回 string | undefined
```

### 泛型接口与泛型类

```typescript
// 泛型接口
interface GenericIdentityFn<T> {
    (arg: T): T;
}
const myFn: GenericIdentityFn<number> = (arg) => arg; // arg 和返回值都是 number

// 泛型类
class GenericNumber<T> {
    zeroValue: T;
    add: (x: T, y: T) => T;
    constructor(zero: T, addFn: (x: T, y: T) => T) {
        this.zeroValue = zero;
        this.add = addFn;
    }
}
let numCalc = new GenericNumber<number>(0, (x, y) => x + y);
let strCalc = new GenericNumber<string>("", (x, y) => x + y);
```

### 泛型约束 `<T extends Interface>`

```typescript
// 约束：T 必须有 length 属性
interface Lengthwise {
    length: number;
}
function loggingIdentity<T extends Lengthwise>(arg: T): T {
    console.log(arg.length);  // ✅ T 一定有 length
    return arg;
}

loggingIdentity("hello");     // ✅ string 有 length
loggingIdentity([1, 2, 3]);   // ✅ array 有 length
// loggingIdentity(123);      // ❌ Error: number 没有 length

// ★ 使用类型参数约束另一个类型参数
function getProperty<T, K extends keyof T>(obj: T, key: K): T[K] {
    return obj[key];  // K 必须是 T 的键名
}
getProperty({ name: "Alice", age: 25 }, "name");  // ✅ "name" 是合法键
// getProperty({ name: "Alice" }, "age");         // ❌ "age" 不是 {name} 的键
```

> **💡 补充**：Vue 3 中的泛型应用——`ref<number>(0)` 使 `.value` 得到 `number` 类型；`computed<string>(() => "hello")` 使返回值得到 `string` 类型；`defineProps<{ title: string }>()` 用泛型定义组件 props 类型。
