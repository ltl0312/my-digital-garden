# TypeScript 类型断言与类型守卫

## 📍 知识体系定位
- **所属技术栈**：前端 Vue 3
- **所在层级**：L3 工程化 → TypeScript → 类型操作
- **上游依赖**：<a href="obsidian://open?file=泛型">TypeScript-泛型</a>、<a href="obsidian://open?file=类与高级类型">TypeScript-类与高级类型</a>
- **下游延伸**：运行时数据校验（Zod）、API 响应类型安全

## 概述（Overview）
> **类型断言（Type Assertion）**告诉编译器"我知道它是什么类型"——你比 TS 更了解当前值的实际类型。**类型守卫（Type Guards）**在运行时检查并缩窄类型范围——`typeof`/`instanceof`/`in`/`is` 谓词四种方式。两者互补：断言是"相信我"，守卫是"证明它"。

## 设计初衷（Motivation）

### 设计思想
类型断言是开发者的"主观声明"（unsafe，不检查），类型守卫是"客观证据"（safe，运行时检查）。TS 更推崇后者——`unknown` 类型强制你用守卫先证明再使用。`pet is Fish` 这种自定义类型守卫是 TS 最精妙的设计之一：一个返回布尔值的函数同时承担了"类型缩窄器"的角色。

## 实现（Implementation）

### 类型断言

```typescript
let someValue: unknown = "this is a string";

// 方式 1：as 语法（推荐，与 JSX 兼容）
let strLen: number = (someValue as string).length;

// 方式 2：尖括号语法（不用于 JSX/.tsx 文件）
let strLen2: number = (<string>someValue).length;

// ★ 双重断言（极端情况，跳过所有检查）
let num = (someValue as any as number).toFixed(2); // 危险！
```

### 类型守卫

```typescript
// ① typeof 守卫（基础类型）
function padLeft(value: string | number) {
    if (typeof value === "number") {
        return " ".repeat(value);  // TS 知道这是 number
    }
    return value;                   // TS 知道这是 string
}

// ② instanceof 守卫（类实例）
class Dog { bark() {} }
class Cat { meow() {} }
function makeSound(animal: Dog | Cat) {
    if (animal instanceof Dog) animal.bark();
    else animal.meow();
}

// ③ in 操作符（检查属性是否存在）
interface Bird { fly(): void; }
interface Fish { swim(): void; }
function move(pet: Bird | Fish) {
    if ("swim" in pet) pet.swim();
    else pet.fly();
}

// ④ ★ 自定义类型守卫 is（类型谓词）
function isFish(pet: Bird | Fish): pet is Fish {
    return (pet as Fish).swim !== undefined;
}
function move2(pet: Bird | Fish) {
    if (isFish(pet)) {
        pet.swim();  // TS 知道这里肯定是 Fish
    } else {
        pet.fly();   // TS 知道这里肯定是 Bird
    }
}
```

### typeof 类型查询操作符（编译期）

`typeof` 有两种身份：**运行时运算符**（上一节：类型守卫）与**编译期类型查询操作符**——放在类型位置上，用来"获取某个值/变量的类型"。

```typescript
let p = { x: 1, y: 2 };

// typeof p 出现在类型位置：获取 p 的类型 { x: number; y: number }
function formatPoint(point: typeof p) {
    return `(${point.x}, ${point.y})`;
}

formatPoint({ x: 1, y: 100 });   // ✅ 结构相同即可传入（结构化类型系统）
// formatPoint({ x: 1 });        // ❌ Error: 缺少 y 属性
```

> **💡 补充**：`typeof` 类型查询与运行时的 `typeof` 是同一关键字的不同用途——运行时返回 "string"/"number" 等字符串，编译期返回 TS 类型。它只能查询变量/属性（有具体值的东西），不能查询函数调用表达式。常与 `keyof` 配合（如 `keyof typeof obj` 获取对象所有键的联合类型）。
