## 概述（Overview）
> **内置工具类型（Utility Types）**是 TS 提供的一组全局泛型，用于对已有类型做变换——`Partial` 全部变可选、`Required` 全部变必填、`Pick` 选取子集、`Omit` 剔除子集、`Record` 构造键值对类型等。**装饰器（Decorators）**用 `@expression` 语法在类及其成员上声明元数据或修改行为。

## 设计初衷（Motivation）

### 设计思想
工具类型体现了"类型元编程"的理念——类型本身可以被操作、转换。`Partial<Todo>` 不需要重新定义一个 `PartialTodo` interface，而是用泛型工具从 `Todo` 派生。装饰器是 AOP（面向切面编程）的实现——在类/方法/属性定义时"横切"注入日志、验证、缓存等逻辑。

## 实现（Implementation）

### 内置工具类型速查

```typescript
interface Todo {
    title: string;
    description: string;
    completed: boolean;
    createdAt: Date;
}

// ① Partial<T>：所有属性变为可选
type PartialTodo = Partial<Todo>;
// { title?: string; description?: string; completed?: boolean; ... }

// ② Required<T>：所有属性变为必填
type RequiredTodo = Required<PartialTodo>;

// ③ Readonly<T>：所有属性只读
type ReadonlyTodo = Readonly<Todo>;

// ④ Record<K, V>：构造键为 K、值为 V 的对象类型
type PageInfo = Record<"home" | "about", { title: string }>;
// { home: {title: string}; about: {title: string} }

// ⑤ Pick<T, K>：从 T 中挑选 K 属性
type TodoPreview = Pick<Todo, "title" | "completed">;
// { title: string; completed: boolean }

// ⑥ Omit<T, K>：从 T 中剔除 K 属性
type TodoInfo = Omit<Todo, "completed" | "createdAt">;
// { title: string; description: string }

// ⑦ Exclude<T, U>：从联合类型 T 中排除 U
type T0 = Exclude<"a" | "b" | "c", "a">;  // "b" | "c"

// ⑧ Extract<T, U>：提取联合类型 T 中与 U 的交集
type T1 = Extract<"a" | "b" | "c", "a" | "f">;  // "a"

// ⑨ ReturnType<T>：获取函数返回值类型
type Func = () => number;
type RType = ReturnType<Func>;  // number

// ⑩ NonNullable<T>：排除 null 和 undefined
type T2 = NonNullable<string | null | undefined>;  // string
```

### 装饰器

```typescript
// ★ 需在 tsconfig.json 开启 experimentalDecorators: true

// ① 类装饰器
function sealed(constructor: Function) {
    Object.seal(constructor);
    Object.seal(constructor.prototype);
}

@sealed
class BugReport {
    type = "report";
    title: string;
    constructor(t: string) { this.title = t; }
}

// ② 属性装饰器（通过 defineProperty 拦截 get/set）
function format(target: any, propertyKey: string) {
    let value = target[propertyKey];
    const getter = () => `${value} (formatted)`;
    const setter = (newVal: string) => { value = newVal; };
    Object.defineProperty(target, propertyKey, { get: getter, set: setter });
}

class Greeter {
    @format
    greeting: string;
    constructor(message: string) { this.greeting = message; }
}
```

### 工具类型选择速查

| 需求 | 工具类型 |
|------|---------|
| 所有属性变为可选 | `Partial<T>` |
| 所有属性变为必填 | `Required<T>` |
| 所有属性变为只读 | `Readonly<T>` |
| 构造键值对类型 | `Record<K, V>` |
| 挑选部分属性 | `Pick<T, K>` |
| 剔除部分属性 | `Omit<T, K>` |
| 排除联合类型成员 | `Exclude<T, U>` |
| 获取返回值类型 | `ReturnType<T>` |

> **💡 补充**：实际开发中最常用的是 `Pick` 和 `Omit`——从已有接口派生新类型而无需重新定义。Vue 3 源码中大量使用 `Pick`/`Omit` 来从组件选项类型中提取子集。
