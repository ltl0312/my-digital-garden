# TypeScript 接口与函数类型

## 📍 知识体系定位
- **所属技术栈**：前端 Vue 3
- **所在层级**：L3 工程化 → TypeScript → 接口与函数
- **上游依赖**：<a href="obsidian://open?file=基础与特殊类型">TypeScript-基础与特殊类型</a>
- **下游延伸**：Vue 3 Props 类型定义、API 响应类型建模
- **同级技术**：Zod（运行时校验）、JSON Schema（数据描述）

## 概述（Overview）
> **Interface** 用于定义对象的"形状"（Shape）——规定对象必须有哪些属性、属性是什么类型。支持可选属性（`?`）、只读属性（`readonly`）、索引签名（`[key: string]: any`）和继承（`extends`）。TS 对函数的参数和返回值都进行类型检查，支持可选参数、默认参数、剩余参数和**函数重载**（同名函数的不同参数组合）。

## 设计初衷（Motivation）

### 设计思想
Interface 是 TypeScript 的类型系统基石——它不生成任何 JS 代码（编译后完全消失），只是在编译阶段做"形状检查"（Structural Typing，鸭式类型）。这与 Java/C# 的 Nominal Typing（名义类型，必须显式声明实现接口）不同——TS 只要形状匹配就算符合接口。

## 实现（Implementation）

### Interface 定义对象形状

```typescript
interface User {
    readonly id: number;      // 只读：初始化后不可修改
    name: string;              // 必填
    age?: number;              // 可选：number | undefined
    [propName: string]: any;   // 索引签名：允许任意额外属性
}

const user: User = { id: 1, name: "Alice", gender: "female" };
// user.id = 2;               // ❌ Error: 只读属性不可修改

// 接口继承
interface Animal { eat(): void; }
interface Dog extends Animal { bark(): void; }
// Dog 必须同时实现 eat() 和 bark()
```

### 函数类型标注

```typescript
// ① 参数与返回值类型
function add(x: number, y: number): number {
    return x + y;
}

// ② 可选参数（必须放在必需参数后面）
function buildName(firstName: string, lastName?: string): string {
    return lastName ? `${firstName} ${lastName}` : firstName;
}

// ③ 默认参数（自动推断类型）
function multiply(a: number, b: number = 2): number {
    return a * b;
}

// ④ 剩余参数（...args 必须是数组类型）
function sumAll(...numbers: number[]): number {
    return numbers.reduce((total, num) => total + num, 0);
}

// ⑤ 函数类型表达式（箭头语法定义函数签名）
type MathOp = (a: number, b: number) => number;
const add2: MathOp = (x, y) => x + y;   // 参数类型可省略（从 MathOp 推导）
```

### 函数重载

```typescript
// 重载签名（声明）：对外暴露的不同调用方式
function getInfo(name: string): string;
function getInfo(age: number): string;
function getInfo(isAdmin: boolean): string;
// 实现签名：兼容所有重载，不直接被外部调用
function getInfo(value: string | number | boolean): string {
    if (typeof value === "string") return `Name: ${value}`;
    if (typeof value === "number") return `Age: ${value}`;
    return `Admin: ${value}`;
}

getInfo("Alice");   // ✅ 返回 "Name: Alice"
getInfo(25);        // ✅ 返回 "Age: 25"
getInfo(true);      // ✅ 返回 "Admin: true"
// getInfo(null);   // ❌ Error: 没有匹配的重载
```

> **💡 补充**：`interface` vs `type` 的选择——定义对象形状优先用 `interface`（支持声明合并、extends 更直观）；定义联合类型、元组、函数签名用 `type`（更灵活）。Vue 3 源码中两者混用，Props 用 interface，组合类型用 type。
