# Next.js 项目创建与核心配置

## 📍 知识体系定位
- **所属技术栈**：前端（React 生态）
- **所在层级**：Next.js → 工程化与配置层
- **上游依赖**：<a href="obsidian://open?file=框架概述与核心特性">Next.js 框架概述与核心特性</a> — 先理解框架定位

- **同级技术**：Vite + React（手动搭建），CRA（已废弃）

## 概述（Overview）
> 一句话定义：`create-next-app` 是 Next.js 的脚手架工具，一键生成包含 TypeScript、ESLint、Tailwind CSS 等可选配置的完整项目模板。项目结构围绕 `pages/`（路由）和 `next.config.js`（配置中心）展开。

## 实现（Implementation）

### 创建项目

```bash
# ① 场景：从零创建 Next.js 项目
npx create-next-app@latest
# ② 交互式问答（当前最新版 Next.js 15.x）：
#    What is your project named? → 输入项目名
#    Would you like to use TypeScript? → Yes
#    Would you like to use ESLint? → Yes
#    Would you like to use Tailwind CSS? → 按需选择
#    Would you like to use `src/` directory? → Yes（推荐）
#    Would you like to use App Router? → Yes（推荐新项目用 App Router）
#    Would you like to customize the import alias? → 默认即可

# ② 等待安装依赖（1-2 分钟）
```

### 项目结构

```
nextjs-demo/
├── src/
│   └── pages/               # ② Pages Router 页面目录（与 App Router 二选一）
│       ├── index.js          # 首页 → /
│       ├── _app.js           # 自定义 App 外壳
│       ├── _document.js      # 自定义 HTML 文档
│       └── api/              # API Routes
│           └── hello.js
├── public/                   # 静态资源（图片、favicon）
├── styles/                   # 样式文件
├── next.config.js            # ② Next.js 核心配置
├── package.json
└── tsconfig.json             # TypeScript 配置
```

### 启动与构建

```bash
npm run dev           # 开发模式（热更新）→ http://localhost:3000
npm run build         # 生产构建
npm run start         # 启动生产服务器
```

### 可扩展配置（next.config.js）

Next.js 暴露出几乎所有配置项，你可以"完全"控制：

```js
// next.config.js
module.exports = {
    // ② 完全控制 webpack 配置
    webpack: (config, { isServer }) => {
        // 自定义 webpack 规则
        return config;
    },

    // ② 服务端/客户端公共配置
    serverRuntimeConfig: { apiUrl: 'https://api.internal.com' },
    publicRuntimeConfig: { apiUrl: 'https://api.public.com' },

    // ② 按需编译第三方 ES 包（tree shaking 粒度更细）
    transpilePackages: ['some-esm-package'],

    // ② 图片优化配置
    images: {
        domains: ['cdn.example.com'],
    },
};
```

### 其他可自定义项

| 自定义项 | 文件 | 用途 |
|---------|------|------|
| 自定义 Server | 自建 `server.js` | 启动时性能监控、自定义路由逻辑 |
| Middleware | `middleware.ts` | 拦截请求、权限校验（无需自定义 server） |
| 自定义 App | `_app.js` | 全局布局、全局状态注入 |
| 自定义 Document | `_document.js` | HTML 结构、GA 脚本注入 |
| 自定义错误页 | `pages/404.js`, `pages/500.js` | 自定义错误界面 |
| 自定义 Head | `<Head>` 组件 | 页面级 title/meta/base 标签 |
| 自定义 Babel | `.babelrc` | 覆盖 Babel 预设 |
| 自定义 PostCSS | `postcss.config.js` | 覆盖 PostCSS 插件 |
