# Next.js — 项目创建与工程化配置指南

> 本指南聚焦于项目创建后的工程化配置。基础安装请参考 <a href="obsidian://open?file=环境配置与项目初始化">Next.js 环境配置与项目初始化</a>。

## Step 1: 内置工程化配置一览

Next.js 内置以下工具链，无需手动安装：

| 工具 | 状态 | 说明 |
|------|------|------|
| babel | ✅ 内置 | JS 向后兼容 |
| postcss | ✅ 内置 | CSS 向后兼容 |
| browserslist | ✅ 支持 | 配合 babel/postcss |
| TypeScript | ✅ 可选 | 创建时选择 |
| ESLint | ✅ 可选 | 创建时选择 |
| CSS Modules | ✅ 内置 | `*.module.css` |
| Tailwind CSS | ✅ 可选 | 创建时选择 |

## Step 2: next.config.js 完整配置

```js
/** @type {import('next').NextConfig} */
const nextConfig = {
    // ② React 严格模式（开发环境双次渲染以检测副作用）
    reactStrictMode: true,

    // ② 声明需要 babel 编译的第三方 ES 包
    transpilePackages: ['some-esm-only-package'],

    // ② 图片优化：允许加载的外部域名
    images: {
        domains: ['cdn.example.com', 'images.unsplash.com'],
        formats: ['image/avif', 'image/webp'],
    },

    // ② webpack 完全控制
    webpack: (config, { isServer, dev }) => {
        // 自定义规则...
        return config;
    },

    // ② 环境变量（服务端专用）
    serverRuntimeConfig: {
        API_SECRET: process.env.API_SECRET,
    },
    // ② 环境变量（客户端也可用）
    publicRuntimeConfig: {
        API_URL: process.env.NEXT_PUBLIC_API_URL,
    },

    // ② 重定向
    async redirects() {
        return [
            { source: '/old-page', destination: '/new-page', permanent: true },
        ];
    },

    // ② 重写（代理）
    async rewrites() {
        return [
            { source: '/api/:path*', destination: 'https://backend.example.com/:path*' },
        ];
    },
};

module.exports = nextConfig;
```

## Step 3: 自定义 Babel 配置

// .babelrc

    "presets": ["next/babel"],
    "plugins": [
        ["styled-components", { "ssr": true }]
    ]
}
```

```

## Step 5: 性能分析

```bash
# 安装分析工具
npm i @next/bundle-analyzer -D

# 使用：在 next.config.js 中包裹
const withBundleAnalyzer = require('@next/bundle-analyzer')({
    enabled: process.env.ANALYZE === 'true',
});
module.exports = withBundleAnalyzer(nextConfig);

# 运行分析
ANALYZE=true npm run build
```

图例：`○` = 静态（SSG），`●` = 服务端渲染（SSR），`λ` = 需要 Node.js 服务端
