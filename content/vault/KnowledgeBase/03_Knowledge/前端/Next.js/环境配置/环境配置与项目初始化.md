# Next.js — 环境配置与项目初始化

## 信息来源
- **官方文档**：https://nextjs.org/docs/getting-started/installation （✅ 可访问）
- **参考文章**：
  - 博客园「Next.js项目演示」：https://www.cnblogs.com/slgkaifa/p/19124249
  - 掘金「Next.js了解篇」：https://juejin.cn/post/7204085076504920119

## 前置条件
- Node.js >= 18（推荐 LTS 版本）
- npm / yarn / pnpm

## Step 1: 验证 Node.js 环境

```bash
node -v     # 预期：v18.x.x 或更高
npm -v      # 预期：9.x.x 或更高
```

如果未安装：前往 https://nodejs.org/ 下载并安装 LTS 版本。

## Step 2: 创建 Next.js 项目

```bash
# 使用 create-next-app 脚手架
npx create-next-app@latest nextjs-demo
```

交互式问答（Next.js 15.x）：

| 问题 | 推荐选择 | 说明 |
|------|---------|------|
| TypeScript? | Yes | 类型安全，强烈推荐 |
| ESLint? | Yes | 代码质量 |
| Tailwind CSS? | 按需 | CSS 框架 |
| `src/` directory? | Yes | 源码放 src 目录 |
| App Router? | Yes（新项目）/ No（学习 Pages Router） | 路由方案 |
| Import alias? | 默认 | `@/*` 指向 src |

## Step 3: 启动开发服务器

```bash
cd nextjs-demo
npm run dev
# 预期输出：Ready on http://localhost:3000
```

浏览器访问 `http://localhost:3000` 看到欢迎页面即成功。

## Step 4: 项目结构速览

```
nextjs-demo/
├── src/pages/           # 页面（文件路由）
│   ├── index.js         # 首页
│   └── _app.js          # 全局外壳
├── public/              # 静态资源
├── next.config.js       # Next.js 配置
├── package.json
└── tsconfig.json        # TS 配置
```

## Step 5: 构建部署

```bash
npm run build       # 生产构建（SSG 页面在此阶段生成）
npm run start       # 启动生产服务器（默认 3000 端口）
```

## 核心配置项（next.config.js）

| 配置项 | 说明 |
|--------|------|
| `transpilePackages` | 声明需要被 babel 编译的第三方 ES 包 |
| `images.domains` | 允许 next/image 加载的外部图片域名 |
| `serverRuntimeConfig` | 仅服务端可用的配置 |
| `publicRuntimeConfig` | 服务端和客户端均可用的配置 |
| `webpack(config)` | 完全控制 webpack 配置 |

## 常见问题

### 问题 1：Windows 上开发/构建性能差
- **原因**：Next.js 的 turbopack/webpack 在 Windows 文件系统上 I/O 性能弱于 macOS/Linux
- **解决**：使用 WSL2，或将项目放在 SSD 上

### 问题 2：页面修改后热更新不生效
- **解决**：确认使用 `npm run dev` 而非 `npm run start`。重启开发服务器

### 问题 3：端口 3000 被占用
- **解决**：`npm run dev -- -p 3001` 指定其他端口
