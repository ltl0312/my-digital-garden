# Next.js — 文件路由系统配置指南

> 本指南聚焦于 Pages Router 的路由配置。基础安装请参考 <a href="obsidian://open?file=环境配置与项目初始化">Next.js 环境配置与项目初始化</a>。

## 信息来源
- **官方文档**：https://nextjs.org/docs/pages/building-your-application/routing （✅ 可访问）

## Step 1: 文件路由映射规则

```bash
# 创建页面文件即创建路由
touch src/pages/about.js      # → /about
mkdir src/pages/blog
touch src/pages/blog/index.js # → /blog
touch src/pages/blog/[id].js  # → /blog/:id（动态路由）
```

## Step 2: 配置 _app.js（全局外壳）

```js
// src/pages/_app.js
import '@/styles/globals.css';

export default function MyApp({ Component, pageProps }) {
    // ② 这里可以包裹全局 Provider（Redux、Auth 等）
    return (
        <Layout>
            <Component {...pageProps} />
        </Layout>
    );
}
```

## Step 3: 配置 _document.js（HTML 文档结构）

```js
// src/pages/_document.js
import { Html, Head, Main, NextScript } from 'next/document';

export default function Document() {
    return (
        <Html lang="zh-CN">
            <Head>
                {/* ② 全局 meta、字体、第三方脚本 */}
                <link rel="icon" href="/favicon.ico" />
            </Head>
            <body>
                <Main />
                <NextScript />
            </body>
        </Html>
    );
}
```

## Step 4: 配置 API Routes

```js
// src/pages/api/hello.js
export default function handler(req, res) {
    if (req.method === 'GET') {
        res.status(200).json({ name: 'Next.js API' });
    } else {
        res.status(405).json({ error: 'Method not allowed' });
    }
}
```

## Step 5: 页面文件组织结构（推荐）

```
src/
├── common/           # 公共组件和工具
├── views/            # 页面具体实现
│   └── home/
│       ├── index.tsx      # 页面主组件
│       ├── List.tsx        # 页面子组件
│       └── util.ts         # 页面工具函数
├── pages/            # 路由层（只做转发）
│   └── home.tsx → export * from '@/views/home'
└── styles/
```

> **💡 补充**：这种组织方式将"路由声明"（pages）和"页面实现"（views）分离，避免 pages 目录下堆积非页面文件。

## 路由参数速查

| 路由文件 | URL 匹配 |
|---------|---------|
| `pages/index.js` | `/` |
| `pages/about.js` | `/about` |
| `pages/blog/[slug].js` | `/blog/hello` |
| `pages/blog/[...slug].js` | `/blog/a/b/c`（捕获所有） |
| `pages/post/[id]/[comment].js` | `/post/1/abc`（多参数） |
