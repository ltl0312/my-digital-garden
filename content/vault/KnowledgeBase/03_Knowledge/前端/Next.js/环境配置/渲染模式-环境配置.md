# Next.js — 渲染模式配置指南

> 本指南聚焦于 Pages Router 的数据获取方法配置。基础安装请参考 <a href="obsidian://open?file=环境配置与项目初始化">Next.js 环境配置与项目初始化</a>。

## 信息来源
- **官方文档**：https://nextjs.org/docs/pages/building-your-application/data-fetching （✅ 可访问）

## 渲染模式选择决策树

```
页面内容是否频繁变化？
├── 否（博客、文档） → SSG / ISR
│   ├── 内容永不改变？ → SSG (getStaticProps)
│   └── 内容偶尔更新？ → ISR (getStaticProps + revalidate)
└── 是（实时数据、个性化） → SSR (getServerSideProps)

页面需要 SEO？
├── 否（管理后台） → CSR（不导出数据获取函数）
└── 是 → SSR / SSG
```

## Step 1: 配置 SSG（静态生成）

```js
// pages/index.js
export async function getStaticProps() {
    const data = await fetch('https://api.example.com/data').then(r => r.json());
    return {
        props: { data },          // ② 注入页面组件
    };
}

export default function Page({ data }) {
    return <pre>{JSON.stringify(data, null, 2)}</pre>;
}
```

## Step 2: 配置 SSR（服务端渲染）

```js
// pages/product/[id].js
export async function getServerSideProps({ params, req, res }) {
    const { id } = params;
    const product = await fetch(`https://api.example.com/product/${id}`).then(r => r.json());
    return {
        props: { product },
        // notFound: true,        // ② 可返回 404
        // redirect: { destination: '/', permanent: false },  // ② 可重定向
    };
}
```

## Step 3: 配置 ISR（增量静态再生）

```js
// pages/blog/[slug].js
export async function getStaticProps({ params }) {
    const post = await fetch(`https://api.example.com/post/${params.slug}`).then(r => r.json());
    return {
        props: { post },
        revalidate: 60,           // ② 秒数：每 60 秒后台重新生成
    };
}

export async function getStaticPaths() {
    const posts = await fetch('https://api.example.com/posts').then(r => r.json());
    return {
        paths: posts.map(p => ({ params: { slug: p.slug } })),
        fallback: 'blocking',      // ② blocking：首次请求时 SSR + 缓存
                                   // ② true：返回 fallback 页面 + 后台 SSR
                                   // ② false：未预生成的路径返回 404
    };
}
```

## 关键参数速查

| API | 运行时机 | 常用返回字段 | 使用场景 |
|-----|---------|-------------|---------|
| `getStaticProps` | 构建时 | `props`, `revalidate`, `notFound`, `redirect` | SSG / ISR |
| `getStaticPaths` | 构建时 | `paths`, `fallback` | 动态路由 SSG |
| `getServerSideProps` | 每次请求 | `props`, `notFound`, `redirect` | SSR |

## 常见问题

### 问题 1：`getStaticProps` 中 fetch 返回 undefined
- **原因**：API 路由不能在同项目的 `getStaticProps` 中调用（构建时服务未启动）
- **解决**：直接写数据库查询或调用外部 API

### 问题 2：ISR 页面不更新
- **解决**：`revalidate` 是最小间隔，不是精确间隔。可使用 On-Demand ISR（API 触发手动重新验证）
