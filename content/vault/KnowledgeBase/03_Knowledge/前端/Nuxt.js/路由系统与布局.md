# Nuxt.js 路由系统与布局

## 📍 知识体系定位
- **所属技术栈**：前端（Vue 生态）
- **所在层级**：Nuxt.js → 路由层
- **上游依赖**：<a href="obsidian://open?file=框架概述与SSR原理">Nuxt.js 框架概述与SSR原理</a> — 先理解 Nuxt 的整体定位
- **下游延伸**：<a href="obsidian://open?file=数据获取与状态管理">Nuxt.js 数据获取与状态管理</a> — 路由页面中获取数据
- **同级技术**：Vue Router（手动配置路由表），Next.js Pages Router（React 的文件路由）

## 概述（Overview）
> 一句话定义：Nuxt.js 采用**文件系统路由**——`pages/` 目录下的每个 `.vue` 文件自动成为对应 URL 路径的页面，无需手动写路由配置。配合 `layouts/` 布局系统，实现页面公共外壳的复用。

```
pages/
├── index.vue          →  /
├── about.vue          →  /about
├── blog/
│   └── index.vue      →  /blog
├── users/
│   └── _id.vue        →  /users/:id（动态路由）
└── posts/
    └── _slug.vue      →  /posts/:slug
```

## 实现（Implementation）

### 文件路由映射

| 文件路径 | 生成的路由 |
|---------|-----------|
| `pages/index.vue` | `/` |
| `pages/about.vue` | `/about` |
| `pages/blog/index.vue` | `/blog` |
| `pages/users/_id.vue` | `/users/:id` |

### 基础页面

```vue
<!-- pages/about.vue — ② 文件名 = 路由路径，创建即生效 -->
<template>
  <div>
    <h1>关于我们</h1>
    <p>这里是关于页面的内容。</p>
  </div>
</template>
<!-- ③ 访问 http://localhost:3000/about → 页面自动生效 -->
```

### 动态路由

```vue
<!-- pages/users/_id.vue — ② _id 下划线前缀 = 动态参数 -->
<template>
  <div>
    <h1>用户详情页</h1>
    <p>用户ID：{{ $route.params.id }}</p>  <!-- ② 获取动态参数 -->
  </div>
</template>
<!-- ③ 访问 /users/123 → 页面显示"用户ID：123" -->
```

### NuxtLink 导航

```vue
<!-- ② 使用 <NuxtLink> 而非 <a> 标签，实现客户端路由切换（不刷新页面） -->
<template>
  <header>
    <nav>
      <NuxtLink to="/">首页</NuxtLink>
      <NuxtLink to="/about">关于</NuxtLink>
      <NuxtLink to="/users/456">用户456</NuxtLink>
    </nav>
  </header>
</template>

<style scoped>
/* ② 当前激活路由的链接自动添加 .nuxt-link-active 类 */
.nuxt-link-active {
  font-weight: bold;
  color: #42b983;
}
</style>
```

> ⚠️ 不要写成 `<a>` 标签——`<a>` 会重新获取整个页面（非 SPA 模式），`<NuxtLink>` 才是客户端路由切换。

### 路由参数传递

```vue
<!-- 方式一：NuxtLink 传参（query） -->
<NuxtLink :to="{ path: '/about', query: { id: 123 } }">
<!-- ③ 地址栏：/about?id=123，接收：this.$route.query.id -->

<!-- 方式二：编程式导航 -->
<script>
export default {
  methods: {
    goDetail(id) {
      this.$router.push({ path: `/describe/${id}` })  // 接收：$route.params.id
      // 或使用 query 传参（页面刷新后参数不丢失）：
      this.$router.push({ path: '/describe', query: { id } })
    }
  }
}
</script>
```

### 路由参数校验

```vue
<!-- pages/news/_id.vue -->
<script>
export default {
  // ② validate 方法校验动态路由参数，返回 true 才渲染页面
  validate({ params }) {
    return /^\d+$/.test(params.id)  // ② 只允许数字 ID
  }
}
</script>
<!-- ③ 访问 /news/abc → 校验失败，跳转 404 -->
```

### 嵌套路由

```
pages/
├── parent.vue              # 父组件
└── parent/                 # 与父组件同名的文件夹
    ├── child1.vue          # /parent/child1
    └── child2.vue          # /parent/child2
```

```vue
<!-- pages/parent.vue — ② 父组件中使用 <NuxtChild> 展示子视图 -->
<template>
  <div>
    <h1>父页面</h1>
    <NuxtChild />  <!-- ② 子路由页面在此处渲染 -->
  </div>
</template>
```

### 布局系统

```vue
<!-- layouts/custom.vue — ② 自定义布局 -->
<template>
  <div>
    <Header />
    <main>
      <slot />  <!-- ② 页面内容插入点 -->
    </main>
    <footer>© 2024 我的网站</footer>
  </div>
</template>
```

```vue
<!-- pages/about.vue — ② 指定页面使用自定义布局 -->
<script>
export default {
  layout: 'custom'  // ② 使用 layouts/custom.vue 布局
}
</script>
```

> **💡 补充**：不指定 `layout` 时默认使用 `layouts/default.vue`。`default.vue` 中必须包含 `<NuxtPage />` 占位符。

### 路由动画

```css
/* ② 全局路由切换动画 — 在全局 CSS 中定义 page 过渡 */
.page-enter-active, .page-leave-active {
  transition: opacity 0.5s;
}
.page-enter, .page-leave-active {
  opacity: 0;
}
```

```vue
<!-- ② 单页面自定义动画 — 在组件中指定 transition 名称 -->
<script>
export default {
  transition: 'test'  // ② 使用 .test-enter-active 等自定义动画类
}
</script>
```
