# Nuxt.js — 数据获取与状态管理配置指南

## 信息来源
- **官方文档**：https://nuxt.com/docs/getting-started/data-fetching （✅ 可访问）

## Step 1: 配置 Axios 模块（Nuxt 2 推荐）

```bash
npm install @nuxtjs/axios @nuxtjs/proxy -S
```

```javascript
// nuxt.config.js
export default {
  modules: ['@nuxtjs/axios', '@nuxtjs/proxy'],
  axios: {
    baseURL: 'https://api.example.com',
    proxy: true,        // ② 开启代理（开发中解决跨域）
    credentials: true,  // ② 请求携带 cookie
    prefix: '/api'       // ② 自动为请求 URL 添加 /api 前缀（可省略）
  },
  proxy: {
    '/api': {
      target: 'http://backend-server:7001',
      changeOrigin: true,
      pathRewrite: { '^/api': '/' }
    }
  }
}
```

## Step 2: 配置 Pinia（Nuxt 3 推荐）

```bash
npm install @pinia/nuxt -S
```

```javascript
// nuxt.config.js
export default {
  modules: ['@pinia/nuxt']
}
```

```javascript
// stores/user.js — ② 自动导入，无需手动注册
import { defineStore } from 'pinia'

export const useUserStore = defineStore('user', {
  state: () => ({ token: '', user: null }),
  actions: {
    async login(credentials) {
      const { data } = await $fetch('/api/login', { method: 'POST', body: credentials })
      this.token = data.token
    }
  }
})
```

## Step 3: 数据获取决策树

```
需要 SEO？
├── 否 → mounted() 中客户端 fetch（普通 fetch）
└── 是 → asyncData / useAsyncData（服务端预获取）
    ├── Nuxt 2 → asyncData()
    └── Nuxt 3 → useAsyncData() 或 useFetch()

注意：asyncData 中不能使用 this！
      服务端不存在 window/document 等浏览器 API
```

## 常见问题

### 问题 1：asyncData 中跨域请求被拒绝
- **原因**：服务端渲染时请求未走代理，需要完整 URL
- **解决**：Nuxt 2 使用 `@nuxtjs/axios` + proxy 配置；Nuxt 3 使用 `useFetch` 自动处理

### 问题 2：页面刷新后 Pinia 状态丢失
- **解决**：使用 `pinia-plugin-persistedstate` 持久化到 localStorage
