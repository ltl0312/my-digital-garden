# Nuxt.js — 中间件、插件与部署环境配置

> 基础安装请参考 <a href="obsidian://open?file=环境配置与项目初始化">Nuxt.js 环境配置与项目初始化</a>。

## 信息来源
- **官方文档**：https://nuxt.com/docs/getting-started/deployment （✅ 可访问）

## Step 1: 配置中间件

```bash
mkdir -p middleware
touch middleware/auth.js
```

```javascript
// middleware/auth.js
export default function ({ redirect, store }) {
  if (!store.auth?.isLoggedIn) {
    return redirect('/login')
  }
}
```

```javascript
// nuxt.config.js — ② 全局/路由级配置
export default {
  router: {
    middleware: ['auth']  // ② 所有页面需要登录
  }
}
```

## Step 2: 配置插件

```bash
mkdir -p plugins
touch plugins/axios-interceptor.js
```

```javascript
// plugins/axios-interceptor.js
export default function ({ $axios, store }) {
  $axios.onRequest(config => {
    config.headers['Authorization'] = `Bearer ${store.auth.token}`
    return config
  })
  $axios.onError(error => {
    if (error.response?.status === 401) {
      window.location.href = '/login'
    }
    return Promise.reject(error)
  })
}
```

```javascript
// nuxt.config.js
export default {
  plugins: [
    '~/plugins/axios-interceptor',
    { src: '~/plugins/wx-sdk', ssr: false }  // ② 浏览器端插件关闭 SSR
  ]
}
```

## Step 3: SSG 部署（静态站点 → 阿里云 OSS）

```javascript
// nuxt.config.js
export default { target: 'static' }
```

```bash
npm run generate          # 生成 dist/ 目录（纯静态 HTML/JS/CSS）
# 上传 dist/ 到：
#   阿里云 OSS、腾讯云 COS、Gitee Pages、七牛云 Kodo
```

## Step 4: SSR 部署（服务端渲染 → PM2）

```bash
npm run build            # 构建生产包

# 安装 PM2 守护进程
npm install pm2 -g
pm2 start "npm run start" --name nuxt-app
pm2 save                 # 保存进程列表（重启后自动恢复）
pm2 startup              # 设置开机自启
```

## Step 5: Docker 部署

```dockerfile
FROM node:16-alpine
WORKDIR /app
COPY . .
RUN npm install --production
RUN npm run build
EXPOSE 3000
CMD ["npm", "start"]
```

## Step 6: 性能优化配置

```javascript
// nuxt.config.js
export default {
  render: {
    http2: { push: true },           // ② HTTP/2 推送
    static: { maxAge: 1000 * 60 * 60 * 24 } // ② 静态资源缓存 1 天
  },
  build: {
    extractCSS: true,                 // ② 提取 CSS
    compress: { brotli: true, gzip: true } // ② 代码压缩
  }
}
```

## 部署方案对比

| 方案 | 服务器要求 | 性能 | SEO | 适用场景 |
|------|----------|------|-----|---------|
| SSG (静态) | 无需 Node 服务器 | ⚡ 极快（CDN） | ✅ | 博客、企业站、文档 |
| SSR (服务端) | Node.js 服务器 + PM2 | 🔶 中等 | ✅ | 电商、社交、动态站 |
