# Nuxt.js — 路由系统配置指南

> 基础安装请参考 <a href="obsidian://open?file=环境配置与项目初始化">Nuxt.js 环境配置与项目初始化</a>。

## 信息来源
- **官方文档**：https://nuxt.com/docs/getting-started/routing （✅ 可访问）

## Step 1: 文件路由规则

```bash
# Nuxt 2 (Pages Router)
touch pages/index.vue     # → /
touch pages/about.vue     # → /about
touch pages/users/_id.vue # → /users/:id

# Nuxt 3 (App Router 可选)
# 使用 pages/ 目录仍然有效
```

## Step 2: 配置 NuxtLink 基础路径

```vue
<!-- Nuxt 3 推荐：组件自动导入，无需 import -->
<template>
  <NuxtLink to="/about">关于</NuxtLink>
  <!-- ② NuxtLink 自动预加载目标页面资源 -->
</template>
```

## Step 3: 自定义布局

```bash
mkdir -p layouts
touch layouts/custom.vue
```

```vue
<!-- layouts/custom.vue -->
<template>
  <div>
    <Header />
    <slot />         <!-- ② 页面内容在此渲染 -->
    <Footer />
  </div>
</template>
```

## Step 4: 配置全局路由动画

```css
/* assets/css/main.css */
.page-enter-active, .page-leave-active {
  transition: opacity 0.5s;
}
.page-enter, .page-leave-active {
  opacity: 0;
}
```

```javascript
// nuxt.config.js
export default {
  css: ['~/assets/css/main.css']
}
```

## Step 5: 路由验证配置

```vue
<!-- pages/admin/[id].vue -->
<script>
export default {
  validate({ params, query, store }) {
    // ② 校验参数 + 检查权限
    return /^\d+$/.test(params.id) && store.auth.isAdmin
  }
}
</script>
<!-- ③ 验证失败 → 跳转 404 或 error 页面 -->
```
