# Nuxt.js — 环境配置与项目初始化

## 信息来源
- **官方文档**：https://nuxt.com/docs/getting-started/installation （✅ 可访问）
- **参考文章**：CSDN「Nuxt.js全栈高手养成指南」：https://blog.csdn.net/weixin_49707375/article/details/146125510

## 前置条件
- Node.js >= 16（推荐 LTS 版本）
- npm / yarn / pnpm

## Step 1: 验证环境

```bash
node -v   # 预期：v16.x.x 或更高
npm -v    # 预期：8.x.x 或更高
```

## Step 2: 创建项目（Nuxt 3）

```bash
npx create-nuxt-app my-nuxt-app
# 或使用 yarn：
yarn create nuxt-app my-nuxt-app
```

交互式问答（推荐新手选择）：

| 问题 | 推荐选择 |
|------|---------|
| Programming language | JavaScript（先熟悉）/ TypeScript（推荐） |
| Package manager | npm / yarn |
| UI framework | None（先不用，减少复杂度） |
| Nuxt.js modules | None（后续手动添加） |
| Rendering mode | Universal (SSR / SSG) |
| Deployment target | Server (SSR) |
| Development tools | jsconfig.json |
| Version control | Git |

## Step 3: 启动开发服务器

```bash
cd my-nuxt-app
npm run dev
# 预期输出：Listening on http://localhost:3000
```

## Step 4: 项目结构速览

```
my-nuxt-app/
├── pages/              # 页面组件 → 自动生成路由
├── layouts/            # 布局组件（页头、页脚）
│   └── default.vue     # 默认布局
├── components/         # 可复用 Vue 组件（自动导入）
├── assets/             # 未编译的静态资源（CSS/图片）
├── static/             # 静态文件（不经过 webpack 处理）
├── store/              # Pinia / Vuex 状态管理
├── plugins/            # Vue 插件（在根实例化前运行）
├── middleware/          # 中间件（路由守卫）
├── nuxt.config.js      # Nuxt 核心配置文件
└── package.json
```

## Step 5: 常用命令

```json
{
  "scripts": {
    "dev": "nuxt dev",         // 开发模式（热更新）
    "build": "nuxt build",     // 生产构建
    "start": "nuxt start",     // 启动生产服务器
    "generate": "nuxt generate" // 生成静态站点（SSG）
  }
}
```

## 核心配置项（nuxt.config.js）

| 配置项 | 说明 |
|--------|------|
| `mode: 'universal'` | 渲染模式：universal（SSR）/ spa（SPA） |
| `head` | 全局 HTML 头部配置（title/meta/script） |
| `css` | 全局 CSS 文件（经 webpack 打包） |
| `plugins` | 插件数组 |
| `modules` | Nuxt 模块（@nuxtjs/axios、@pinia/nuxt 等） |
| `build` | webpack 自定义配置 |
| `server` | 自定义端口和主机 `{ port: 8000, host: '0.0.0.0' }` |
| `proxy` | 开发代理（解决跨域） |

## 常见问题

### 问题 1：端口被占用
- **解决**：`nuxt.config.js` 中配置 `server: { port: 8000 }`

### 问题 2：`pages/` 目录下新建文件未生效
- **解决**：重启开发服务器。路由在启动时注册

### 问题 3：服务端代码报 `window is not defined`
- **解决**：将浏览器 API 代码放在 `mounted()` 或 `process.client` 判断中
