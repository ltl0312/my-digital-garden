# Nuxt.js 数据获取与状态管理

## 📍 知识体系定位
- **所属技术栈**：前端（Vue 生态）
- **所在层级**：Nuxt.js → 数据层
- **上游依赖**：<a href="obsidian://open?file=路由系统与布局">Nuxt.js 路由系统与布局</a> — 数据获取在路由页面中配置
- **下游延伸**：<a href="obsidian://open?file=中间件插件与部署">Nuxt.js 中间件插件与部署</a> — 中间件常配合鉴权数据使用
- **同级技术**：Next.js `getServerSideProps`/`getStaticProps`（React 对应 API）

## 概述（Overview）
> Nuxt.js 提供两套数据获取机制：**Nuxt 2 的 `asyncData`/`fetch`**（Options API）和 **Nuxt 3 的 `useAsyncData`/`useFetch`**（Composition API）。核心目标是在服务端渲染阶段预取数据，让首屏即包含完整内容，SEO 友好。

## 实现（Implementation）

### Nuxt 2：asyncData（服务端数据预获取）

**特性**：在页面渲染前运行（服务端），返回的数据自动合并到组件 `data` 中。SEO 友好。

> ⚠️ `asyncData` 在组件初始化前调用，**内部无法通过 `this` 访问组件实例**。

```vue
<!-- pages/posts/_id.vue -->
<template>
  <div>
    <h1>{{ post.title }}</h1>
    <p>{{ post.content }}</p>
  </div>
</template>

<script>
export default {
  // ② asyncData 接收 context 参数，返回的数据合并到 data
  async asyncData({ params }) {
    const post = await fetch(`https://api.example.com/posts/${params.id}`)
      .then(res => res.json())
    return { post }  // ② 返回的数据自动合并到组件 data 中
  }
}
</script>
```

**三种写法**：

```javascript
// 方式一：返回 Promise
asyncData({ params }) {
  return axios.get(`/posts/${params.id}`).then(res => ({ title: res.data.title }))
}

// 方式二：async/await（推荐）
async asyncData({ params }) {
  const { data } = await axios.get(`/posts/${params.id}`)
  return { title: data.title }
}

// 方式三：回调函数（旧式）
asyncData({ params }, callback) {
  axios.get(`/posts/${params.id}`).then(res => {
    callback(null, { title: res.data.title })
  })
}
```

**并发请求（Promise.all）**：

```javascript
async asyncData(context) {
  let [detailRes, hotRes, relatedRes] = await Promise.all([
    axios.post('/api/news/detail', { newsCode }),
    axios.post('/api/news/list', { start: 0, pageSize: 10 }),
    axios.post('/api/news/related', { start: 0, pageSize: 3 })
  ])
  return {
    detail: detailRes.data,
    hotList: hotRes.data,
    relatedList: relatedRes.data
  }
}
```

### Nuxt 3：useAsyncData / useFetch

```vue
<!-- pages/posts/[id].vue — Nuxt 3 Composition API -->
<script setup>
// ② useAsyncData：自定义数据获取逻辑 + 缓存
const { data, error } = await useAsyncData('posts', () => {
  return $fetch(`https://api.example.com/posts`)
})

// ② useFetch：useAsyncData + $fetch 的语法糖
const { data: product } = await useFetch(`/api/product/${params.id}`)

// ② 错误处理
if (error.value) {
  console.error('数据加载失败:', error.value)
}
</script>
```

### context 对象（asyncData 可用属性）

| 属性 | 描述 |
|------|------|
| `ctx.app` | 根 Vue 实例 |
| `ctx.route` | 路由实例 |
| `ctx.params` | 路由参数 |
| `ctx.query` | URL 查询字符串 |
| `ctx.error({statusCode, message})` | 触发错误页面 |
| `ctx.$axios` | Axios 实例（需安装模块） |

### Axios 集成（Nuxt 2）

```bash
npm install @nuxtjs/axios
```

```javascript
// nuxt.config.js
export default {
  modules: ['@nuxtjs/axios'],
  axios: {
    baseURL: 'https://api.example.com',
    credentials: true,
    proxy: true  // ② 开启开发代理（解决跨域）
  }
}
```

```vue
<script>
export default {
  async asyncData({ $axios }) {
    const users = await $axios.$get('/users')  // ② $axios 自动注入
    return { users }
  }
}
</script>
```

### 状态管理：Pinia

```bash
npm install @pinia/nuxt
```

```javascript
// nuxt.config.js
export default { modules: ['@pinia/nuxt'] }
```

```javascript
// stores/counter.js — ② Nuxt 自动导入 stores/ 目录下的 store
import { defineStore } from 'pinia'

export const useCounterStore = defineStore('counter', {
  state: () => ({ count: 0 }),
  actions: {
    increment() { this.count++ }
  }
})
```

```vue
<script setup>
// ② 直接在组件中使用，无需手动导入
const counter = useCounterStore()
</script>
```
