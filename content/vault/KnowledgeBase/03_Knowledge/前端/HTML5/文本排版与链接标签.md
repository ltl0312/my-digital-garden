# HTML 文本排版与链接标签

## 📍 知识体系定位
- **所属技术栈**：前端 Vue 3
- **所在层级**：L0 三件套 → HTML5 → 文本内容标签
- **上游依赖**：<a href="obsidian://open?file=基础语法与文档结构">HTML5-基础语法与文档结构</a>
- **下游延伸**：CSS 文本样式（字体、颜色、行高、间距）、JavaScript DOM 文本操作
- **同级技术**：<a href="obsidian://open?file=语义化结构标签">HTML5-语义化结构标签</a>（结构层）、CSS3 文本属性（表现层）

## 概述（Overview）
> HTML 文本排版标签分为**块级元素**（独占一行，可设宽高）和**行内元素**（不独占一行，宽度由内容撑开）。`<a>` 标签作为超链接，是 Web 最核心的"连接"机制——它将分散在全球的文档编织成了万维网。

## 设计初衷（Motivation）

### 历史演进
- **前身技术**：早期 HTML 混用 `<font>`、`<center>` 等样式标签控制文本外观。样式和结构深度耦合，修改一个页面的字体颜色需要逐个标签查找替换。
- **为什么前身被淘汰**：表现与结构不分，维护噩梦。HTML 4.01 开始废弃纯样式标签，CSS 接管表现层。
- **本技术的核心突破**：HTML5 清理了语义体系，`<strong>` 代表"重要"（语义），`<b>` 仅代表"加粗"（样式）；`<em>` 代表"强调"（语义），`<i>` 仅代表"斜体"（样式）。`<a>` 增加了 `download` 属性，支持纯前端文件下载。
- **为什么是它活下来了**：语义化标签让屏幕阅读器能以不同语调朗读 `<strong>` 和 `<em>`，搜索引擎给 `<h1>` 中的内容更高权重。
- **当前版本**：HTML5 Living Standard

> ⚠️ **版本兼容性**：`<u>` 在 HTML4 中被废弃，HTML5 重新赋予语义"拼写错误标记"——不再是纯样式下划线。纯样式下划线请用 CSS `text-decoration: underline`。

## 实现（Implementation）

### 块级元素速查

| 标签 | 用途 | 关键点 |
|------|------|--------|
| `<h1>`-`<h6>` | 标题，h1 级别最高 | 页面通常只有一个 h1 |
| `<p>` | 段落 | 段落间有默认间距 |
| `<div>` | 无语义块级容器 | 最常用的布局标签 |
| `<hr>` | 水平分割线 | 表示主题转换 |
| `<blockquote>` | 块级引用 | 带 cite 属性指明来源 URL |
| `<address>` | 作者/拥有者联系信息 | 通常斜体显示 |
| `<pre>` | 预格式化文本 | 保留空格和换行符 |

### 行内元素速查

| 标签 | 语义 | 默认样式 |
|------|------|---------|
| `<span>` | 无语义行内容器 | 无 |
| `<strong>` | **重要文本**（语义强调） | 加粗 |
| `<b>` | 仅视觉加粗（无语义） | 加粗 |
| `<em>` | *强调文本*（语义强调） | 斜体 |
| `<i>` | 仅视觉斜体（无语义） | 斜体 |
| `<mark>` | 高亮/突出显示 | 黄色背景 |
| `<q>` | 短的行内引用 | 自动加引号 |
| `<code>` | 计算机代码片段 | 等宽字体 |
| `<kbd>` | 键盘输入 | 等宽字体 |
| `<sup>` / `<sub>` | 上标 / 下标 | 缩小上移/下移 |
| `<small>` | 附注、小号文本 | 小号字 |
| `<s>` | 删除线（不再准确的文本） | 删除线 |
| `<time>` | 机器可读时间日期 | 无 |
| `<abbr>` | 缩写词（title 给出全称） | 虚线下划线 |

### 完整实例：`<a>` 标签的四种用法

```html
<!-- ① 普通链接：target="_blank" 在新标签页打开，增加 rel="noopener noreferrer" 防钓鱼 -->
<a href="https://google.com" target="_blank" rel="noopener noreferrer">访问 Google</a>

<!-- ② 锚点链接：跳转到同一页面中 id="section1" 的元素位置 -->
<a href="#section1">跳到第一节</a>

<!-- ③ 协议链接：mailto 调用邮件客户端，tel 调用拨号（移动端） -->
<a href="mailto:test@example.com">发邮件</a>
<a href="tel:+123456789">打电话</a>

<!-- ④ 下载链接：download 属性强制浏览器下载而非导航 -->
<a href="document.pdf" download="我的文档.pdf">下载 PDF</a>
```

> **💡 补充**：`target="_blank"` 打开的新页面可以通过 `window.opener` 访问原页面。安全实践：始终配合 `rel="noopener noreferrer"` 使用，防止钓鱼攻击（Tabnabbing）。

### `<a>` 核心属性

| 属性 | 说明 |
|------|------|
| `href` | 目标 URL（绝对路径 / 相对路径 / 锚点 `#id` / 协议 `mailto:` `tel:`） |
| `target` | `_self`（当前窗口）、`_blank`（新窗口）、`_parent`/`_top`（iframe 中） |
| `download` | HTML5 新增，强制下载，可指定文件名 |
