# HTML5 多媒体与嵌入技术

## 📍 知识体系定位
- **所属技术栈**：前端 Vue 3
- **所在层级**：L0 三件套 → HTML5 → 多媒体嵌入
- **上游依赖**：<a href="obsidian://open?file=基础语法与文档结构">HTML5-基础语法与文档结构</a>、<a href="obsidian://open?file=语义化结构标签">HTML5-语义化结构标签</a>
- **下游延伸**：Canvas API（JavaScript 2D/3D 绘图）、WebGL、Web Audio API
- **同级技术**：CSS3 动画（`@keyframes`）、SVG 动画（`<animate>`）

## 概述（Overview）
> HTML5 提供了原生的图像（`<img>`/`<picture>`）、音频（`<audio>`）、视频（`<video>`）、画布（`<canvas>`）和矢量图（`<svg>`）标签，使浏览器无需 Flash 等第三方插件即可处理多媒体内容。

## 设计初衷（Motivation）

### 历史演进
- **前身技术**：HTML 4 时代，网页多媒体几乎完全依赖 Adobe Flash 插件。`<embed>` 和 `<object>` 标签用于嵌入 Flash 内容。
- **为什么前身被淘汰**：Flash 是封闭私有技术，性能差、耗电高、安全漏洞频发。2010 年 Steve Jobs 发表《Thoughts on Flash》公开信后，行业加速抛弃 Flash。
- **本技术的核心突破**：HTML5 将音视频播放能力直接内置到浏览器中。`<video>` 和 `<audio>` 标签只需几行代码即可播放媒体，`<canvas>` 提供了像素级绘图能力。
- **为什么是它活下来了**：开放标准、无需插件、跨平台（桌面/移动端浏览器原生支持）、更安全（浏览器沙箱隔离）。
- **当前版本**：HTML5 Living Standard

> ⚠️ **版本兼容性**：不同浏览器支持的音视频编码格式不同。MP4（H.264）和 MP3 兼容性最好，WebM 和 OGG 作为开放格式备选。使用多个 `<source>` 提供格式回退。

### 跨学科溯源
- `<canvas>` 像素绘图 → <a href="obsidian://open?file=XD-4 编程语言与编译">XD-4 编程语言与编译</a>（JavaScript 引擎的即时编译 JIT 优化绘图指令）→ <a href="obsidian://open?file=XD-1 数字系统与体系结构">XD-1 数字系统与体系结构</a>（GPU 图形管线：顶点着色器 → 光栅化 → 片段着色器）
- `<video>` 编解码 → <a href="obsidian://open?file=XD-7 数据与智能">XD-7 数据与智能</a>（H.264/H.265 视频压缩算法：帧内预测 + 运动补偿 + 熵编码）

## 实现（Implementation）

### 1. 图像：`<img>` 与响应式 `<picture>`

```html
<!-- ① img 基础用法：src 必填，alt 必填（SEO + 无障碍） -->
<img src="photo.jpg" alt="一只在草地上奔跑的金毛犬" loading="lazy" width="800" height="600">

<!-- ② picture：按屏幕宽度或格式支持提供不同图片源 -->
<picture>
    <!-- 屏幕宽度 >= 800px 时加载大图 -->
    <source media="(min-width: 800px)" srcset="large.jpg">
    <!-- 屏幕宽度 >= 400px 时加载中图 -->
    <source media="(min-width: 400px)" srcset="medium.jpg">
    <!-- 后备：不匹配任何 source 条件或浏览器不支持 picture 时使用 -->
    <img src="small.jpg" alt="响应式图片示例">
</picture>
```

### 2. 音频：`<audio>`

```html
<!-- ① controls 显示播放控件，loop 循环，muted 静音（多数浏览器要求自动播放必须静音） -->
<audio controls loop muted>
    <!-- ② 多个 source：浏览器按顺序尝试，选择第一个支持的格式 -->
    <source src="music.mp3" type="audio/mpeg">
    <source src="music.ogg" type="audio/ogg">
    <!-- ③ 后备内容：浏览器不支持 audio 标签时显示 -->
    您的浏览器不支持 audio 标签。
</audio>
```

### 3. 视频：`<video>`

```html
<!-- ① poster 指定封面图，preload="metadata" 仅预加载元数据节省带宽 -->
<video controls width="600" poster="cover.jpg" preload="metadata">
    <source src="video.mp4" type="video/mp4">
    <source src="video.webm" type="video/webm">
    <!-- ② track：加载字幕文件（VTT 格式），kind="subtitles" 表示字幕 -->
    <track src="subtitles_zh.vtt" kind="subtitles" srclang="zh" label="中文">
    您的浏览器不支持 video 标签。
</video>
```

### 4. 画布与矢量图：`<canvas>` 与 `<svg>`

```html
<!-- canvas：像素级画布，必须通过 JavaScript Canvas API 绘制 -->
<canvas id="myCanvas" width="200" height="100"></canvas>

<!-- svg：矢量图形，XML 描述，放大不失真，可直接内嵌或通过 <img> 引用 -->
<svg width="100" height="100">
    <circle cx="50" cy="50" r="40" fill="red" />
</svg>
```

> **💡 补充**：Canvas vs SVG 选择原则：Canvas 适合像素密集型操作（游戏、图像处理、实时图表），SVG 适合需要缩放和交互的图形（图标、数据可视化、地图）。

### 核心属性速查

| 标签 | 关键属性 |
|------|---------|
| `<img>` | `src`（必填）、`alt`（必填）、`loading="lazy"`（懒加载）、`width`/`height` |
| `<picture>` | 内含 `<source media="..." srcset="...">` + 后备 `<img>` |
| `<audio>` | `controls`、`autoplay`（需配合 `muted`）、`loop`、`muted`、`preload` |
| `<video>` | 同 audio + `poster`（封面图）、`width`/`height` |
| `<track>` | `src`（VTT 文件）、`kind`（subtitles/captions/descriptions）、`srclang`、`label` |
| `<iframe>` | `src`（嵌入 URL）、`allowfullscreen`（允许全屏）、`sandbox`（安全限制） |
