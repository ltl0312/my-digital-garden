# HTML5 交互组件与全局属性

## 📍 知识体系定位
- **所属技术栈**：前端 Vue 3
- **所在层级**：L0 三件套 → HTML5 → 交互组件与全局属性
- **上游依赖**：<a href="obsidian://open?file=基础语法与文档结构">HTML5-基础语法与文档结构</a>、<a href="obsidian://open?file=语义化结构标签">HTML5-语义化结构标签</a>
- **下游延伸**：JavaScript DOM 操作（`dataset` API、`showModal()`）、Vue 3 自定义指令
- **同级技术**：CSS `display: none`（对比 `hidden` 属性）、JavaScript 模态框库

## 概述（Overview）
> HTML5 提供了无需 JavaScript 即可工作的原生交互组件（`<details>`/`<summary>` 折叠面板、`<dialog>` 模态弹窗），以及一组可应用于几乎所有元素的全局属性（`id`、`class`、`data-*`、`hidden`、`contenteditable` 等），构成了 HTML 元素的通用控制面。

## 设计初衷（Motivation）

### 设计思想
HTML5 的交互组件和全局属性体现了"平台能力下放"的哲学——将原本需要 JavaScript 才能实现的基础 UI 模式（折叠面板、模态弹窗、自定义数据存储）直接内置到 HTML 标准中。这意味着：
- 屏幕阅读器原生理解 `<details>` 的展开/收起状态
- `<dialog>` 自动处理焦点陷阱和背景遮罩（无需手写无障碍代码）
- `data-*` 属性结束了开发者滥用 `rel`、`class` 存储数据的历史

### 跨学科溯源
- `data-*` 属性 → <a href="obsidian://open?file=XD-6 软件工程与架构">XD-6 软件工程与架构</a>（关注点分离：HTML 存数据，JS 取数据，数据与行为分离）
- `<dialog>` 模态框 → <a href="obsidian://open?file=XD-2 操作系统">XD-2 操作系统</a>（焦点管理类似于操作系统的窗口 z-order 和模态对话框机制）

## 实现（Implementation）

### 1. 折叠面板：`<details>` + `<summary>`

```html
<!-- ① details：可折叠容器，open 属性使默认展开 -->
<details>
    <!-- ② summary：可见的点击标题，必须是 details 的第一个子元素 -->
    <summary>点击查看详细说明</summary>
    <!-- ③ 隐藏内容：点击 summary 后展开/收起，无需一行 JS -->
    <p>这里是隐藏的详细内容，点击上方标题后可见。</p>
</details>

<!-- 默认展开状态 -->
<details open>
    <summary>默认展开的章节</summary>
    <p>这个内容页面加载时就可见。</p>
</details>
```

### 2. 模态弹窗：`<dialog>`

```html
<!-- ① dialog 标签定义弹窗，初始隐藏 -->
<dialog id="myDialog">
    <p>这是一个原生的弹窗！无需引入第三方库。</p>
    <!-- ② method="dialog" 的 form：提交后自动关闭弹窗 -->
    <form method="dialog">
        <button>关闭</button>
    </form>
</dialog>

<!-- JavaScript 控制：showModal() 打开（带背景遮罩），close() 关闭 -->
<script>
    const dialog = document.getElementById('myDialog');
    // dialog.showModal();  // 打开弹窗
    // dialog.close();      // 关闭弹窗
</script>
```

> **💡 补充**：`<dialog>` 的 `showModal()` 方法自动处理：① 背景遮罩（`::backdrop` 伪元素可样式化）；② 焦点锁定在弹窗内（Tab 不会跳出）；③ ESC 键关闭。这些在传统 JavaScript 弹窗中需要手动实现。

### 3. 全局属性速查表

| 属性 | 用途 | 示例 |
|------|------|------|
| `id` | 元素唯一标识符 | `<div id="app">` |
| `class` | 元素类名（可重复，空格分隔多个） | `<div class="btn btn-primary active">` |
| `style` | 行内 CSS 样式（优先级最高） | `<p style="color: red">` |
| `title` | 鼠标悬停时的工具提示 | `<abbr title="World Wide Web">WWW</abbr>` |
| `data-*` | 自定义私有数据（JS 通过 `dataset` 读取） | `<div data-user-id="123" data-role="admin">` |
| `hidden` | 隐藏元素（等同 `display: none`） | `<div hidden>` |
| `tabindex` | Tab 键导航顺序，`-1` 表示不参与 | `<div tabindex="0">` |
| `contenteditable` | 元素可编辑（富文本编辑器基础） | `<div contenteditable="true">` |
| `draggable` | 元素可拖动（配合拖放 API） | `<div draggable="true">` |
| `spellcheck` | 拼写检查开关 | `<textarea spellcheck="true">` |
| `lang` | 元素内容语言 | `<p lang="en">Hello</p>` |
| `dir` | 文本方向（`ltr`/`rtl`） | `<p dir="rtl">مرحبا</p>` |

### 4. `data-*` 自定义属性详解

```html
<!-- ① 在 HTML 中存储任意数据，不会影响渲染 -->
<div id="user-card"
     data-user-id="123"
     data-role="admin"
     data-last-login="2026-06-16">

<!-- ② JavaScript 通过 dataset API 读取（连字符转驼峰） -->
<script>
    const card = document.getElementById('user-card');
    console.log(card.dataset.userId);      // "123"
    console.log(card.dataset.role);         // "admin"
    console.log(card.dataset.lastLogin);    // "2026-06-16"

    // ③ 也可以写入
    card.dataset.status = 'active';
</script>
```

### 5. 已废弃标签（避免使用）

HTML5 废弃了纯样式标签，以下标签请使用 CSS 替代：

| 废弃标签 | CSS 替代方案 |
|----------|-------------|
| `<font>` | `font-family`、`font-size`、`color` |
| `<center>` | `text-align: center`、`margin: 0 auto` |
| `<big>` | `font-size: larger` |
| `<strike>` | `text-decoration: line-through` |
| `<tt>` | `font-family: monospace` |
| `<frame>` / `<frameset>` | `<iframe>` |
| `<marquee>` | CSS `@keyframes` 动画 |

> **💡 补充**：`<u>` 标签在 HTML5 中被重新赋予语义——"拼写错误的单词或中文专有名词"的下划线。如果需要纯样式下划线，请使用 CSS `text-decoration: underline`。不要在非链接文本上使用下划线（用户会误以为是可以点击的链接）。
