# HTML5 基础语法与文档结构

## 📍 知识体系定位

- **所在层级**：L0 三件套 → HTML5
- **上游依赖**：无（前端学习的起点）

- **同级技术**：CSS3（样式）、JavaScript ES6+（行为逻辑）

## 概述（Overview）
> HTML5 的文档声明、字符编码和基本语法规则构成了网页的"骨架约定"——告诉浏览器如何解析文档、使用哪种字符集、以及遵循什么语法规则。这是所有 HTML 页面的起点。

## 设计初衷（Motivation）

### 历史演进
- **前身技术**：HTML 4.01 时代，DOCTYPE 声明冗长且需要区分 Strict/Transitional/Frameset 三种 DTD。
- **为什么前身被淘汰**：旧式 DOCTYPE 声明极其冗长（如 `<!DOCTYPE HTML PUBLIC "-//W3C//DTD HTML 4.01 Transitional//EN" "http://www.w3.org/TR/html4/loose.dtd">`），开发者几乎不可能记住，只能复制粘贴。
- **本技术的核心突破**：HTML5 将 DOCTYPE 简化为 `<!DOCTYPE html>`，15 个字符，且大小写不敏感。
- **为什么是它活下来了**：HTML5 的极简 DOCTYPE 被所有现代浏览器原生支持，触发了标准模式渲染，彻底终结了"怪异模式（Quirks Mode）"的混乱时代。
- **当前版本**：HTML5（Living Standard，由 WHATWG 维护）

> ⚠️ **版本兼容性**：HTML5 向后兼容 HTML 4.01 和 XHTML 1.x。`<br>`、`<br/>`、`<br />` 均合法，但推荐使用简洁写法。跨学科的知识引用不受此限。

### 设计思想
HTML5 的文档结构设计遵循"约定优于配置"的思想：用最短的声明表达最明确的意图。`<!DOCTYPE html>` 没有版本号——因为 HTML 不再有版本号，它是一个持续演进的"活标准（Living Standard）"。这体现了 Web 平台"永不破坏向后兼容性"的核心哲学。

## 实现（Implementation）

### 完整实例：一个标准的 HTML5 空白页面模板
> 这是每个前端项目的最初始文件。**每一行都有明确含义。**

```html
<!-- ① 文档类型声明：告诉浏览器"我是 HTML5 文档，请用标准模式渲染" -->
<!DOCTYPE html>
<!-- ② 根元素：lang="zh-CN" 告知搜索引擎和屏幕阅读器页面主要语言为简体中文 -->
<html lang="zh-CN">
<head>
    <!-- ③ 字符集声明：UTF-8 覆盖全球所有字符，避免乱码，必须放在 head 最前面 -->
    <meta charset="UTF-8">
    <!-- ④ 视口设置：移动端适配的关键，width=device-width 让页面宽度跟随设备宽度 -->
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <!-- ⑤ 网页标题：显示在浏览器标签页上，对 SEO 至关重要 -->
    <title>网页标题</title>
</head>
<body>
    <!-- ⑥ 主体内容：所有用户可见的内容都写在这里 -->
</body>
</html>
```

> **💡 补充**：以上标准模板是每个 HTML 页面的最小骨架。实际开发中还会在 `<head>` 中添加 `<meta name="description">`（SEO 描述）、`<link rel="stylesheet">`（引入 CSS）、`<script src="...">`（引入 JS）等。

### 基本语法规则速查

| 规则 | 说明 |
|------|------|
| 标签闭合 | 大多数标签成对出现 `<div></div>`；单标签可不闭合 `<img src="">` |
| 大小写 | HTML5 不区分大小写，但**强烈建议全部小写** |
| 属性值引号 | 可用双引号/单引号/不加引号，但**强烈建议双引号** |
| 注释 | `<!-- 注释内容 -->`，不在浏览器中显示 |
