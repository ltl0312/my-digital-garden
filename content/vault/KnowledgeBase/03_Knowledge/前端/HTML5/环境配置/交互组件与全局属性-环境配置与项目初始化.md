## Step 2: 最小可运行示例

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>交互组件与全局属性</title>
    <style>
        /* dialog 背景遮罩样式 */
        dialog::backdrop {
            background: rgba(0, 0, 0, 0.5);
        }
        dialog {
            border: none;
            border-radius: 8px;
            padding: 2rem;
            box-shadow: 0 4px 20px rgba(0,0,0,0.3);
        }
    </style>
</head>
<body>

    <!-- ① 折叠面板：零 JS 实现 -->
    <details>
        <summary><strong>点击展开 —— HTML5 原生折叠面板</strong></summary>
        <p>这是隐藏的详细内容。完全不需要 JavaScript！</p>
        <p>屏幕阅读器可以正确播报展开/收起状态。</p>
    </details>

    <hr>

    <!-- ② 弹窗触发器 -->
    <button onclick="document.getElementById('myDialog').showModal()">
        打开原生弹窗
    </button>

    <!-- ③ 原生模态弹窗 -->
    <dialog id="myDialog">
        <h2>原生 HTML 弹窗</h2>
        <p>不需要引入任何第三方库！</p>
        <p>✅ 自动背景遮罩（::backdrop）</p>
        <p>✅ 自动焦点锁定（Tab 不会跳出）</p>
        <p>✅ ESC 键关闭</p>
        <form method="dialog">
            <button type="submit">关闭弹窗</button>
        </form>
    </dialog>

    <hr>

    <!-- ④ contenteditable 可编辑区域 -->
    <h3>可编辑区域 (contenteditable)</h3>
    <div contenteditable="true"
         style="border: 2px dashed #ccc; padding: 1rem; min-height: 60px; border-radius: 4px;"
         spellcheck="true">
        点击这里直接编辑文字...
    </div>

    <hr>

    <!-- ⑤ data-* 自定义属性 -->
    <h3>data-* 自定义数据属性</h3>
    <div id="user-card"
         data-user-id="12345"
         data-role="admin"
         data-join-date="2026-01-15"
         style="background: #f0f0f0; padding: 1rem; border-radius: 4px;">
        用户信息卡片（查看 Console 读取 data 属性）
    </div>

    <script>
        // 读取 data-* 属性
        const card = document.getElementById('user-card');
        console.log('用户ID:', card.dataset.userId);
        console.log('角色:', card.dataset.role);
        console.log('加入日期:', card.dataset.joinDate);
    </script>
</body>
</html>
```

## Step 3: 核心配置项

| 功能 | 推荐方案 | 原因 |
|------|---------|------|
| 弹窗 | `<dialog>` + `showModal()` | 原生焦点管理、ESC 关闭、背景遮罩 |
| 折叠面板 | `<details>` + `<summary>` | 零 JS，原生无障碍支持 |
| 自定义数据 | `data-*` 属性 + `dataset` API | 避免滥用 class/rel 存储数据 |
| 隐藏元素（临时） | `hidden` 属性 | 无需写 CSS `display: none` |
| 隐藏元素（动画过渡） | CSS `opacity` / `visibility` | hidden 无法做过渡动画 |

## 常见问题

1. **`<dialog>` 不显示**：必须通过 JS 的 `.showModal()` 或 `.show()` 打开，`<dialog>` 标签默认是隐藏的。`showModal()` 显示为模态弹窗（带遮罩），`show()` 显示为非模态。
2. **`contenteditable` 粘贴带格式**：从 Word/网页粘贴会带入富文本格式。使用 `document.execCommand('pasteText')` 或监听 paste 事件清除格式。
3. **`data-*` 命名问题**：HTML 中 `data-user-id` → JS 中 `dataset.userId`（连字符转驼峰）。大写字母在 HTML 属性中不合法（会被转为小写）。
