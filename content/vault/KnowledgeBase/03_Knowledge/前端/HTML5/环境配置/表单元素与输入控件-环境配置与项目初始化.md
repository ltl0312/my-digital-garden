# HTML5 表单元素 — 环境配置与项目初始化

## Step 1: 推荐开发工具

- **Chrome DevTools Network 面板**：`F12` → Network → 勾选 Preserve log，查看表单提交的请求详情
- **Formik DevTools**（进阶）：React 表单开发调试工具

## Step 2: 验证 HTML5 原生验证

创建 `form-test.html`：
```html
<form action="/submit" method="POST">
    <input type="email" required>
    <button type="submit">提交</button>
</form>
```
不填内容直接提交 → 浏览器应弹出"请填写此字段"提示。填入 `abc`（非邮箱格式）→ 应弹出"请包含 @"提示。

## Step 3: 最小可运行示例 — 完整表单页面

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>用户注册</title>
    <style>
        form { max-width: 480px; margin: 2rem auto; }
        .form-group { margin-bottom: 1rem; }
        label { display: block; margin-bottom: 0.25rem; font-weight: bold; }
        input, select, textarea { width: 100%; padding: 0.5rem; border: 1px solid #ccc; border-radius: 4px; }
        input:invalid { border-color: #e74c3c; }
        input:valid { border-color: #2ecc71; }
        button { padding: 0.5rem 1.5rem; border: none; border-radius: 4px; cursor: pointer; }
        button[type="submit"] { background: #3498db; color: #fff; }
        button[type="reset"] { background: #eee; margin-left: 0.5rem; }
    </style>
</head>
<body>
    <form action="/api/register" method="POST">
        <h2>用户注册</h2>

        <div class="form-group">
            <label for="email">邮箱</label>
            <input type="email" id="email" name="email"
                   required placeholder="you@example.com">
        </div>

        <div class="form-group">
            <label for="username">用户名</label>
            <input type="text" id="username" name="username"
                   required minlength="3" maxlength="20"
                   placeholder="3-20个字符">
        </div>

        <div class="form-group">
            <label for="password">密码</label>
            <input type="password" id="password" name="password"
                   required minlength="8"
                   pattern="^(?=.*[A-Za-z])(?=.*\d)[A-Za-z\d]{8,}$"
                   placeholder="至少8位，含字母和数字">
        </div>

        <div class="form-group">
            <label for="birthday">出生日期</label>
            <input type="date" id="birthday" name="birthday">
        </div>

        <div class="form-group">
            <label for="level">经验等级</label>
            <input type="range" id="level" name="level"
                   min="1" max="10" step="1" value="5"
                   oninput="this.nextElementSibling.textContent = this.value">
            <span>5</span>/10
        </div>

        <div class="form-group">
            <button type="submit">注册</button>
            <button type="reset">重置</button>
        </div>
    </form>
</body>
</html>
```

## Step 4: 常见表单验证属性

| 属性 | 适用类型 | 示例 |
|------|---------|------|
| `required` | 几乎所有 | 字段不得为空 |
| `minlength` / `maxlength` | text, password, textarea | `minlength="6"` |
| `min` / `max` | number, range, date | `min="0" max="100"` |
| `step` | number, range | `step="0.1"` |
| `pattern` | text, password, email | `pattern="[A-Za-z]{3,}"` |
| `multiple` | email, file | 允许多选/多文件 |

## 常见问题

1. **表单验证不触发**：检查 `<form>` 上没有 `novalidate` 属性，该属性禁用原生验证。
2. **移动端键盘类型不对**：`<input type="number">` 弹出数字键盘，`type="tel"` 弹出拨号键盘。选择正确的 type 提升移动端体验。
3. **`pattern` 正则不生效**：`pattern` 属性不需要 `/ /` 分隔符，直接写正则表达式内容。例如 `pattern="[0-9]{6}"` 而非 `pattern="/[0-9]{6}/"`。
4. **中文输入法触发验证**：使用 `pattern` 时输入法组合文字（composition）可能意外触发验证。解决方案：配合 JS 监听 `compositionend` 事件延迟验证。
