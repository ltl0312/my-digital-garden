# HTML5 基础语法 — 环境配置与项目初始化

## 信息来源
- **官方文档**：https://developer.mozilla.org/zh-CN/docs/Web/HTML（✅ 可访问）
- **参考文章**：VS Code HTML 官方文档：https://code.visualstudio.com/docs/languages/html

## 前置条件
- 操作系统：Windows / macOS / Linux
- 文本编辑器：推荐 VS Code

## Step 1: 安装 VS Code

- **Windows**：从 https://code.visualstudio.com/ 下载安装包，双击安装
- **macOS**：下载 `.dmg` 文件，拖入 Applications
- **Linux**：`sudo snap install code --classic` 或使用包管理器

## Step 2: 安装推荐扩展

在 VS Code 中按 `Ctrl+Shift+X` 打开扩展面板，搜索安装：
- **Live Server**（ritwickdey.liveserver）：一键启动本地开发服务器，保存即刷新
- **Prettier**：代码格式化
- **HTML CSS Support**：HTML 中 class 属性的 CSS 智能提示

## Step 3: 验证安装

1. 打开 VS Code，新建文件 `test.html`
2. 输入 `!` 然后按 `Tab` 键（Emmet 缩写展开为完整 HTML5 模板）
3. 确认生成如下结构：
```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Document</title>
</head>
<body>
</body>
</html>
```

## Step 4: 创建第一个 HTML 项目

```bash
# 在终端中操作
mkdir my-html-project
cd my-html-project
code .
```

在 VS Code 中创建 `index.html`，输入以下内容：
```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>我的第一个 HTML 页面</title>
</head>
<body>
    <h1>Hello, HTML5!</h1>
    <p>HTML5 文档结构配置成功。</p>
</body>
</html>
```

右键文件 → **Open with Live Server**，浏览器自动打开并显示页面。修改 `<h1>` 内容并保存，浏览器自动刷新。

## Step 5: 核心配置项说明

| 配置项 | 默认值 | 推荐值 | 原因 |
|--------|--------|--------|------|
| `lang` 属性 | 无 | `zh-CN` | SEO + 屏幕阅读器语言识别 |
| `<meta charset>` | 浏览器推测 | `UTF-8` | 避免中文乱码 |
| `<meta viewport>` | 无（桌面端默认 980px） | `width=device-width, initial-scale=1.0` | 移动端适配必设 |
| Emmet 触发键 | `Tab` | `Tab` | 输入 `!` + Tab 生成 HTML5 骨架 |

## 常见安装/配置问题

1. **Emmet 输入 `!` 不展开**：检查 VS Code 右下角文件语言模式是否为 `HTML`（而非 Plain Text）。
2. **中文乱码**：确认 `<meta charset="UTF-8">` 在 `<head>` 最前面，且文件本身保存为 UTF-8 编码（VS Code 右下角状态栏查看）。
3. **Live Server 端口冲突**：默认 5500 端口被占用 → VS Code 设置搜索 `liveServer.settings.port`，改为其他端口（如 5501）。
