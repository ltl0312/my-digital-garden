## Step 2: 验证浏览器媒体支持

打开 Chrome DevTools Console，执行：
```javascript
// 检测浏览器支持的音视频格式
const video = document.createElement('video');
console.log('MP4支持:', video.canPlayType('video/mp4'));       // "probably" 或 "maybe"
console.log('WebM支持:', video.canPlayType('video/webm'));
console.log('OGG支持:', video.canPlayType('video/ogg'));

const audio = document.createElement('audio');
console.log('MP3支持:', audio.canPlayType('audio/mpeg'));
console.log('OGG音频支持:', audio.canPlayType('audio/ogg'));
```

## Step 3: 最小可运行示例 — 完整多媒体页面

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>多媒体示例</title>
</head>
<body>
    <h1>HTML5 多媒体测试</h1>

    <!-- 响应式图片 -->
    <h2>1. 响应式图片 (picture)</h2>
    <picture>
        <source media="(min-width: 800px)" srcset="large.jpg">
        <img src="small.jpg" alt="示例图片" style="max-width:100%">
    </picture>

    <!-- 音频播放器 -->
    <h2>2. 音频播放器</h2>
    <audio controls>
        <source src="sample.mp3" type="audio/mpeg">
        浏览器不支持音频播放。
    </audio>

    <!-- 视频播放器 -->
    <h2>3. 视频播放器</h2>
    <video controls width="640" poster="cover.jpg">
        <source src="sample.mp4" type="video/mp4">
        浏览器不支持视频播放。
    </video>

    <!-- Canvas 画布 -->
    <h2>4. Canvas 画布</h2>
    <canvas id="myCanvas" width="400" height="200"
            style="border:1px solid #ccc;"></canvas>
    <script>
        const canvas = document.getElementById('myCanvas');
        const ctx = canvas.getContext('2d');
        ctx.fillStyle = '#4CAF50';
        ctx.fillRect(50, 50, 300, 100);
        ctx.fillStyle = '#fff';
        ctx.font = '24px sans-serif';
        ctx.fillText('Canvas 绘制成功!', 80, 110);
    </script>
</body>
</html>
```

## Step 4: 媒体格式兼容性速查

| 格式 | 类型 | Chrome | Firefox | Safari | Edge |
|------|------|--------|---------|--------|------|
| MP4 (H.264) | 视频 | ✅ | ✅ | ✅ | ✅ |
| WebM (VP8/VP9) | 视频 | ✅ | ✅ | ❌ | ✅ |
| OGG (Theora) | 视频 | ✅ | ✅ | ❌ | ✅ |
| MP3 | 音频 | ✅ | ✅ | ✅ | ✅ |
| OGG (Vorbis) | 音频 | ✅ | ✅ | ❌ | ✅ |
| WAV | 音频 | ✅ | ✅ | ✅ | ✅ |

> 最佳实践：视频提供 MP4 + WebM 双格式，音频提供 MP3 + OGG 双格式，确保跨浏览器兼容。

## 常见问题

1. **视频不自动播放**：现代浏览器禁止有声自动播放。解决方案：加 `muted` 属性允许静音自动播放；或用户首次交互后再触发播放。
2. **Canvas 内容不显示**：确认 JS 代码在 canvas 元素之后执行，或放在 `DOMContentLoaded` 事件中。检查 `getContext('2d')` 是否正确调用。
3. **iframe 嵌入被拒绝**：目标网站设置了 `X-Frame-Options: DENY` 或 CSP `frame-ancestors` 限制，无法通过 iframe 嵌入（如 google.com）。
