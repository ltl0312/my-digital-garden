# HTML 列表与表格 — 环境配置与项目初始化

## 信息来源
- **官方文档**：https://developer.mozilla.org/zh-CN/docs/Learn/HTML/Tables（✅ 可访问）

## 前置条件
- VS Code + Live Server（参考 <a href="obsidian://open?file=基础语法-环境配置与项目初始化">HTML5-基础语法-环境配置与项目初始化</a>）

## Step 1: 推荐工具

- **Chrome DevTools Elements 面板**：右键表格 → 检查，查看浏览器自动生成的 `<tbody>` 包裹层
- **Emmet 缩写**：`table>thead>tr>th*3^^tbody>tr*5>td*3` 快速生成 3 列表格

## Step 2: 验证

```html
<table>
    <caption>测试表</caption>
    <tr><th>列1</th><th>列2</th></tr>
    <tr><td>A</td><td>B</td></tr>
</table>
```
用 W3C 验证器（https://validator.w3.org/）检查，确认无错误。

## Step 3: 最小可运行示例 — 数据表格

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
    <meta charset="UTF-8">
    <title>表格示例</title>
    <style>
        table { border-collapse: collapse; width: 100%; }
        th, td { border: 1px solid #ddd; padding: 8px; text-align: left; }
        thead { background: #f5f5f5; }
        tbody tr:hover { background: #f0f8ff; }
        caption { caption-side: top; font-weight: bold; margin-bottom: 8px; }
    </style>
</head>
<body>
    <table>
        <caption>2026年销售报表</caption>
        <thead>
            <tr>
                <th scope="col">月份</th>
                <th scope="col">销售额 (万元)</th>
                <th scope="col">同比增长</th>
            </tr>
        </thead>
        <tbody>
            <tr><td>一月</td><td>50</td><td>+12%</td></tr>
            <tr><td>二月</td><td>60</td><td>+20%</td></tr>
            <tr><td>三月</td><td>55</td><td>+15%</td></tr>
        </tbody>
        <tfoot>
            <tr>
                <th scope="row">合计</th>
                <td>165</td>
                <td>—</td>
            </tr>
        </tfoot>
    </table>
</body>
</html>
```

## Step 4: 核心 CSS 配置

| CSS 属性 | 推荐值 | 原因 |
|----------|--------|------|
| `border-collapse` | `collapse` | 合并相邻单元格边框，避免双线 |
| `th` `text-align` | `left`（数值列可设 `right`） | 表头左对齐符合中文阅读习惯 |
| `td, th` `padding` | `8px` 以上 | 保证单元格内容不拥挤 |
| `tr:hover` `background` | 浅色背景 | 鼠标悬停行高亮，大表格必备 |

## 常见问题

1. **表格边框双线**：忘记设置 `border-collapse: collapse` → 相邻单元格边框会出现双线效果。
2. **DevTools 中多了 `<tbody>`**：浏览器会自动在 `<table>` 内的 `<tr>` 外层包裹 `<tbody>`，这是正常行为，手动写在 HTML 中更规范。
3. **表格移动端溢出**：宽表格在小屏幕上横向溢出 → 外层加 `<div style="overflow-x: auto">` 包裹表格，启用横向滚动。
