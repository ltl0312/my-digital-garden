# HTML5 语义化结构标签 — 环境配置与项目初始化

## 信息来源
- **官方文档**：https://developer.mozilla.org/zh-CN/docs/Web/HTML/Element（✅ 可访问）
- **W3C HTML 验证器**：https://validator.w3.org/（✅ 可访问）

## 前置条件
- VS Code 已安装（参考 <a href="obsidian://open?file=基础语法-环境配置与项目初始化">HTML5-基础语法-环境配置与项目初始化</a>）
- 了解 HTML5 文档骨架结构

## Step 1: 安装语义检查工具

推荐安装 VS Code 扩展：
- **HTMLHint**：静态分析 HTML 代码，检测语义错误
- **axe Accessibility Linter**：检查无障碍访问问题

## Step 2: 验证安装

创建测试文件 `semantic-test.html`：
```html
<!DOCTYPE html>
<html lang="zh-CN">
<head><meta charset="UTF-8"><title>语义测试</title></head>
<body>
    <main>
        <article>
            <h1>测试文章</h1>
        </article>
    </main>
</body>
</html>
```
用 W3C 验证器（https://validator.w3.org/#validate_by_input）检查无错误。

## Step 3: HTML5 语义标签项目模板

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>语义化页面模板</title>
    <style>
        /* 基础布局样式 */
        body { font-family: sans-serif; margin: 0; }
        header, footer { background: #333; color: #fff; padding: 1rem; }
        main { max-width: 800px; margin: 0 auto; padding: 1rem; }
        nav a { color: #fff; margin-right: 1rem; }
    </style>
</head>
<body>
    <header>
        <h1>网站名称</h1>
        <nav>
            <a href="/">首页</a>
            <a href="/about">关于</a>
        </nav>
    </header>
    <main>
        <article>
            <h2>文章标题</h2>
            <p>文章内容...</p>
        </article>
        <aside>
            <h3>侧边栏</h3>
        </aside>
    </main>
    <footer>
        <p>&copy; 2026 My Site</p>
    </footer>
</body>
</html>
```

## Step 4: 核心检查项

| 检查项 | 工具 | 说明 |
|--------|------|------|
| HTML 语法正确性 | W3C Validator | 在线验证或 VS Code HTMLHint 扩展 |
| 语义结构完整性 | 手动检查 | 确保有 header/nav/main/footer 结构 |
| 无障碍访问 | axe DevTools | 浏览器扩展，检测 ARIA 和语义问题 |
| 移动端响应式 | Chrome DevTools | `Ctrl+Shift+M` 切换设备模拟 |

## Step 5: 核心配置项说明

| 配置项 | 推荐值 | 原因 |
|--------|--------|------|
| `<html lang>` | `zh-CN` | 屏幕阅读器使用正确的语音引擎 |
| 页面结构顺序 | header → nav → main → aside → footer | 符合无障碍导航习惯 |
| `<main>` 唯一性 | 每页仅一个 `<main>` | HTML5 规范要求，否则验证报错 |

## 常见问题

1. **`<section>` 没有标题报 warning**：HTML5 规范建议 `<section>` 包含标题元素（h1-h6），W3C 验证器会提示。
2. **多个 `<main>` 标签报错**：每个页面只允许一个 `<main>`，且不能嵌套在 header/nav/article/aside/footer 内。
3. **语义标签与 ARIA 角色冲突**：不要在 `<nav>` 上加 `role="navigation"`——标签本身已隐含该 ARIA 角色，重复声明反而冗余。
