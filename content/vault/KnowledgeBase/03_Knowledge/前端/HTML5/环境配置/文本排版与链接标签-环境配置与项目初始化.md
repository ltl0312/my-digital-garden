# HTML 文本排版与链接 — 环境配置与项目初始化

## 信息来源
- **官方文档**：https://developer.mozilla.org/zh-CN/docs/Web/HTML/Inline_elements（✅ 可访问）

## 前置条件
- VS Code + Live Server 已安装（参考 <a href="obsidian://open?file=基础语法-环境配置与项目初始化">HTML5-基础语法-环境配置与项目初始化</a>）

## Step 1: 推荐扩展

- **Auto Rename Tag**：修改开标签时自动同步改闭标签（对 `<a>`、`<strong>` 等成对标签极其方便）
- **Path Intellisense**：写 `<a href="...">` 时自动补全文件路径

## Step 2: 验证

创建 `text-test.html`：
```html
<!DOCTYPE html>
<html lang="zh-CN">
<head><meta charset="UTF-8"><title>文本排版测试</title></head>
<body>
    <h1>一级标题</h1>
    <p>一段包含<strong>重要文本</strong>和<em>强调文本</em>的段落。</p>
    <a href="https://developer.mozilla.org/zh-CN/" target="_blank" rel="noopener noreferrer">MDN 文档</a>
</body>
</html>
```
Live Server 打开 → 确认链接可点击跳转，`<strong>` 加粗，`<em>` 斜体。

## Step 3: 链接安全最佳实践

| 场景 | target | rel 属性 | 原因 |
|------|--------|---------|------|
| 外站链接 | `_blank` | `noopener noreferrer` | 防 Tabnabbing 钓鱼攻击 |
| 站内链接 | `_self`（默认） | 无需 | 同源安全 |
| 下载链接 | 无需（download 属性） | `noopener` | 下载无需打开新页面 |
| UGC 外链 | `_blank` | `nofollow noopener` | nofollow 告知搜索引擎不传递权重 |

## Step 4: 最小可运行示例

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
    <meta charset="UTF-8">
    <title>文本与链接示例</title>
    <style>
        body { font-family: system-ui; max-width: 600px; margin: 2rem auto; }
        mark { background: #fff3cd; padding: 0 0.2em; }
        blockquote { border-left: 3px solid #ccc; margin: 1em 0; padding-left: 1em; color: #666; }
    </style>
</head>
<body>
    <h1>文本语义示例</h1>
    <p>这是一个<mark>高亮</mark>的关键词。</p>
    <blockquote cite="https://example.com">
        <p>这是一个块级引用，cite 属性指向来源 URL。</p>
    </blockquote>
    <p>缩写示例：<abbr title="HyperText Markup Language">HTML</abbr></p>
    <p>键盘快捷键：按 <kbd>Ctrl</kbd> + <kbd>S</kbd> 保存文件。</p>
    <p>代码片段：<code>console.log('Hello World');</code></p>
    <hr>
    <p>
        <a href="mailto:hello@example.com">✉️ 发邮件</a> |
        <a href="tel:+8613800138000">📞 打电话</a>
    </p>
</body>
</html>
```

## 常见问题

1. **`<a>` 链接不跳转**：检查 `href` 是否以 `http://` 或 `https://` 开头（相对路径则检查文件是否存在）。
2. **`<a>` 中嵌套 `<div>` 不合法**：`<a>` 在 HTML5 中虽然是透明内容模型（可包裹块级元素），但在 `<p>` 等段落元素内嵌套块级链接仍不合法。
3. **`<abbr>` 不显示下划线**：浏览器默认对 `<abbr>` 应用虚线下划线，可通过 CSS `text-decoration: underline dotted` 自定义。
