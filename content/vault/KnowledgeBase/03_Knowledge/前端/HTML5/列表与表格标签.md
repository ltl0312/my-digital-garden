# HTML 列表与表格标签

## 📍 知识体系定位
- **所属技术栈**：前端 Vue 3
- **所在层级**：L0 三件套 → HTML5 → 结构化数据展示
- **上游依赖**：<a href="obsidian://open?file=基础语法与文档结构">HTML5-基础语法与文档结构</a>、<a href="obsidian://open?file=文本排版与链接标签">HTML-文本排版与链接标签</a>
- **下游延伸**：CSS 列表样式（`list-style`）、CSS 表格样式（`border-collapse`）、JavaScript 动态表格生成
- **同级技术**：CSS Grid 布局（替代表格用于页面布局）、Flexbox（一维布局）

## 概述（Overview）
> HTML 提供三种列表类型（无序列表 `<ul>`、有序列表 `<ol>`、定义列表 `<dl>`）和一套完整的表格标签体系（`<table>` / `<thead>` / `<tbody>` / `<tfoot>` / `<tr>` / `<th>` / `<td>`），分别用于罗列项目和展示结构化数据。

## 设计初衷（Motivation）

### 设计思想
列表和表格反映了人类信息组织的两种基本模式：**序列**（列表）和**矩阵**（表格）。HTML 将它们内置为原生标签，而非让开发者用 `<div>` 模拟，是因为：
- 屏幕阅读器可以宣告"列表，3 项"或"表格，5 行 2 列"，帮助视障用户导航
- 搜索引擎理解 `<ol>` 中的项有先后顺序，`<table>` 中的数据存在行列关系
- `<dl>` 实现了"术语-定义"的键值对语义，适合词汇表和元数据展示

> 重要原则：**表格用于展示数据，不用于页面布局。** 页面布局使用 CSS Flexbox/Grid。

## 实现（Implementation）

### 三种列表对比

```html
<!-- ① 无序列表：项目顺序不重要，默认圆点前缀 -->
<ul>
    <li>苹果</li>
    <li>香蕉</li>
</ul>

<!-- ② 有序列表：项目有严格顺序，默认数字前缀 -->
<!-- type 控制编号类型(1/A/a/I/i)，start 控制起始数字，reversed 降序 -->
<ol type="1" start="3" reversed>
    <li>第三步：部署上线</li>
    <li>第二步：编写代码</li>
    <li>第一步：需求分析</li>
</ol>

<!-- ③ 定义列表：术语+描述的名值对结构 -->
<dl>
    <dt>HTML</dt>
    <dd>超文本标记语言，定义网页结构。</dd>
    <dt>CSS</dt>
    <dd>层叠样式表，控制网页外观。</dd>
</dl>
```

### 完整实例：一个完整的语义化表格

```html
<!-- ① table 容器 + caption 表格标题（必须紧跟 table 之后） -->
<table>
    <caption>2026年销售报表</caption>
    <!-- ② thead：表头区域，用 th 而非 td 标记表头单元格 -->
    <thead>
        <tr>
            <th scope="col">月份</th>
            <th scope="col">销售额 (万元)</th>
        </tr>
    </thead>
    <!-- ③ tbody：数据主体，浏览器即使不写也会自动包裹 tr -->
    <tbody>
        <tr>
            <td>一月</td>
            <td>50</td>
        </tr>
        <tr>
            <td>二月</td>
            <td>60</td>
        </tr>
    </tbody>
    <!-- ④ tfoot：表尾，通常用于汇总行（如总计） -->
    <tfoot>
        <tr>
            <th scope="row">总计</th>
            <td>110</td>
        </tr>
    </tfoot>
</table>
```

### 核心属性说明

| 标签/属性 | 说明 |
|-----------|------|
| `<ol>` `type` | 编号类型：`1`（数字）、`A`（大写字母）、`a`（小写字母）、`I`（大写罗马）、`i`（小写罗马） |
| `<ol>` `start` | 起始编号，如 `start="5"` 从 5 开始计数 |
| `<ol>` `reversed` | HTML5 新增，列表降序排列 |
| `<td>` `colspan` | 跨列合并（横向合并），值 = 合并的列数 |
| `<td>` `rowspan` | 跨行合并（纵向合并），值 = 合并的行数 |
| `<th>` `scope` | `"col"`（表头作用于整列）或 `"row"`（表头作用于整行），辅助无障碍访问 |

> **💡 补充**：HTML5 中 `<table border="1">` 已被废弃，表格边框应使用 CSS 的 `border` 属性控制。`<colgroup>` 和 `<col>` 可用于对整列应用统一样式。
