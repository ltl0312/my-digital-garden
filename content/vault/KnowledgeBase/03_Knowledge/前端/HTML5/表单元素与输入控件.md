## 📍 知识体系定位

- **所在层级**：L0 三件套 → HTML5 → 表单

## 概述（Overview）
> HTML 表单（`<form>`）是用户与服务器交互的桥梁——注册、登录、搜索、评论等所有数据提交操作都通过表单完成。HTML5 新增了大量 `input` type 类型和原生验证属性，大幅减少了 JavaScript 验证代码。

## 设计初衷（Motivation）

### 历史演进
- **前身技术**：HTML 4 时代，`<input>` 仅有 text/password/radio/checkbox/submit/reset/button/file/hidden 等约 10 种类型。日期选择、颜色选择、邮箱验证等全靠 JavaScript 库实现。
- **为什么前身被淘汰**：每个表单都需要引入 jQuery UI、jQuery Validation 等第三方库来做日期选择器和表单验证，页面臃肿。
- **本技术的核心突破**：HTML5 新增了 email/url/tel/number/range/search/color/date/time/datetime-local/month/week 等 13 种 input 类型，自带格式验证和移动端键盘优化。同时增加了 required/pattern/minlength/maxlength 等原生验证属性。
- **为什么是它活下来了**：零依赖的表单验证和移动端键盘适配，大幅减少了 JavaScript 代码量。即使在不支持的旧浏览器中，新 type 也会优雅降级为 type="text"。
- **当前版本**：HTML5 Living Standard

> ⚠️ **版本兼容性**：HTML5 新增的 input type 在旧浏览器中降级为 `type="text"`，不会报错。但 `required`、`pattern` 等验证属性在旧浏览器中不生效，需要 JavaScript 兜底。

### 设计思想
HTML5 表单的设计体现了"声明式优于命令式"的思想。`required` 声明"此字段必填"，`type="email"` 声明"此处输入邮箱"，浏览器自动完成验证——开发者无需写一行 JavaScript。这种声明式思想也深刻影响了后来的 Vue、React 等框架。

## 实现（Implementation）

### `<form>` 容器属性

| 属性 | 说明 |
|------|------|
| `action` | 提交到的后端 URL |
| `method` | `GET`（数据在 URL 中，适合搜索）/ `POST`（数据在请求体中，适合密码/大量数据） |
| `enctype` | `multipart/form-data`（上传文件必设） |
| `autocomplete` | `on` / `off`，控制浏览器自动填充 |
| `novalidate` | 禁用 HTML5 原生验证（调试用） |

### HTML5 新增 input type 一览

```html
<!-- ① 邮箱：自动验证 @ 符号，移动端弹出邮箱键盘 -->
<input type="email" placeholder="you@example.com">

<!-- ② 网址：自动验证 http(s):// 前缀 -->
<input type="url" placeholder="https://">

<!-- ③ 电话：移动端弹出拨号键盘 -->
<input type="tel" placeholder="13800138000">

<!-- ④ 数字：出现微调按钮，min/max/step 控制范围 -->
<input type="number" min="0" max="100" step="5">

<!-- ⑤ 滑动条：可视化范围选择 -->
<input type="range" min="0" max="100" step="10">

<!-- ⑥ 搜索框：带清除 X 按钮 -->
<input type="search" placeholder="搜索...">

<!-- ⑦ 颜色拾取器 -->
<input type="color">

<!-- ⑧ 日期系列：原生日期选择器 -->
<input type="date">
<input type="time">
<input type="datetime-local">
<input type="month">
<input type="week">
```

### 完整实例：用户注册表单

```html
<!-- ① form 容器：method="POST" 保护密码不在 URL 中暴露 -->
<form action="/register" method="POST">
    <fieldset>
        <legend>用户注册</legend>

        <!-- ② label + input 绑定：点击"用户名"文字即可聚焦输入框 -->
        <div>
            <label for="username">用户名：</label>
            <input type="text" id="username" name="username"
                   required placeholder="请输入用户名" autofocus>
        </div>

        <!-- ③ 密码字段：minlength 限制最小长度 -->
        <div>
            <label for="pwd">密码：</label>
            <input type="password" id="pwd" name="password"
                   required minlength="6" placeholder="至少6位">
        </div>

        <!-- ④ 单选按钮：同组 radio 必须具有相同的 name 值 -->
        <div>
            <label>性别：</label>
            <input type="radio" id="male" name="gender" value="m" checked>
            <label for="male">男</label>
            <input type="radio" id="female" name="gender" value="f">
            <label for="female">女</label>
        </div>

        <!-- ⑤ 下拉选择：select + option -->
        <div>
            <label for="city">城市：</label>
            <select id="city" name="city">
                <option value="beijing">北京</option>
                <option value="shanghai">上海</option>
            </select>
        </div>

        <!-- ⑥ 多行文本 -->
        <div>
            <label for="bio">个人简介：</label>
            <textarea id="bio" name="bio" rows="4" cols="40" placeholder="介绍一下自己"></textarea>
        </div>

        <!-- ⑦ 按钮：type="submit" 触发表单提交，type="reset" 清空表单 -->
        <div>
            <button type="submit">注册账户</button>
            <button type="reset">重置</button>
        </div>
    </fieldset>
</form>
```

### 其他表单控件速查

| 控件 | 关键点 |
|------|--------|
| `<textarea>` | 多行文本，`rows`/`cols` 控制大小 |
| `<button>` | 比 `<input type="button">` 更灵活，可包含图文 |
| `<select>` + `<option>` | 下拉框，`multiple` 属性变多选，`<optgroup>` 分组 |
| `<label>` | `for` 绑定 input 的 `id`，点击文字聚焦输入框 |
| `<fieldset>` + `<legend>` | 表单分组 + 分组标题 |
| `<datalist>` | HTML5 新增，为 input 提供自动完成列表（通过 `list` 属性绑定 id） |
| `<output>` | HTML5 新增，显示计算结果 |
| `<progress>` | HTML5 新增，进度条 `<progress value="22" max="100">` |
| `<meter>` | HTML5 新增，度量衡 `<meter value="0.6" min="0" max="1">` |

> **💡 补充**：`<datalist>` 与 `<select>` 的区别：`<datalist>` 是"建议列表"，用户可以输入不在列表中的值；`<select>` 是"约束列表"，用户只能从选项中选择。
