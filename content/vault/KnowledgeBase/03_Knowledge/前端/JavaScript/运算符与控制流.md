# JavaScript 运算符与控制流

## 📍 知识体系定位
- **所属技术栈**：前端 Vue 3
- **所在层级**：L0 三件套 → JavaScript → 运算符与流程控制
- **上游依赖**：<a href="obsidian://open?file=基础语法与数据类型">JavaScript-基础语法与数据类型</a>
- **下游延伸**：<a href="obsidian://open?file=函数与参数">JavaScript-函数与参数</a>（函数体内使用控制流）
- **同级技术**：Python 控制流、Java 控制流

## 概述（Overview）
> JavaScript 提供算术、比较、逻辑三大类运算符，以及 `if-else`、`switch`、`for`/`while`/`do-while`、`for-in`/`for-of` 等控制流结构。ES11 新增的可选链（`?.`）和空值合并（`??`）运算符极大简化了深层属性访问和默认值处理。

## 设计初衷（Motivation）

### 历史演进
- **前身技术**：ES5 时代，访问深层嵌套属性需要写冗长的 `&&` 链（`obj && obj.user && obj.user.name`），设置默认值需要用 `||` 运算符（但 `||` 把 `0`、`""`、`false` 也视为 falsy，不符合语义）。
- **本技术的核心突破**：ES11（2020）引入 `?.`（可选链）——短路安全访问深层属性；`??`（空值合并）——仅在 `null`/`undefined` 时使用默认值，`0` 和 `""` 被视为合法值。
- **当前版本**：ES11+

### 设计思想
`?.` 和 `??` 的设计体现了"精确语义"的理念——区分"不存在"（null/undefined）和"假值"（0/false/""）。`||` 运算符不能区分"用户输入 0"和"无输入"，`??` 可以。

### 跨学科溯源
- `?.` 可选链 → <a href="obsidian://open?file=XD-4 编程语言与编译">XD-4 编程语言与编译</a>（短路求值 Short-circuit Evaluation 的扩展——不仅是布尔短路，还包含 nullish 短路）
- `switch` 严格相等匹配 → <a href="obsidian://open?file=XD-5 数据结构与算法">XD-5 数据结构与算法</a>（查表法优化：V8 将密集 case 的 switch 编译为跳转表实现 O(1) 匹配）

## 实现（Implementation）

### 核心运算符速查

```javascript
// ① 算术：+ - * / % **（指数） ++ --
2 ** 3; // 8（ES7 指数运算符）

// ② 比较（关键区别）
0 == "";    // true ← 隐式类型转换后相等
0 === "";   // false ← 严格相等，类型不同

// ③ 逻辑
true && false;  // false（与）
true || false;  // true（或）
!true;          // false（非）

// ④ 空值合并 ??（ES11）：左侧为 null 或 undefined 时返回右侧
let value = null ?? "默认值";  // "默认值"
let count = 0 ?? 10;           // 0（0 不是 null/undefined，不会触发回退）
let old = 0 || 10;             // 10（|| 把 0 视为 falsy）

// ⑤ 可选链 ?.（ES11）：安全访问深层属性
let userName = obj?.user?.name;       // 任意一层为 null/undefined 时返回 undefined
let first = arr?.[0];                 // 安全访问数组元素
let result = obj?.method?.();         // 安全调用方法
```

### 控制流

```javascript
// if...else if...else
if (score >= 90) {
    grade = "A";
} else if (score >= 80) {
    grade = "B";
} else {
    grade = "C";
}

// switch：使用严格相等 === 匹配
switch (day) {
    case "Mon":
        console.log("周一");
        break; // 没有 break 会"穿透"到下一个 case
    case "Fri":
        console.log("周五");
        break;
    default:
        console.log("其他");
}

// 循环
for (let i = 0; i < 10; i++) { }        // 传统 for
while (condition) { }                     // 先判断后执行
do { } while (condition);                 // 先执行后判断

// for...in：遍历对象的可枚举属性（含原型链）
for (let key in obj) { console.log(key, obj[key]); }

// for...of（ES6）：遍历可迭代对象（数组、字符串、Map、Set）
for (let value of [1, 2, 3]) { console.log(value); }
for (let char of "hello") { console.log(char); }
```

> **💡 补充**：`for...in` vs `for...of` — for...in 遍历的是**键名**（适用于普通对象的属性），for...of 遍历的是**值**（适用于数组、字符串等可迭代对象）。不要把 for...in 用于数组遍历（会遍历到数组原型上的属性）。
