## 📍 知识体系定位

## 概述（Overview）
> JavaScript 有三种变量声明方式（`var`/`let`/`const`），8 种数据类型（7 种原始类型 + Object），以及 `typeof`/`instanceof` 等多种类型检测手段。理解变量作用域和类型系统是 JS 编程的基石。

## 设计初衷（Motivation）

### 历史演进
- **前身技术**：JS 最初只有 `var` 关键字，函数作用域 + 变量提升（hoisting）导致大量意外行为。
- **为什么前身被淘汰**：`var` 的变量提升让代码逻辑不可预测；无块级作用域导致循环中的闭包陷阱（经典面试题：for + setTimeout）。
- **本技术的核心突破**：ES6 引入 `let`（块级作用域，TDZ 暂时性死区）和 `const`（常量声明），从根本上解决了 var 的两大缺陷。
- **为什么是它活下来了**：`let`/`const` 的行为与大多数编程语言一致，降低了学习曲线，且向后兼容（`var` 仍然可用）。
- **当前版本**：ES6+（ECMAScript 2015+）

> ⚠️ **版本兼容性**：`let`/`const` 在 IE11 中部分支持（不支持块级作用域的 `for` 循环中的 `let`）。现代项目通过 Babel 转译可兼容 IE11。

### 设计思想
JavaScript 的动态弱类型设计源于其"脚本语言"的定位——快速编写、容忍错误、不阻塞页面。`typeof null === "object"` 是著名的历史遗留 Bug（JS 内部用类型标签低位表示类型，对象的标签是 `000`，而 null 是全零，恰好匹配）。

## 实现（Implementation）

### var / let / const 对比

```javascript
// ① var：函数作用域，存在变量提升
console.log(x); // undefined（变量提升：声明提前，初始化为 undefined）
var x = 10;
// var 允许重复声明（危险！）
var x = 20; // 不报错

// ② let：块级作用域（{} 内有效），TDZ 暂时性死区
// console.log(y); // ❌ ReferenceError: Cannot access 'y' before initialization
let y = 20;
// let y = 30; // ❌ SyntaxError: 同一作用域内不能重复声明

// ③ const：块级作用域，声明时必须初始化，基础类型不可修改
const z = 30;
// z = 40; // ❌ TypeError: Assignment to constant variable

// const 的特殊情况：对象/数组的内容可修改，但不能重新赋值整个变量
const person = { name: "Alice" };
person.name = "Bob";     // ✅ 修改属性（对象引用没变）
// person = { name: "Charlie" }; // ❌ 重新赋值整个对象
```

### 8 种数据类型

```javascript
// 7 种原始类型（Primitive Types，存储在栈内存）
let str = "Hello";              // 1. String：单引号/双引号/反引号
let num = 42;                   // 2. Number：整数、浮点数、NaN、Infinity
let bool = true;                // 3. Boolean：true / false
let undef;                      // 4. Undefined：声明但未赋值
let empty = null;               // 5. Null：人为设置的空值
let sym = Symbol("unique");     // 6. Symbol（ES6）：独一无二的值
let big = 12345678901234567890n;// 7. BigInt（ES10）：超大整数，以 n 结尾

// 1 种引用类型（Reference Type，存储在堆内存）
let obj = { name: "Alice" };    // 8. Object：普通对象、Array、Function、Date、RegExp 等
let arr = [1, 2, 3];
let fn = function() {};
```

### 类型检测三剑客

```javascript
// ① typeof：检测原始类型（快但有两个陷阱）
typeof "hello";   // "string"
typeof 42;        // "number"
typeof true;      // "boolean"
typeof undefined; // "undefined"
typeof Symbol();  // "symbol"
typeof 123n;      // "bigint"
typeof {};        // "object"
typeof [];        // "object"   ← 陷阱1：数组也是 "object"
typeof null;      // "object"   ← 陷阱2：历史遗留 Bug
typeof function(){}; // "function"

// ② instanceof：检测对象是否属于某构造函数（不能检测原始类型）
[] instanceof Array;       // true
new Date() instanceof Date;// true

// ③ Object.prototype.toString.call()：最准确的类型检测
Object.prototype.toString.call([]);        // "[object Array]"
Object.prototype.toString.call(null);      // "[object Null]"
Object.prototype.toString.call(new Date());// "[object Date]"
```

> **💡 补充**：`NaN`（Not a Number）是 Number 类型的一个特殊值。`typeof NaN === "number"` 为 true。判断 NaN 用 `Number.isNaN()` 而非 `isNaN()`（后者会先做类型转换，`isNaN("hello")` 返回 true）。
