## 概述（Overview）
> JavaScript 函数是一等公民（First-Class Citizen），有四种定义方式：函数声明、函数表达式、箭头函数、构造函数。ES6 新增了默认参数、剩余参数（Rest Parameters），箭头函数改变了 this 绑定规则。

## 设计初衷（Motivation）

### 设计思想
JavaScript 函数的"一等公民"地位意味着函数可以：① 赋值给变量 ② 作为参数传递（回调）③ 作为返回值（高阶函数）④ 动态创建。这是 JS 函数式编程和异步编程（回调模式）的基础。

箭头函数的设计目标不是替代普通函数，而是解决 `this` 绑定的痛点——普通函数的 `this` 由调用方式决定（动态作用域），箭头函数的 `this` 由定义时的外层作用域决定（词法作用域）。

## 实现（Implementation）

### 四种定义方式

```javascript
// ① 函数声明（存在函数提升，可以在声明前调用）
function greet(name) {
    return "Hello " + name;
}

// ② 函数表达式（不存在提升，推荐用 const 防止覆盖）
const greetExp = function(name) {
    return "Hello " + name;
};

// ③ 箭头函数（ES6）：没有自己的 this 和 arguments
const greetArrow = (name) => {
    return "Hello " + name;
};
// 简写：只有一个参数可省略括号，只有一行 return 可省略 {} 和 return
const greetShort = name => "Hello " + name;

// ④ 构造函数（极少使用）
const greetNew = new Function('name', 'return "Hello " + name');
```

### 参数高级特性

```javascript
// ① 默认参数（ES6）：调用时未传或传 undefined 时使用默认值
function multiply(a, b = 1) {
    return a * b;
}
multiply(5);     // 5（b 默认为 1）
multiply(5, 3);  // 15

// ② 剩余参数（ES6）：将多余实参收集到一个真数组中（必须是最后一个参数）
function sum(...numbers) {
    // numbers 是真正的 Array，可以直接使用数组方法
    return numbers.reduce((acc, curr) => acc + curr, 0);
}
sum(1, 2, 3, 4); // 10

// ③ arguments 对象：普通函数内内置的类数组对象（箭头函数中没有）
function oldSchool() {
    console.log(arguments[0]);        // 获取第一个实参
    console.log(arguments.length);    // 实参个数
    // arguments 是类数组对象（有 length 但没有 forEach/map 等方法）
    const argsArray = Array.from(arguments); // 转为真数组
}
oldSchool("a", "b", "c");
```

### 箭头函数 vs 普通函数的 this

```javascript
// 普通函数：this 由调用方式决定
const obj1 = {
    name: "Alice",
    greet: function() {
        console.log(this.name); // this → obj1（点调用）
    }
};
obj1.greet(); // "Alice"

// 箭头函数：this 由定义时的外层作用域决定
const obj2 = {
    name: "Bob",
    greet: () => {
        console.log(this.name); // this → 外层（window/global），不是 obj2
    }
};
obj2.greet(); // undefined

// ★ 经典场景：setTimeout 中的 this
const obj3 = {
    name: "Charlie",
    // ❌ 普通函数：this 丢失
    delayedBad: function() {
        setTimeout(function() {
            console.log(this.name); // undefined（this → window）
        }, 100);
    },
    // ✅ 箭头函数：this 继承外层
    delayedGood: function() {
        setTimeout(() => {
            console.log(this.name); // "Charlie"（this → obj3）
        }, 100);
    }
};
```

> **💡 补充**：什么时候用箭头函数？① 简短的回调函数（`arr.map(x => x * 2)`）② 需要继承外层 this 的场景（事件处理、setTimeout）。什么时候不用？① 对象方法（需要 this 指向对象）② 构造函数（箭头函数没有 prototype）③ 需要 arguments 对象时。
