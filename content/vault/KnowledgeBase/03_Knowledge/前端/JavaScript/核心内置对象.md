# JavaScript 核心内置对象

## 📍 知识体系定位
- **所属技术栈**：前端 Vue 3
- **所在层级**：L0 三件套 → JavaScript → 内置对象 API
- **上游依赖**：<a href="obsidian://open?file=基础语法与数据类型">JavaScript-基础语法与数据类型</a>、<a href="obsidian://open?file=函数与参数">JavaScript-函数与参数</a>
- **下游延伸**：函数式编程（map/filter/reduce）、数据转换、Vue computed 计算属性
- **同级技术**：Python 内置类型（list/dict）、Java Collections API

## 概述（Overview）
> JavaScript 的三大核心内置对象——String（字符串）、Array（数组）、Object（对象）——各自配有丰富的方法 API。数组方法分为**改变原数组**（push/pop/splice/sort）和**返回新数组**（map/filter/reduce/slice）两类。理解这些 API 是 JS 数据处理的基础。

## 设计初衷（Motivation）

### 设计思想
JS 数组方法的设计体现了"不可变性受推崇但不强制"的原则：map/filter/reduce 等函数式方法返回新数组（不可变风格），但 push/splice/sort 等直接修改原数组（命令式风格）。现代 JS 开发趋势倾向不可变方法（React/Vue 的响应式系统依赖不可变检测）。

### 跨学科溯源
- Array 方法链（map → filter → reduce）→ <a href="obsidian://open?file=XD-5 数据结构与算法">XD-5 数据结构与算法</a>：MapReduce 编程模型，源自函数式编程的 map/filter/fold 三元组
- `sort()` 默认比较器 → <a href="obsidian://open?file=XD-5 数据结构与算法">XD-5 数据结构与算法</a>：按 UTF-16 码元排序，"10" 排在 "2" 前面，这是一个经典陷阱

## 实现（Implementation）

### String 字符串方法速查

```javascript
let str = "Hello World";

// 查找
str.charAt(0);          // "H" — 返回指定位置字符
str.includes("World");  // true — 是否包含子串
str.indexOf("o");       // 4 — 首次出现位置，找不到返回 -1
str.lastIndexOf("o");   // 7 — 最后出现位置
str.startsWith("He");   // true（ES6）
str.endsWith("ld");     // true（ES6）

// 提取与转换
str.slice(0, 5);        // "Hello" — 提取子串（支持负索引：slice(-5) → "World"）
str.substring(0, 5);    // "Hello" — 提取子串（不支持负索引）
str.split(" ");         // ["Hello", "World"] — 分割为数组
str.toUpperCase();      // "HELLO WORLD"
str.toLowerCase();      // "hello world"

// 修改（返回新字符串，原字符串不变）
str.replace("World", "JS");    // "Hello JS"（替换首个匹配）
str.replaceAll("l", "L");      // "HeLLo WorLd"（ES12）
str.trim();                     // 去除首尾空格
```

### Array 数组方法速查

```javascript
let arr = [3, 1, 4, 1, 5];

// ★ 改变原数组的方法（Mutation Methods）
arr.push(9);          // [3,1,4,1,5,9] — 尾部添加，返回新长度
arr.pop();            // [3,1,4,1,5] — 尾部删除，返回删除的元素
arr.unshift(0);       // [0,3,1,4,1,5] — 头部添加
arr.shift();          // [3,1,4,1,5] — 头部删除
arr.splice(1, 2, 9); // [3,9,1,5] — 从索引1删2个，插入9（万能方法）
arr.reverse();        // [5,1,4,1,3] — 反转
arr.sort((a, b) => a - b); // [1,1,3,4,5] — 升序（必须传比较函数！）

// ★ 不改变原数组的方法（返回新数组，推荐优先使用）
arr.concat([6, 7]);   // 合并，返回新数组
arr.slice(1, 3);      // [1, 4] — 截取，不含 end
arr.join(" - ");      // "1-4-3-1-5" — 转为字符串
arr.indexOf(1);       // 0 — 查找元素位置
arr.includes(5);      // true — 是否包含

// ★ 高级迭代方法（函数式编程核心）
arr.forEach((item, idx) => console.log(item, idx));  // 遍历，无返回值
arr.map(x => x * 2);           // [6,2,8,2,10] — 映射为等长新数组
arr.filter(x => x > 2);        // [3,4,5] — 过滤满足条件的元素
arr.reduce((sum, x) => sum + x, 0); // 14 — 累加器（0 是初始值）
arr.find(x => x > 3);          // 4 — 返回第一个满足条件的元素
arr.findIndex(x => x > 3);     // 2 — 返回其索引
arr.some(x => x > 4);          // true — 是否有元素满足条件？
arr.every(x => x > 0);         // true — 是否全部满足条件？
```

### Object 对象方法速查

```javascript
const obj = { name: "Alice", age: 25 };

Object.keys(obj);      // ["name", "age"] — 所有可枚举属性名
Object.values(obj);    // ["Alice", 25] — 所有属性值
Object.entries(obj);   // [["name","Alice"], ["age",25]] — 键值对数组
Object.assign({}, obj, { city: "NYC" }); // 浅合并对象（常用作浅拷贝）
Object.freeze(obj);    // 冻结对象：不能修改/添加/删除属性
Object.seal(obj);      // 密封对象：不能添加/删除，但可修改现有属性

// 检查属性存在性
"name" in obj;                    // true — in 运算符（含原型链）
obj.hasOwnProperty("name");       // true — 仅检查自身属性
```

> **💡 补充**：数组去重的最简方式：`[...new Set(array)]`。利用 Set 的"成员唯一"特性，一行代码替代 filter + indexOf 的手动去重。

### 常用数据处理模式

```javascript
// ① 链式处理（map → filter → reduce）
const prices = [10, 20, 30, 40];
const total = prices
    .map(p => p * 1.1)      // 加10%税：[11, 22, 33, 44]
    .filter(p => p > 20)     // 筛选大于20：[22, 33, 44]
    .reduce((s, p) => s + p, 0); // 求和：99

// ② 数组去重
const unique = [...new Set([1, 2, 2, 3, 3, 3])]; // [1, 2, 3]

// ③ 数组扁平化
[1, [2, [3]]].flat(2);       // [1, 2, 3]（ES10，参数为深度）
[1, [2, [3]]].flat(Infinity); // 无限深度展开
```
