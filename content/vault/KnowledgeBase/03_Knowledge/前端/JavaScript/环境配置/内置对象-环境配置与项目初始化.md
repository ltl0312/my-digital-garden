## Step 1: 验证

```javascript
const arr = [1, 2, 3];
console.log(arr.map(x => x * 2));       // [2, 4, 6]
console.log([...new Set([1,2,2,3])]);   // [1, 2, 3] — 去重
console.log(Object.entries({a:1,b:2})); // [['a',1],['b',2]]
```

## Step 2: 处理性能提示

```javascript
// ✅ 大数据量去重：用 for 循环 + Set（O(n)）优于 filter + indexOf（O(n²)）
const arr = [/* 大量数据 */];
const unique = [...new Set(arr)];  // O(n)

// ✅ 查找：Set.has() 或 Map.get() 比 Array.includes() 快（O(1) vs O(n)）
const set = new Set(arr);
set.has(value);  // 快速查找
```

## 常见问题

1. **`sort()` 排序错误**：`[2, 10].sort()` → `[10, 2]`（默认按字符串排序）。正确：`.sort((a,b) => a-b)`。
2. **`splice` 误用为 `slice`**：splice 修改原数组，slice 不修改。
