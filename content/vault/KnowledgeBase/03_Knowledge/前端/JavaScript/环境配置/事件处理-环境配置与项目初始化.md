## Step 1: DevTools 事件调试

1. **查看事件监听器**：Elements 面板 → 选中元素 → 右侧 Event Listeners 标签 → 展开查看所有绑定的事件
2. **事件监听器断点**：Sources 面板 → 右侧 Event Listener Breakpoints → 勾选事件类型（如 Mouse → click）→ 触发该事件时自动断点
3. **监控事件**：Console 中 `monitorEvents(element, 'click')` → 点击元素时Console 打印事件对象

## Step 2: 验证事件委托

```html
<ul id="list">
    <li data-id="1">Item 1</li>
    <li data-id="2">Item 2</li>
</ul>
<script>
    document.getElementById('list').addEventListener('click', function(e) {
        const li = e.target.closest('li');
        if (li) console.log('Clicked:', li.dataset.id);
    });
</script>
```
Console → 点击 li → 输出 clicked id。

## Step 3: throttle/debounce 模板

```javascript
// 防抖（debounce）：连续触发只执行最后一次（搜索框输入）
function debounce(fn, delay = 300) {
    let timer;
    return (...args) => {
        clearTimeout(timer);
        timer = setTimeout(() => fn(...args), delay);
    };
}
window.addEventListener('scroll', debounce(() => console.log('scrolled'), 200));
```

## 常见问题

1. **事件冒泡导致意外触发**：在回调中加 `e.stopPropagation()` 阻止冒泡。
2. **动态添加的元素无事件响应**：用事件委托在已有父元素上监听，而非直接在动态元素上绑事件。
