# JavaScript 函数与参数 — 环境配置与项目初始化

## 信息来源
- **ESLint 规则**：https://eslint.org/docs/latest/rules/（✅ 可访问）

## 前置条件
- Node.js + VS Code（参考 <a href="obsidian://open?file=基础语法-环境配置与项目初始化">JavaScript-基础语法-环境配置与项目初始化</a>）

## Step 1: ESLint 函数相关规则配置

```bash
npm init -y && npm install -D eslint
npx eslint --init  # 选择 AirBnB 或 Standard 风格
```

关键函数规则（`.eslintrc.json`）：
```json
{
  "rules": {
    "no-unused-vars": "warn",          // 未使用变量警告
    "prefer-arrow-callback": "warn",   // 推荐箭头函数作为回调
    "func-style": ["error", "expression"] // 推荐函数表达式
  }
}
```

## Step 2: 验证

```javascript
// test.js
const greet = name => `Hello, ${name}!`;
console.log(greet("World"));
```
`npx eslint test.js` → 无错误输出。

## Step 3: 最小可运行示例

```javascript
// Default params + rest params + arrow
const sum = (...numbers) => numbers.reduce((a, b) => a + b, 0);
const createGreeting = (name, greeting = "Hello") => `${greeting}, ${name}!`;
console.log(sum(1, 2, 3, 4));           // 10
console.log(createGreeting("Alice"));   // "Hello, Alice!"
```

## 常见问题

1. **箭头函数的 this 不符合预期**：对象方法、构造函数、需要动态 this 的场景不能用箭头函数。
2. **默认参数在中间位置**：默认参数建议放在参数列表末尾，否则调用时需传 `undefined` 占位。
