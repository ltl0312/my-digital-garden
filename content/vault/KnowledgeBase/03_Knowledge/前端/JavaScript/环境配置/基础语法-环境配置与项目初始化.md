# JavaScript 基础语法 — 环境配置与项目初始化

## 信息来源
- **Node.js 官网**：https://nodejs.org/（✅ 可访问，推荐 LTS 版本）
- **MDN JS 文档**：https://developer.mozilla.org/zh-CN/docs/Web/JavaScript（✅ 可访问）

## 前置条件
- VS Code 已安装（参考 <a href="obsidian://open?file=基础语法-环境配置与项目初始化">HTML5-基础语法-环境配置与项目初始化</a>）

## Step 1: 安装 Node.js

- **Windows**：nodejs.org → 下载 LTS 版本（.msi）→ 双击安装，勾选"Add to PATH"
- **macOS**：`brew install node@20` 或官网下载 .pkg
- **Linux**：`sudo apt install nodejs npm`（Ubuntu）或使用 nvm

## Step 2: 验证

```bash
node --version   # 预期输出：v20.x.x
npm --version    # 预期输出：10.x.x
```

在 VS Code 终端中运行：
```bash
node -e "console.log('JS 环境配置成功！')"
```

## Step 3: 推荐 VS Code 扩展

- **ESLint**：JS 代码规范检查和自动修复
- **JavaScript (ES6) code snippets**：快速代码片段
- **Quokka.js**：实时运行 JS 代码，边写边看输出

## Step 4: 最小可运行示例

```bash
mkdir js-project && cd js-project
echo 'console.log("Hello, JavaScript!");' > index.js
node index.js
```

## Step 5: 核心配置

| 配置项 | 推荐值 | 原因 |
|--------|--------|------|
| Node.js 版本 | LTS（20.x） | 稳定性 + 长期支持 |
| 代码风格 | ESLint + Prettier | 自动格式化和错误检查 |
| `.js` vs `.mjs` | `.js`（CommonJS）或 `.mjs`（ES Module） | 根据项目模块系统选择 |

## 常见问题

1. **`node` 命令找不到**：安装时未勾选"Add to PATH" → 重新安装或手动添加 Node.js 安装目录到环境变量 PATH。
2. **`console.log` 中文乱码**：终端字符编码问题。Windows 终端执行 `chcp 65001` 切换到 UTF-8。
3. **npm 全局安装权限错误（macOS/Linux）**：使用 nvm 管理 Node.js 版本可避免 sudo 权限问题。
