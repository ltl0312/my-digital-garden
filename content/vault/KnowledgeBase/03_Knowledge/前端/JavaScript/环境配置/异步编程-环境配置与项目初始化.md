## Step 1: 异步调试工具

- **Network 面板**：`F12` → Network → 查看 Fetch 请求的 Headers/Preview/Response
- **Sources → async 断点**：在 async 函数内设断点，Call Stack 面板显示完整的异步调用链
- **Console 中的 Promise**：`<pending>` 状态表示 Promise 未解决；展开查看 resolve/reject 的值

## Step 2: 测试 API（JSONPlaceholder）

```javascript
// 浏览器 Console 中直接运行
fetch('https://jsonplaceholder.typicode.com/users/1')
    .then(res => res.json())
    .then(data => console.log(data.name))
    .catch(err => console.error(err));
// 预期输出："Leanne Graham"
```

## Step 3: 最小可运行示例

```html
<script>
    async function loadUsers() {
        try {
            const res = await fetch('https://jsonplaceholder.typicode.com/users');
            if (!res.ok) throw new Error(`HTTP ${res.status}`);
            const users = await res.json();
            console.table(users.map(u => ({ id: u.id, name: u.name, email: u.email })));
        } catch (err) {
            console.error('加载失败', err.message);
        }
    }
    loadUsers();
</script>
```
Live Server 打开 → F12 Console → 看到用户数据表格。

## 常见问题

1. **Fetch CORS 被阻断**：浏览器 Console 显示 `has been blocked by CORS policy` → 需要后端设置 `Access-Control-Allow-Origin` 头，或使用代理服务器。
2. **`await` 忘了导致 Promise pending**：检查 `await` 关键字是否遗漏——忘记 await 会让变量变成 Promise 对象而非解析值。
3. **`Promise.all` 一个失败导致全部失败**：改用 `Promise.allSettled`，或给每个 Promise 加 `.catch()` 兜底。
