# JavaScript 运行与调试环境

## 信息来源
- **Chrome DevTools JS 调试**：https://developer.chrome.com/docs/devtools/javascript/（✅ 可访问）

## 前置条件
- Node.js 已安装（参考 [JavaScript-基础语法-环境配置与项目初始化]）

## Step 1: 三种运行 JS 的方式

| 环境 | 方式 | 适用场景 |
|------|------|---------|
| 浏览器 Console | `F12` → Console 标签 | 快速测试、DOM 操作 |
| Node.js | `node script.js` | 本地脚本、自动化 |
| HTML `<script>` | `<script src="app.js"></script>` | 网页交互 |

## Step 2: Chrome DevTools 调试

1. `F12` → Sources 面板 → 左侧文件树找到 `.js` 文件
2. 点击行号设置**断点**（蓝色标记）
3. 刷新页面或触发交互 → 代码在断点处暂停
4. 右侧面板查看：Call Stack（调用栈）、Scope（变量值）、Watch（监视表达式）
5. 使用 Step Over（`F10`）、Step Into（`F11`）逐行执行

## Step 3: Node.js 调试

```bash
# Node.js 内置调试器
node inspect index.js

# VS Code 图形化调试
# 创建 .vscode/launch.json → 选择 "Node.js" → F5 启动调试
```

## Step 4: 快速测试技巧

```javascript
// ① 浏览器 Console 中直接写 JS
document.querySelectorAll('div').length  // 实时查看 DOM

// ② Node.js REPL（交互式解释器）
// 终端输入 node 回车 → 直接写 JS 代码，回车执行
> 1 + 2   // 3
> [1,2,3].map(x => x * 2)  // [2, 4, 6]

// ③ 监测循环性能
console.time('loop');
for (let i = 0; i < 1e6; i++) {}
console.timeEnd('loop');  // "loop: 1.234ms"
```

## 常见问题

1. **`console.log` 不输出**：检查是否有语法错误（更早行的代码报错会阻止后续执行）。
2. **DevTools 断点不触发**：检查 Source Map 是否正确、代码是否被压缩混淆。
3. **`debugger` 语句不生效**：DevTools 必须处于打开状态，`debugger` 关键字才会暂停执行。
