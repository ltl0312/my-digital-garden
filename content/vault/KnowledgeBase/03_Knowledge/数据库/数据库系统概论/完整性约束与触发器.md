## 核心概念
> DBMS 的完整性控制包含定义、检查和违约处理三个功能。通用约束（PRIMARY KEY、FOREIGN KEY、CHECK、UNIQUE）覆盖 90% 的场景，触发器则是处理复杂完整性逻辑的"兜底武器"。

---

## 一、DBMS 完整性控制三功能

```
定义功能 → 提供语法定义约束（CREATE TABLE 中的约束子句）
检查功能 → 数据操作时自动检查约束，违反则拒绝执行
违约处理 → 根据约束类型执行（拒绝/级联删除/级联修改）
```

---

## 二、五大约束速查

| 约束 | SQL 关键字 | 作用 | 示例 |
|------|-----------|------|------|
| 主码 | `PRIMARY KEY` | 实体完整性：唯一 + 非空 | `Sno CHAR(9) PRIMARY KEY` |
| 外码 | `FOREIGN KEY ... REFERENCES` | 参照完整性：值必须存在于被参照表 | `FOREIGN KEY(Sno) REFERENCES Student(Sno)` |
| 非空 | `NOT NULL` | 列值不能为 NULL | `Sname CHAR(20) NOT NULL` |
| 唯一 | `UNIQUE` | 列值不能重复（允许一个 NULL） | `Cname CHAR(40) UNIQUE` |
| 检查 | `CHECK` | 自定义条件约束 | `Grade SMALLINT CHECK(Grade >= 0 AND Grade <= 100)` |
| 默认值 | `DEFAULT` | 未指定值时的默认值 | `Ssex CHAR(2) DEFAULT '男'` |

### 完整建表示例
```sql
CREATE TABLE SC (
    Sno CHAR(9),
    Cno CHAR(4),
    Grade SMALLINT CHECK(Grade >= 0 AND Grade <= 100),  -- 成绩范围
    PRIMARY KEY (Sno, Cno),                               -- 复合主码
    FOREIGN KEY (Sno) REFERENCES Student(Sno)
        ON DELETE CASCADE ON UPDATE CASCADE,              -- 级联操作
    FOREIGN KEY (Cno) REFERENCES Course(Cno)
        ON DELETE RESTRICT                                -- 限制删除
);
```

## 三、参照完整性的违约处理策略

| 违约操作 | 可用策略 | 示例场景 |
|----------|----------|----------|
| **插入外码值** | 拒绝插入 | SC 表插入不存在的 Sno → 拒绝 |
| **删除被参照元组** | 级联删除 / 限制 | 删除学生 → 级联删除其选课记录 |
| **修改被参照主码** | 级联修改 / 限制 | 修改学号 → 级联修改 SC 表对应外码 |
| **外码设为 NULL** | 允许 | 员工未分配部门时 DeptNo 为 NULL |

## 四、触发器（Trigger）

> 由事件（INSERT/UPDATE/DELETE）自动触发的存储过程，用于实现复杂的完整性逻辑。

### 五要素

| 要素 | 说明 |
|------|------|
| 触发事件 | INSERT / UPDATE / DELETE |
| 触发时机 | BEFORE（事件前）/ AFTER（事件后） |
| 触发级别 | FOR EACH ROW（行级）/ FOR EACH STATEMENT（语句级） |
| OLD/NEW | OLD = 修改前行的值，NEW = 修改后行的值 |
| SIGNAL | 抛出异常阻止操作 |

### 实战案例

```sql
-- 触发器1：禁止删除及格的成绩记录
CREATE TRIGGER PreventDeletePassed
BEFORE DELETE ON SC
FOR EACH ROW
BEGIN
    IF OLD.Grade >= 60 THEN
        SIGNAL SQLSTATE '45000'
        SET MESSAGE_TEXT = '不可删除及格的成绩记录';
    END IF;
END;

-- 触发器2：学生年龄增加1岁时，自动增加年级
CREATE TRIGGER UpdateGrade
AFTER UPDATE ON Student
FOR EACH ROW
BEGIN
    IF NEW.Sage - OLD.Sage = 1 THEN
        UPDATE Student SET Sgrade = Sgrade + 1 WHERE Sno = NEW.Sno;
    END IF;
END;
```
