## 一、索引

### 索引类型速查

| 索引类型 | SQL 示例 | 说明 |
|----------|----------|------|
| **普通索引** | `CREATE INDEX idx_name ON t(col);` | 加速查询，无唯一约束 |
| **唯一索引** | `CREATE UNIQUE INDEX idx_name ON t(col);` | 值不能重复（允许一个 NULL） |
| **主键索引** | 定义 `PRIMARY KEY` 时自动创建 | 特殊唯一索引，不允许 NULL |
| **组合索引** | `CREATE INDEX idx_name ON t(c1, c2);` | 多列联合，遵循最左前缀 |

### 创建与删除
```sql
-- 创建表时定义
CREATE TABLE students (
    student_id INT,
    student_name VARCHAR(50),
    INDEX idx_student_name (student_name)     -- 普通索引
);

-- 对已有表创建
CREATE INDEX idx_student_id ON students (student_id);
CREATE UNIQUE INDEX uniq_email ON employees (employee_email);

-- 删除索引
DROP INDEX idx_student_name ON students;
ALTER TABLE products DROP PRIMARY KEY;         -- 删除主键索引
```

### 维护操作
```sql
SHOW INDEX FROM students;       -- 查看所有索引
ANALYZE TABLE students;          -- 更新索引统计（帮助优化器）
OPTIMIZE TABLE students;         -- 碎片整理（MyISAM/InnoDB 适用）
ALTER TABLE students REBUILD;    -- 重建所有索引
```

### 聚簇索引 vs 非聚簇索引

| 对比维度 | 聚簇索引（Clustered） | 非聚簇索引（Non-Clustered） |
|----------|----------------------|---------------------------|
| 存储方式 | 数据与索引同文件，按索引排序 | 索引与数据分离，索引存指针 |
| 数量限制 | 每表仅 1 个 | 多个 |
| 查询性能 | 范围查询快 | 单点查询快 |
| 适用场景 | 主码列、频繁范围查询列 | 频繁过滤查询列 |

### 索引设计三原则
1. **必建**：主码列、外码列、WHERE 高频列
2. **禁建**：低选择性列（如性别 < 20%）、频繁更新列
3. **防过度**：小表不建多余索引（INSERT/UPDATE 变慢）

## 二、视图

### 创建与类型
```sql
-- 可更新视图（不含聚合/DISTINCT/GROUP BY）
CREATE VIEW SC_Update AS
    SELECT Sno, Cno, Grade FROM SC WHERE Cno = 'C001';

-- 不可更新视图（含聚合函数）
CREATE VIEW Cno_AvgGrade AS
    SELECT Cno, AVG(Grade) AS 平均分 FROM SC GROUP BY Cno;
```

### 视图三大作用
| 作用 | 说明 |
|------|------|
| **简化查询** | 避免反复编写复杂连接/子查询 |
| **数据安全** | 隐藏敏感字段（如工资表视图不显示薪资） |
| **逻辑独立** | 屏蔽表结构变化，应用程序无需修改 |

## 三、存储过程与函数

### 存储过程（批量执行，无返回值）
```sql
-- 创建存储过程
CREATE PROCEDURE GetStudentCount(
    IN deptName VARCHAR(20),    -- 输入参数
    OUT countNum INT            -- 输出参数
)
BEGIN
    SELECT COUNT(*) INTO countNum FROM Student WHERE Sdept = deptName;
END;

-- 调用
CALL GetStudentCount('计算机', @num);
SELECT @num AS 计算机专业人数;
```

### 函数（有返回值，用于计算）
```sql
-- 创建函数
CREATE FUNCTION GetCourseAvg(cno CHAR(4))
    RETURNS DECIMAL(5,2)
    DETERMINISTIC               -- 相同输入返回相同结果
BEGIN
    DECLARE avgG DECIMAL(5,2);
    SELECT AVG(Grade) INTO avgG FROM SC WHERE Cno = cno;
    RETURN avgG;
END;

-- 调用
SELECT GetCourseAvg('C001') AS 数据库平均分;
```

## 四、派生表（FROM 中的子查询）

```sql
-- 语法结构
SELECT columns
FROM (
    SELECT sub_columns
    FROM sub_table
    WHERE sub_conditions
    GROUP BY sub_grouping_columns
) AS derived_table_alias         -- 必须有别名！
WHERE main_conditions;
```

> **注意事项**：派生表必须指定别名；列名需清晰避免冲突；复杂派生表可能影响性能（大数据集谨慎使用）。
