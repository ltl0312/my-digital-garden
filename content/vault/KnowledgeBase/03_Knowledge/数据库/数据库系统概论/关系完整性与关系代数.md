## 核心概念
> 关系数据库建立在严格的数学基础之上。三类完整性约束（实体/参照/用户定义）确保数据质量；关系代数提供了一套精确的数学运算符来描述数据查询逻辑。

## 一、关系的 6 条基本性质

| # | 性质 | 说明 |
|---|------|------|
| 1 | 列同质 | 同一属性列中分量来自同一域 |
| 2 | 属性名唯一 | 不同属性列名称不可重复 |
| 3 | 行列无序 | 元组和属性的先后顺序无关 |
| 4 | 元组唯一 | 没有重复元组（主码保证） |
| 5 | 分量原子化 | 每个分量是不可再分的数据项（1NF 基础） |
| 6 | 域原子化 | 域中的元素不可再分 |

## 二、三类完整性约束

### 1. 实体完整性（Entity Integrity）

> 主属性不能取空值（NULL）。

- 实现机制：DBMS 自动检查，主码列不允许 NULL
- 示例：`Student` 表主码 `Sno` 不可为 NULL；`SC` 表主码 `(Sno, Cno)` 两者均不可为 NULL

### 2. 参照完整性（Referential Integrity）

> 外码值要么为空，要么等于被参照关系中某个元组的主码值。

**核心概念：**
- **外码**：R 的属性组 F，与 S 的主码 K 对应，则 F 称为 R 的外码
- **参照关系**：R（外码所在方）
- **被参照关系**：S（主码所在方）

**违约处理策略：**

| 策略 | 说明 | SQL 语法 |
|------|------|----------|
| **级联删除** | 删除被参照元组时，同时删除参照元组 | `ON DELETE CASCADE` |
| **级联修改** | 修改被参照主码时，同时修改外码值 | `ON UPDATE CASCADE` |
| **限制** | 参照方有对应元组时禁止操作 | `RESTRICT` |
| **允许 NULL** | 外码全为 NULL 是合法的（如未分配部门的员工） | 默认行为 |

### 3. 用户定义完整性（User-Defined Integrity）

| 类型 | 约束方式 | SQL 关键字 |
|------|----------|------------|
| 属性值范围 | `Sage BETWEEN 15 AND 30` | `CHECK` |
| 属性值格式 | `Sno LIKE '2023%'` | `CHECK` |
| 属性值唯一 | `Sname + Sdept` 组合不重复 | `UNIQUE` |

## 三、关系代数

### 传统集合运算（要求同构关系）

| 运算 | 符号 | 定义 |
|------|------|------|
| **并（Union）** | ∪ | 属于 A 或属于 B 的元组（去重） |
| **交（Intersection）** | ∩ | 属于 A 且属于 B 的元组 |
| **差（Difference）** | - | 属于 A 但不属于 B 的元组 |
| **笛卡尔积（Cartesian Product）** | × | A 每个元组与 B 每个元组的所有组合 |

### 专门关系运算

| 运算 | 符号 | 定义 | SQL 对应 |
|------|------|------|----------|
| **选择** | σ | 横向筛选满足条件的元组 | `WHERE` |
| **投影** | π | 纵向选取指定属性列（自动去重） | `SELECT DISTINCT` |
| **连接** | ⋈ | 按条件组合两个关系的元组 | `JOIN ON` |
| **除** | ÷ | 选取"包含另一关系所有元组"的元组 | 无直接对应 |

### 连接运算细分

| 连接类型 | 说明 |
|----------|------|
| **等值连接** | 按属性值相等条件连接，结果含两个连接列 |
| **自然连接** | 自动按所有同名列等值连接，结果去重连接列 |
| **外连接** | 保留未匹配元组（左/右/全外连），未匹配方填 NULL |
| **自身连接** | 表与自身连接，必须使用别名区分 |

## 四、完整性约束的 SQL 实现速查

```sql
-- 实体完整性：PRIMARY KEY
CREATE TABLE Student (Sno CHAR(9) PRIMARY KEY, ...);

-- 参照完整性：FOREIGN KEY
CREATE TABLE SC (
    Sno CHAR(9),
    Cno CHAR(4),
    FOREIGN KEY (Sno) REFERENCES Student(Sno)
        ON DELETE CASCADE ON UPDATE CASCADE,
    FOREIGN KEY (Cno) REFERENCES Course(Cno)
);

-- 用户定义完整性：CHECK / UNIQUE / NOT NULL / DEFAULT
CREATE TABLE Course (
    Cno CHAR(4) PRIMARY KEY,
    Cname CHAR(40) NOT NULL UNIQUE,
    Ccredit SMALLINT CHECK(Ccredit BETWEEN 1 AND 8)
);
```
