## 核心概念
> 范式是关系模式的"质量标准"，从 1NF 到 BCNF 逐级递进地消除冗余和异常。核心手段是：1NF 要求属性原子化 → 2NF 消除部分函数依赖 → 3NF 消除传递函数依赖 → BCNF 消除主属性的异常依赖。

---

## 一、函数依赖（范式判断基础）

### 定义
> 设 R(U)，若对 R 中任意两个元组，当 X 属性值相等时 Y 属性值必相等，则 **X → Y**（X 函数决定 Y）。

### 三类关键依赖

| 类型 | 定义 | 示例（R 含 Sno, Sname, Cno, Grade）|
|------|------|----------------------------------|
| **完全函数依赖** | X→Y，X 的任一真子集不能决定 Y | (Sno, Cno) → Grade（缺任何一个都定不了成绩） |
| **部分函数依赖** | X→Y，存在 X 的真子集 X' 也能决定 Y | (Sno, Cno) → Sname（仅 Sno 就能定名字，Cno 是冗余的） |
| **传递函数依赖** | X→Y, Y→Z，且 Y↛X, Z∉X | Sno → Sdept → Dean（学号→系别→系主任） |

---

## 二、范式逐级推导

### 以 R(Sno, Sname, Sdept, Dean, Cno, Cname, Grade) 为例

### 1NF — 最低要求
> 属性不可再分（分量原子化）

- ✅ R 中所有属性（Sno、Grade 等）均为原子值，满足 1NF
- ❌ 反例：联系方式列含"电话+邮箱"则不满足 1NF

### 2NF — 消除部分函数依赖
> 满足 1NF，且所有**非主属性**完全依赖于**主码**

- 主码：(Sno, Cno)（唯一决定所有属性）
- 非主属性：Sname, Sdept, Dean, Cname, Grade
- **问题**：(Sno, Cno) → Sname，而 Sno → Sname（部分依赖！），不满足 2NF

**分解方案（拆为 3 个 2NF 模式）：**
```
R1 (Sno, Sname, Sdept, Dean)        -- 主码 Sno
R2 (Cno, Cname)                     -- 主码 Cno
R3 (Sno, Cno, Grade)                -- 主码 (Sno, Cno)
```

### 3NF — 消除传递函数依赖
> 满足 2NF，且所有非主属性**不传递依赖**于主码

- **问题**：R1 中 Sno → Sdept, Sdept → Dean（传递依赖！），不满足 3NF

**分解方案：**
```
R11 (Sno, Sname, Sdept)             -- 主码 Sno
R12 (Sdept, Dean)                    -- 主码 Sdept
```

最终 3NF 模式集：**R11、R12、R2、R3**（无冗余、无异常）

### BCNF — 消除主属性的异常依赖
> 满足 3NF，且所有函数依赖的左部都**含主码**

- 例：R(仓库 W, 管理员 M, 物品 I)，依赖 W→M, (W,I)→M，主码 (W,I)
- **问题**：W → M 的左部 W 不是主码（只是主码的一部分）

**分解：**
```
R1 (W, M)   -- 主码 W
R2 (W, I)   -- 主码 (W, I)
```

## 三、范式判断流程图

```
1. 属性是否原子化？
   ├─ NO → 不满足 1NF，拆分复合属性
   └─ YES → 进入 2NF 判断

2. 非主属性是否完全依赖主码？
   ├─ NO（存在部分依赖）→ 不满足 2NF，拆分子模式消除
   └─ YES → 进入 3NF 判断

3. 非主属性是否传递依赖主码？
   ├─ YES → 不满足 3NF，拆分子模式消除
   └─ NO → 进入 BCNF 判断

4. 所有函数依赖的左部都含主码？
   ├─ NO → 不满足 BCNF，继续分解
   └─ YES → 满足 BCNF
```

---

## 四、模式分解两大原则

| 原则 | 说明 |
|------|------|
| **无损连接性** | 分解后的子关系通过自然连接可还原原关系 |
| **保持函数依赖性** | 原函数依赖集在分解后仍成立 |

---

## 五、易错点辨析

| 混淆点 | 区分 |
|--------|------|
| 部分依赖 vs 传递依赖 | 部分依赖 = 主码子集 → 非主属性；传递依赖 = 非主属性 → 非主属性 |
| 范式判断跳级 | 必须 **1NF → 2NF → 3NF** 逐步判断，不可直接跳级 |
| BCNF ⊆ 3NF | BCNF 是 3NF 的子集，有些 3NF 可能不满足 BCNF |
