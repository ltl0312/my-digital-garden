```
第 1 步：L0 关系理论
  核心概念与三级模式  →  关系完整性与关系代数
  （理解数据库是什么 + 关系代数基本功）

第 2 步：L1 SQL 语言
  SQL核心语法  →  完整性约束与触发器  →  索引视图与存储过程
  （会用 + 会约束 + 会优化）

第 3 步：L2 数据库设计
  数据库设计与E-R图  →  范式与关系模式分解
  （从现实建模到规范化）

第 4 步：L4 高级特性
  事务恢复与并发控制
  （理解 ACID 与并发控制原理）

第 5 步：L6 分布式与规范
  安全性与存取控制
  （生产环境安全实践）
```
