# Nginx — 环境配置与安装

## 信息来源
- **官方文档**：https://nginx.org/en/docs/ （✅ 可访问）

## Step 1: 安装（按系统选择）

### Ubuntu
```bash
sudo apt update
sudo apt install nginx -y
nginx -v   # 验证
```

### CentOS
```bash
sudo yum install epel-release -y
sudo yum install nginx -y
```

### macOS
```bash
brew install nginx
```

### Docker
```bash
docker run -d --name nginx -p 80:80 nginx
```

## Step 2: 源码编译安装（需定制模块时）

```bash
yum -y install gcc pcre-devel zlib-devel openssl openssl-devel
wget https://nginx.org/download/nginx-1.24.0.tar.gz
tar -zxvf nginx-1.24.0.tar.gz && cd nginx-1.24.0
./configure --prefix=/usr/local/nginx
make && make install
```

## Step 3: 基本管理命令

```bash
nginx -t              # 检查配置语法（修改配置后必做！）
nginx                 # 启动
nginx -s reload       # 热重载（不中断服务）
nginx -s stop         # 停止
nginx -s quit         # 优雅停止
```

### systemctl（yum/apt 安装）
```bash
sudo systemctl start nginx
sudo systemctl enable nginx   # 开机自启
sudo systemctl status nginx
```

## Step 4: Hello World 第一个网站

```bash
sudo mkdir -p /var/www/hello
echo "<h1>Hello from Nginx!</h1>" | sudo tee /var/www/hello/index.html
```

```nginx
# /etc/nginx/conf.d/hello.conf
server {
    listen 80;
    server_name localhost;
    root /var/www/hello;
    index index.html;
}
```

```bash
sudo nginx -t && sudo nginx -s reload
# 浏览器访问 http://你的服务器IP → "Hello from Nginx!"
```

## Step 5: 核心配置结构

```
nginx.conf
├── worker_processes    # 全局：worker 数
├── events {}           # 连接处理
└── http {}             # 核心配置
    ├── server {}       # 虚拟主机（可多个）
    │   ├── listen      # 端口
    │   ├── server_name # 域名
    │   └── location {} # URL 路由规则
    └── include conf.d/*.conf  # 引入外部配置
```

## 常见问题

| 问题 | 解决 |
|------|------|
| 访问不了 80 端口 | 检查防火墙 `firewall-cmd --add-port=80/tcp` + 云安全组 |
| `nginx -t` 报语法错误 | 检查每行末尾 `;`，检查 `{}` 配对 |
| 403 Forbidden | 检查文件权限和目录的 `x` 权限 |
| 修改配置不生效 | 必须 `nginx -s reload` 或 `systemctl reload nginx` |
