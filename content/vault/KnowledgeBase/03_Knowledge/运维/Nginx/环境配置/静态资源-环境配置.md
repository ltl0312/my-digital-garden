# Nginx — 静态资源与虚拟主机配置指南

> 基础安装请参考 <a href="obsidian://open?file=环境配置与项目初始化">Nginx 环境配置与安装</a>。

## Step 1: 部署静态网站

```bash
# ① 将打包后的前端文件放到站点目录
sudo mkdir -p /var/www/portfolio
sudo cp -r dist/* /var/www/portfolio/
```

```nginx
server {
    listen 80;
    server_name portfolio.local;
    root /var/www/portfolio;
    index index.html;

    location / {
        try_files $uri $uri/ /index.html;  # ② SPA History 模式
    }
}
```

## Step 2: root vs alias

| 指令 | 访问 `/img/logo.png` | 实际查找 |
|------|---------------------|---------|
| `root /var/www` | → | `/var/www/img/logo.png` |
| `alias /var/static/` | → | `/var/static/logo.png` |

```nginx
# root：root路径 + location路径 + 文件名（追加）
location /img/ { root /var/www; }   # → /var/www/img/logo.png

# alias：alias路径 + (请求去掉location部分)（替换）
location /img/ { alias /var/static/; }  # → /var/static/logo.png
```

## Step 3: 多站点（虚拟主机）

```nginx
# 按域名（推荐）
server { listen 80; server_name blog.test; root /var/www/blog; }
server { listen 80; server_name shop.test; root /var/www/shop; }

# 按端口
server { listen 8081; root /var/www/blog; }
server { listen 8082; root /var/www/shop; }
```

## Step 4: 动静态分离

```nginx
server {
    # 静态：Nginx 直接返回
    location /static/ {
        root /usr/share/nginx;
        try_files $uri =404;
    }
    # 动态：转发到后端
    location / {
        proxy_pass http://127.0.0.1:8080;
    }
}
```

## Step 5: SpringBoot + Vue 完整部署

```nginx
server {
    listen 81;
    server_name 你的IP;

    location / {
        root /usr/local/nginx/html/dist;  # 前端打包目录
        index index.html;
        try_files $uri $uri/ /index.html;
    }
    location /api/ {
        proxy_pass http://127.0.0.1:8080/;  # 后端 SpringBoot
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
}
```
