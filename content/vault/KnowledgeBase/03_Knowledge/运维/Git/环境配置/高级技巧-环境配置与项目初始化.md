## Step 1: 使用 Husky 管理 Hooks（Node.js 项目推荐）

```bash
npm install --save-dev husky
npx husky init                          # 初始化，创建 .husky/ 目录

echo "npm run lint" > .husky/pre-commit # 提交前运行 lint

# commitlint 检查提交信息格式
npm install --save-dev @commitlint/cli @commitlint/config-conventional
echo 'npx --no -- commitlint --edit "$1"' > .husky/commit-msg
echo "export default { extends: ['@commitlint/config-conventional'] };" > commitlint.config.js
```

## Step 2: 手动创建 Git Hook

```bash
cd .git/hooks/

cat > pre-commit << 'EOF'
#!/bin/sh
echo "🔍 运行代码检查..."
npm run lint
if [ $? -ne 0 ]; then
    echo "❌ Lint 检查失败，提交已中止"
    exit 1
fi
echo "✅ 代码检查通过"
EOF

chmod +x pre-commit          # macOS / Linux
```

### 常用 Hook 类型

| Hook | 触发时机 | 典型用途 |
|------|---------|---------|
| `pre-commit` | commit 之前 | lint、格式检查、单元测试 |
| `commit-msg` | 提交信息填写后 | 检查 Conventional Commits 格式 |
| `pre-push` | push 之前 | 运行完整测试套件 |
| `post-merge` | 合并完成后 | 重新安装依赖 |

## Step 3: 配置全局 .gitignore

```bash
touch ~/.gitignore_global
git config --global core.excludesfile ~/.gitignore_global
```

```gitignore
# ~/.gitignore_global — 对所有仓库生效
.DS_Store
Thumbs.db
*.swp
*.swo
.idea/
.vscode/
*.tmp
*.temp
```

## Step 4: 子模块初始化

```bash
git clone --recurse-submodules <url>        # 克隆时自动初始化子模块
git submodule update --init --recursive     # 已有仓库补拉子模块

# 配置自动递归（大型项目慎用）
git config --global submodule.recurse true
```

## Step 5: 仓库性能优化

```bash
# 启用文件系统监视器（加速 git status，大型仓库推荐）
git config core.fsmonitor true
# 需安装 Watchman：brew install watchman

# 启用未跟踪文件缓存
git config core.untrackedCache true

# 启用提交图（加速 git log）
git config core.commitGraph true
git commit-graph write --reachable

# GC 阈值
git config gc.auto 256
git config gc.autoPackLimit 32
```

## Step 6: 推荐别名扩展

```ini
[alias]
    # 撤销
    undo = reset --soft HEAD~1
    unstage = reset HEAD --

    # 查看
    lg = log --oneline --graph --all
    hist = log --pretty=format:"%h %ad | %s%d [%an]" --graph --date=short
    last = log -1 HEAD

    # 清理已合并分支
    cleanup = "!git branch --merged | grep -v '\\*\\|main\\|master\\|develop' | xargs -r git branch -d"

    # stash 快捷
    wip = stash push -u -m "WIP"
    unwip = stash pop
```
