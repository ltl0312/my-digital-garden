# Git — 环境配置与项目初始化

## 信息来源
- **官方文档**：https://git-scm.com/book/zh/v2 （✅ 可访问）
- **参考文章**：CSDN 程序员白城 Git 教程：https://blog.csdn.net/qq_16027093/article/details/130503317

## 前置条件
- 操作系统：Windows 10+ / macOS 12+ / Linux（Ubuntu 20.04+）
- 终端/命令行基础操作能力
- （可选）注册 GitHub / GitLab / Gitee 账号

## Step 1: 安装 Git

### Windows
```bash
# 下载 Git for Windows：https://gitforwindows.org/
# 安装建议：编辑器选 VS Code、PATH 选 "Git from the command line"、
#          行尾转换选 "Checkout Windows-style, commit Unix-style"
```

### macOS
```bash
brew install git                    # Homebrew（推荐）
# 或：xcode-select --install        # Xcode Command Line Tools
```

### Linux
```bash
# Ubuntu / Debian
sudo apt-get update && sudo apt-get install git

# CentOS / RHEL / Fedora
sudo yum install git                # 或 sudo dnf install git
```

## Step 2: 验证安装
```bash
git --version
# 预期输出：git version 2.45.0
```

## Step 3: 首次配置（必须！）

```bash
# 设置用户名和邮箱（每次提交附带）
git config --global user.name "你的名字"
git config --global user.email "你的邮箱@example.com"

# 设置默认编辑器（VS Code）
git config --global core.editor "code --wait"

# 设置默认分支名为 main
git config --global init.defaultBranch main

# 开启命令行颜色
git config --global color.ui auto

# 查看所有配置
git config --list
```

## Step 4: 生成 SSH 密钥

```bash
# 生成 Ed25519 密钥（比 RSA 更安全更快）
ssh-keygen -t ed25519 -C "your_email@example.com"
# 如不支持 Ed25519：ssh-keygen -t rsa -b 4096 -C "your_email@example.com"

# 查看公钥
cat ~/.ssh/id_ed25519.pub

# 将公钥添加到 GitHub/GitLab/Gitee 的 SSH Keys 设置中

# 测试连接
ssh -T git@github.com
# 预期输出：Hi username! You've successfully authenticated...
```

## Step 5: 初始化第一个仓库

```bash
# 方式一：从零初始化
mkdir my-project && cd my-project
git init
echo "# My Project" > README.md
git add README.md
git commit -m "chore: initial commit"

# 方式二：克隆现有仓库
git clone git@github.com:username/repo.git           # SSH（推荐）
git clone https://github.com/username/repo.git       # HTTPS
git clone git@github.com:username/repo.git my-folder # 指定目录名
```

## Step 6: 配置 .gitignore


## 核心配置项说明

| 配置项 | 推荐值 | 说明 |
|--------|--------|------|
| `user.name` | 真实姓名 | 显示在提交记录中 |
| `user.email` | GitHub 关联邮箱 | 与远程平台一致 |
| `core.editor` | `code --wait` | 提交信息编辑器 |
| `init.defaultBranch` | `main` | 新仓库默认分支名 |
| `core.autocrlf` | Win: `true`, Mac: `input` | 行尾符自动转换 |
| `pull.rebase` | `true` | pull 时用 rebase |

### 推荐别名
```bash
git config --global alias.co checkout
git config --global alias.br branch
git config --global alias.st status
git config --global alias.lg "log --oneline --graph --all"
git config --global alias.unstage "reset HEAD --"
git config --global alias.last "log -1 HEAD"
```

## 常见安装/配置问题

### 问题 1：`Permission denied (publickey)`
- **解决**：`eval "$(ssh-agent -s)" && ssh-add ~/.ssh/id_ed25519`

### 问题 2：Windows 中文文件名乱码
- **解决**：`git config --global core.quotepath false`

### 问题 3：`git commit` 进入 vim 不知道怎么退出
- **解决**：按 `Esc`，输入 `:wq` 回车；或提前配置编辑器
