# Git — 分支管理环境配置

> 本指南聚焦于优化 Git 分支和合并操作。基础安装请参考 <a href="obsidian://open?file=环境配置与项目初始化">Git 环境配置与项目初始化</a>。

## 信息来源
- **官方文档**：https://git-scm.com/book/zh/v2/Git-分支-分支简介 （✅ 可访问）

## Step 1: 配置默认分支名

```bash
git config --global init.defaultBranch main
```

## Step 2: 配置 Pull 策略

```bash
# 默认用 rebase 保持线性历史
git config --global pull.rebase true

# 仅快进合并（冲突时拒绝）
git config --global pull.ff only
```

## Step 3: 配置 Merge 冲突解决工具

```bash
# VS Code
git config --global merge.tool vscode
git config --global mergetool.vscode.cmd "code --wait \$MERGED"

# Meld（跨平台可视化工具）
# brew install meld / sudo apt-get install meld
git config --global merge.tool meld

# 启动：git mergetool
```

## Step 4: 配置 Diff 算法

```bash
git config --global diff.algorithm histogram   # 对函数重排等场景更好
git config --global diff.renames copies         # 识别文件移动和重命名
git config --global diff.context 3              # diff 显示 3 行上下文
```

## Step 5: 自动清理远程跟踪分支

```bash
git config --global fetch.prune true
# git fetch 时自动删除本地对应已删除的远程分支
```

## Step 6: 分支命名规范建议

| 分支类型 | 命名格式 | 示例 |
|---------|---------|------|
| 功能分支 | `feature/<描述>` | `feature/user-authentication` |
| Bug 修复 | `bugfix/<描述>` | `bugfix/login-redirect-loop` |
| 热修复 | `hotfix/<描述>` | `hotfix/v2.1.1-payment-crash` |
| 发布分支 | `release/<版本>` | `release/v2.2.0` |
| 实验分支 | `experiment/<描述>` | `experiment/new-cache-strategy` |

> **💡 补充**：在 `.github/pull_request_template.md` 中创建 PR 模板，规范描述格式和检查清单。
