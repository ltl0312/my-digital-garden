# Git — 基本操作环境配置

> 本指南聚焦于优化 Git 日常操作体验。基础安装请参考 <a href="obsidian://open?file=环境配置与项目初始化">Git 环境配置与项目初始化</a>。

## 信息来源
- **官方文档**：https://git-scm.com/book/zh/v2/自定义-Git-配置-Git （✅ 可访问）

## Step 1: 配置 Diff 工具

```bash
# 使用 VS Code 作为 diff 工具
git config --global diff.tool vscode
git config --global difftool.vscode.cmd "code --wait --diff \$LOCAL \$REMOTE"

# 推荐：安装 delta 获得更好的 diff 显示
# https://github.com/d11wtq/delta
# git config --global core.pager delta
# git config --global interactive.diffFilter 'delta --color-only'
```

## Step 2: 配置 Merge 工具

```bash
# 使用 VS Code 作为合并工具
git config --global merge.tool vscode
git config --global mergetool.vscode.cmd "code --wait \$MERGED"

# 启动合并工具：git mergetool
```

## Step 3: 自动纠错

```bash
git config --global help.autocorrect 20
# git comit → 等待 2 秒后自动执行为 git commit
```

## Step 4: 行尾符处理

```bash
# Windows（提交转 LF，检出转 CRLF）
git config --global core.autocrlf true

# macOS / Linux（提交转 LF，检出不变）
git config --global core.autocrlf input
```

## Step 5: 输出着色优化

```bash
git config --global color.ui auto

git config --global color.diff.meta "yellow bold"
git config --global color.diff.frag "magenta bold"
git config --global color.diff.old "red bold"
git config --global color.diff.new "green bold"

git config --global color.status.added "green"
git config --global color.status.changed "yellow"
git config --global color.status.untracked "cyan"
```

## 完整配置文件示例（~/.gitconfig）

```ini
[user]
    name = 你的名字
    email = your@email.com

[core]
    editor = code --wait
    autocrlf = input
    quotepath = false
    pager = less -F -X

[init]
    defaultBranch = main

[color]
    ui = auto

[alias]
    co = checkout
    br = branch
    ci = commit
    st = status
    lg = log --oneline --graph --all
    unstage = reset HEAD --
    last = log -1 HEAD
    undo = reset --soft HEAD~1

[pull]
    rebase = true

[push]
    default = simple

[help]
    autocorrect = 20
```
