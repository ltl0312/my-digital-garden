# 多端发布 — 部署运维环境配置指南

## 前置条件
- 云服务器一台（阿里云/腾讯云/AWS，推荐 CentOS 7+ / Ubuntu 20.04+）
- 已购买域名（国内需完成备案）
- Docker 已安装（参考下方 Step 1）

## Step 1: 服务器基础环境

```bash
# SSH 登录服务器
ssh root@your-server-ip

# 安装 Docker（Ubuntu 示例）
curl -fsSL https://get.docker.com | sh
sudo usermod -aG docker $USER  # 免 sudo 运行 docker

# 安装 Docker Compose
sudo curl -L "https://github.com/docker/compose/releases/latest/download/docker-compose-$(uname -s)-$(uname -m)" -o /usr/local/bin/docker-compose
sudo chmod +x /usr/local/bin/docker-compose

# 验证
docker --version        # Docker version 24.x.x
docker-compose --version
```

## Step 2: 域名与 SSL 证书

```bash
# 1. DNS 配置
# 域名服务商控制台 → 添加 A 记录：
# @     → your-server-ip
# www   → your-server-ip
# api   → your-server-ip

# 2. 安装 Certbot（Let's Encrypt 免费 SSL）
sudo apt install certbot python3-certbot-nginx -y    # Ubuntu
# sudo yum install certbot python3-certbot-nginx -y  # CentOS

# 3. 申请证书
sudo certbot --nginx -d example.com -d www.example.com -d api.example.com
# 按提示输入邮箱 → 同意条款 → 选择是否重定向 HTTP→HTTPS（推荐选 2）
# 预期输出：Congratulations! Your certificate and chain have been saved...

# 4. 验证自动续期
sudo certbot renew --dry-run
# 预期输出：The dry run was successful.
```

## Step 3: 前端 Web 部署（Vue 3 + Nginx）

```bash
# 1. 本地构建
cd my-web-app
npm run build
# 输出物在 dist/ 目录 → 上传到服务器

# 2. 上传到服务器
scp -r dist/* root@your-server-ip:/var/www/my-app/

# 3. Nginx 配置 /etc/nginx/sites-available/my-app
```

```nginx
# /etc/nginx/sites-available/my-app
server {
    listen 80;
    server_name example.com www.example.com;
    return 301 https://$host$request_uri;  # 强制 HTTPS
}

server {
    listen 443 ssl http2;
    server_name example.com www.example.com;

    ssl_certificate     /etc/letsencrypt/live/example.com/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/example.com/privkey.pem;

    root /var/www/my-app;
    index index.html;

    # SPA 路由重写（Vue Router / React Router 必须）
    location / {
        try_files $uri $uri/ /index.html;
    }

    # API 反向代理到后端
    location /api/ {
        proxy_pass http://localhost:8080;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }

    # 静态资源缓存
    location ~* \.(js|css|png|jpg|svg|woff2)$ {
        expires 1y;
        add_header Cache-Control "public, immutable";
    }
}
```

```bash
# 4. 启用站点并重载
sudo ln -s /etc/nginx/sites-available/my-app /etc/nginx/sites-enabled/
sudo nginx -t              # 测试配置文件
sudo systemctl reload nginx
```

## Step 4: 后端部署（Spring Boot + MySQL + Redis — Docker Compose 全栈）

```yaml
# docker-compose.yml — 一键启动全栈
version: '3.8'
services:
  mysql:
    image: mysql:8.0
    environment:
      MYSQL_ROOT_PASSWORD: ${DB_ROOT_PASSWORD}
      MYSQL_DATABASE: myapp
    volumes:
      - mysql_data:/var/lib/mysql
    restart: unless-stopped

  redis:
    image: redis:7-alpine
    volumes:
      - redis_data:/data
    restart: unless-stopped

  backend:
    build: ./backend
    ports:
      - "8080:8080"
    environment:
      SPRING_DATASOURCE_URL: jdbc:mysql://mysql:3306/myapp
      SPRING_REDIS_HOST: redis
    depends_on:
      - mysql
      - redis
    restart: unless-stopped

volumes:
  mysql_data:
  redis_data:
```

```bash
# 启动全部服务
docker-compose up -d
# 预期输出：Creating network ... Creating mysql ... Creating redis ... Creating backend ... done

# 查看运行状态
docker-compose ps
# 验证：curl http://localhost:8080/api/hello
```

## 常见安装/配置问题

1. **Nginx 报 403 Forbidden？**
   → 检查 `/var/www/my-app` 目录权限：`sudo chmod -R 755 /var/www/my-app`，确保 Nginx 用户（www-data）有读取权限

2. **SSL 证书到期了网站打不开？**
   → `sudo certbot renew` 手动续期。检查 crontab 定时任务：`sudo crontab -l | grep certbot`。Let's Encrypt 证书有效期 90 天。

3. **Docker 容器之间无法通信？**
   → 确保在同一个 docker-compose.yml 中定义 → Docker Compose 会自动创建网络。不同 compose 文件的容器通信需要手动创建外部网络：`docker network create shared`。
