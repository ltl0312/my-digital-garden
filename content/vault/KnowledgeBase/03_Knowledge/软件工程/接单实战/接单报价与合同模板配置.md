## Step 3: 合同关键条款清单

> **⚠️ 声明**：以下为合同**应包含的关键条款清单**，非法律意见。正式合同建议使用电子合同平台的标准模板，或咨询律师。本清单用于与客户沟通时检查合同是否覆盖了核心风险点。

### 必须包含的条款

| 条款类别 | 关键内容 | 为什么重要 |
|----------|---------|-----------|
| **付款节点** | 30% 定金签合同后支付，40% 进度款核心功能验收后支付，30% 尾款全部完成后交付源码前支付 | 保护现金流，任何阶段客户毁约你都有保障 |
| **交付标准** | 以附件《功能清单》为准，功能正常运行即视为交付完成 | 锁定验收标准，防止客户无限要求修改 |
| **需求变更** | 新增功能需书面确认并单独报价，不在原报价范围内 | 防止需求蔓延 |
| **源码归属** | 尾款付清后源码版权转移给甲方；尾款未付清前版权归乙方 | 法理上的保护——不只是防骗态度，而是有法律依据的权利声明 |
| **售后维保** | 免费维保期 X 个月，仅限修复清单内功能的 Bug。新功能需另签合同 | 防止变成免费长期维护 |
| **违约责任** | 甲方逾期付款按日收违约金；乙方逾期交付同理 | 双向约束 |

## Step 4: 电子合同签署流程

```bash
# 腾讯电子签（微信小程序）操作流程：
# 1. 微信搜索"腾讯电子签"进入小程序

# 6. 双方签署完成后 → 合同生效，平台存证

# 费用：个人用户每月有免费签署额度
```

## 常见安装/配置问题

1. **合同金额太小，签电子合同会不会小题大做？**
   → 5000 元以上的项目建议都签。腾讯电子签免费，操作只需 3 分钟。不签合同的风险是 100% 损失，签合同的成本是 3 分钟——收益远大于成本。

2. **客户觉得功能清单太麻烦？**
   → 解释话术："这份清单不是不信任你，而是保护咱们双方。有了它，你知道我肯定会把这些功能做好，我也知道你不会中途让我做清单之外的事。这是行业标准做法。"

3. **客户要求报价打折？**
   → 可以打折，但必须删功能。不要在工作量上打折——"你的预算我可以做到 X 功能（从清单中删掉 Y 和 Z），这些功能后续可以追加"。这样你不亏，客户也得到了"降价"。
