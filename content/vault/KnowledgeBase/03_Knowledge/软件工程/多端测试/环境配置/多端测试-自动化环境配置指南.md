## Step 1: Web 端自动化测试 — Playwright

```bash
# 1. 安装 Playwright
npm init -y
npm install -D @playwright/test

# 2. 安装浏览器
npx playwright install
# 会下载 Chromium、Firefox、WebKit 三个浏览器

# 3. 创建第一个测试文件 tests/example.spec.ts
```

```typescript
// tests/example.spec.ts — 最简单的端到端测试
import { test, expect } from '@playwright/test';

test('首页可以正常加载', async ({ page }) => {
  await page.goto('http://localhost:5173');
  await expect(page).toHaveTitle(/我的应用/);
});

test('登录流程正常', async ({ page }) => {
  await page.goto('http://localhost:5173/login');
  await page.fill('input[name="username"]', 'testuser');
  await page.fill('input[name="password"]', 'password123');
  await page.click('button[type="submit"]');
  await expect(page).toHaveURL(/.*dashboard/);
});

// 运行：npx playwright test
```

### 浏览器兼容性测试

```typescript
// playwright.config.ts — 配置多浏览器测试
import { defineConfig } from '@playwright/test';
export default defineConfig({
  projects: [
    { name: 'chromium', use: { browserName: 'chromium' } },
    { name: 'firefox',  use: { browserName: 'firefox' } },
    { name: 'webkit',   use: { browserName: 'webkit' } },   // Safari
    { name: 'edge',     use: { browserName: 'chromium', channel: 'msedge' } },
  ],
});
// 运行：npx playwright test → 自动在所有浏览器中执行
```

## Step 2: 前端单元测试 — Vitest / Jest

```bash
# Vitest（推荐，与 Vite 深度集成）
npm install -D vitest @vue/test-utils jsdom

# 或 Jest（更传统的选择）
npm install -D jest @testing-library/vue
```

```typescript
// 示例：Vue 组件单元测试（Vitest）
import { describe, it, expect } from 'vitest'
import { mount } from '@vue/test-utils'
import LoginForm from '@/components/LoginForm.vue'

describe('LoginForm', () => {
  it('用户名和密码为空时禁用登录按钮', () => {
    const wrapper = mount(LoginForm)
    const button = wrapper.find('button[type="submit"]')
    expect(button.element.disabled).toBe(true)
  })

  it('填写完整表单后启用登录按钮', async () => {
    const wrapper = mount(LoginForm)
    await wrapper.find('input[name="username"]').setValue('user')
    await wrapper.find('input[name="password"]').setValue('pass')
    const button = wrapper.find('button[type="submit"]')
    expect(button.element.disabled).toBe(false)
  })
})
```

## Step 3: 性能测试 — JMeter

```bash
# 1. 下载 JMeter
# 访问 https://jmeter.apache.org/download_jmeter.cgi
# 下载 apache-jmeter-5.6.x.zip → 解压

# 2. 启动 JMeter（Windows）
cd apache-jmeter-5.6.x/bin
jmeter.bat
# macOS/Linux: ./jmeter.sh

# 3. 创建测试计划
# ① 右键 Test Plan → Add → Threads → Thread Group
#    线程数: 100（模拟100个并发用户）
#    Ramp-Up: 10秒（10秒内启动全部线程）
#    循环次数: 10（每个用户执行10次）
# ② 右键 Thread Group → Add → Sampler → HTTP Request
#    服务器: localhost, 端口: 8080, 路径: /api/products
# ③ 右键 Thread Group → Add → Listener → View Results Tree / Summary Report
# ④ 点击绿色三角启动测试

# 关键指标解读：
# - Average: 平均响应时间（ms），应 ≤ 目标值
# - Throughput: 吞吐量（请求/秒），越高越好
# - Error%: 错误率，应 = 0%
```

## 常见安装/配置问题

1. **Playwright 安装报错 "host system misses dependencies"（Linux）？**
   → `npx playwright install-deps` 自动安装所有系统依赖库

2. **JMeter 启动后界面乱码？**
   → `bin/jmeter.properties` 中修改 `jmeter.hidpi.mode=true` 并添加中文语言包

3. **Vitest 报 "Cannot find module 'vue'"？**
   → 确认 `vite.config.ts` 中添加了 `@vitejs/plugin-vue` 插件，且 vitest 配置中 `environment: 'jsdom'`
