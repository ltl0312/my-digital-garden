# 多端项目 — 跨平台开发环境配置指南

- **Flutter 官方文档**：https://docs.flutter.dev ✅ 可访问

## 前置条件
- Node.js 18+（React Native / Electron / Uni-app）
- Git 2.30+
- 各平台额外依赖见下方 Step 1

## Step 1: 按目标平台选择环境

### Web 端（Vue 3 + Vite — 前端主流方案）

```bash
# 1. 确保 Node.js ≥ 18
node -v

# 2. 创建 Vue 3 + Vite 项目
npm create vite@latest my-web-app -- --template vue-ts
cd my-web-app
npm install

# 3. 安装 Vue Router + Pinia（SPA 状态与路由）
npm install vue-router@4 pinia

# 4. 启动开发服务器
npm run dev
# 预期输出：VITE v5.x.x  ready in xxx ms → http://localhost:5173/
```

### Flutter（移动端跨平台 — iOS + Android）

```bash
# 1. 下载 Flutter SDK
# Windows/macOS/Linux: https://docs.flutter.dev/get-started/install

# 2. 验证环境（会检查 Android SDK / Xcode / Chrome 等）
flutter doctor
# 预期输出：全部 ✓（或根据提示修复缺失项）

# 3. 创建项目
flutter create my_flutter_app
cd my_flutter_app

# 4. 运行（连接真机或启动模拟器后）
flutter run
```

### React Native（移动端跨平台 — React 生态）

```bash
# 1. 创建项目（推荐 Expo 框架，降低原生配置复杂度）
npx create-expo-app@latest my-rn-app
cd my-rn-app

# 2. 启动
npx expo start
# 扫码安装 Expo Go App 即可在真机上预览
```

### Tauri（桌面端 — Rust + Web 前端，体积小）

```bash
# 1. 安装 Rust（Tauri 后端）
# Windows: https://rustup.rs → 下载 rustup-init.exe
# macOS/Linux: curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh

# 2. 安装 Tauri CLI
npm install -g @tauri-apps/cli@latest

# 3. 创建项目（以 Vue 为例）
npm create tauri-app@latest my-tauri-app -- --template vue-ts
cd my-tauri-app
npm install

# 4. 启动开发模式
npm run tauri dev
```

### Electron（桌面端 — Web 技术栈，跨平台）

```bash
# 1. 创建项目
mkdir my-electron-app && cd my-electron-app
npm init -y
npm install electron --save-dev

# 2. 最小主进程代码（main.js）
# const { app, BrowserWindow } = require('electron')
# app.whenReady().then(() => {
#   new BrowserWindow().loadURL('https://your-app.com')
# })
# 完整示例见官方 Quick Start

# 3. 启动
npx electron .
```

### Uni-app（国内多端 — 小程序 + App + H5 统一开发）

```bash
# 1. 安装 HBuilderX（官方 IDE）或使用 CLI
npm install -g @dcloudio/uvm

# 2. 创建项目（Vue 3 版本）
npx degit dcloudio/uni-preset-vue#vite-ts my-uni-app
cd my-uni-app
npm install

# 3. 运行到各端
npm run dev:h5          # H5 开发
npm run dev:mp-weixin   # 微信小程序开发（需微信开发者工具）
```

## Step 2: 服务端环境（后端 — Java Spring Boot 示例）

```bash
# 1. JDK 17+ 安装验证
java -version
# 预期输出：openjdk version "17.0.x" ...

# 2. 创建 Spring Boot 3.x 项目
# 方式一：通过 Spring Initializr
# 访问 https://start.spring.io → 选择 Spring Boot 3.x + Java 17 + Maven

# 方式二：通过 CLI（需安装 Spring CLI）
spring init --java-version=17 --dependencies=web,data-jpa,mysql my-backend
cd my-backend
./mvnw spring-boot:run
```

## Step 3: 数据库环境

```bash
# MySQL 8.0（Docker 方式，推荐）
docker run -d --name mysql-dev \
  -e MYSQL_ROOT_PASSWORD=root123 \
  -e MYSQL_DATABASE=myapp \
  -p 3306:3306 \
  mysql:8.0

# Redis 7（Docker 方式）
docker run -d --name redis-dev \
  -p 6379:6379 \
  redis:7-alpine
```

## Step 4: 最小可运行示例 — 全栈 "Hello World"

**后端** (Spring Boot `HelloController.java`):
```java
@RestController
public class HelloController {
    @GetMapping("/api/hello")
    public Map<String, String> hello() {
        return Map.of("message", "Hello from Backend!");
    }
}
```

**前端** (Vue 3 `App.vue`):
```vue
<script setup>
import { ref, onMounted } from 'vue'
const message = ref('Loading...')
onMounted(async () => {
  const res = await fetch('http://localhost:8080/api/hello')
  const data = await res.json()
  message.value = data.message
})
</script>
<template>
  <h1>{{ message }}</h1>
</template>
```

## 常见安装/配置问题

1. **Flutter doctor 报 Android SDK 缺失？**
   → 安装 Android Studio → SDK Manager → 勾选 Android SDK Platform 33+ 和 Android SDK Command-line Tools

2. **Tauri Windows 编译报错？**
   → 需安装 Visual Studio Build Tools + "C++桌面开发"工作负载 + Windows 10 SDK

3. **小程序开发工具打不开项目？**
   → 微信开发者工具 → 设置 → 安全 → 开启"服务端口"。Uni-app 需在 HBuilderX 中配置微信开发者工具路径。
