## 跨学科纵深

以计算机学科为核心轴线，从底层硬件到顶层智能，一脉贯通。所有技术的"跨学科溯源"字段应在此纵深轴上找到对应的关联层级。

| 层级 | 名称 | 包含内容 | 与计算机学科的关系 |
|------|------|----------|-------------------|
| **XD-0** | 物理与电路 | 半导体物理、PN 结、晶体管(MOSFET)、逻辑门(与或非)、布尔代数、触发器/锁存器 | → 一切计算设备的物理基石 |
| **XD-1** | 数字系统与体系结构 | 组合逻辑/时序逻辑、ALU 算术逻辑单元、寄存器/计数器、冯·诺依曼架构、CPU 指令集(x86/ARM/RISC-V)、流水线/超标量、缓存层次结构(L1/L2/L3) | → 计算机组成原理的硬件实现 |
| **XD-2** | 操作系统 | 进程/线程模型、内存管理(虚拟内存/分页/分段)、文件系统、I/O 与中断、同步互斥(信号量/Mutex/条件变量)、调度算法 | → 软件与硬件之间的桥梁 |
| **XD-3** | 计算机网络 | TCP/IP 协议栈、HTTP/HTTPS、DNS、路由与交换、网络安全(TLS/防火墙) | → 单机计算扩展到分布式系统 |
| **XD-4** | 编程语言与编译 | 编译原理(词法/语法/语义分析、中间代码、优化)、类型系统、运行时(GC/JIT)、编程范式(OOP/FP/RP) | → 人类思想到机器指令的翻译 |
| **XD-5** | 数据结构与算法 | 数组/链表/树/图/哈希表、排序/搜索/图论/DP/贪心/分治、复杂度分析(P/NP/NPC) | → 计算机科学的核心方法论 |
| **XD-6** | 软件工程与架构 | 设计模式(23种 GoF)、SOLID 原则、DDD 领域驱动设计、微服务/单体、事件驱动、CQRS | → 大规模软件系统的组织方法论 |
| **XD-7** | 数据与智能 | 数据库系统(关系型/NoSQL/NewSQL)、大数据处理(Hadoop/Spark)、机器学习(监督/无监督/强化学习)、深度学习(CNN/RNN/Transformer)、自然语言处理、计算机视觉 | → 从存储数据到理解数据的跨越 |
| **XD-8** | 人工智能与前沿 | 大语言模型(LLM)、Agent 智能体、多模态模型、强化学习高级应用、AI 安全与对齐 | → 计算机科学的终极前沿 |

> **使用规则**：在为任何技术写"跨学科溯源"时，沿此纵深轴向上游和下游追溯。例如：
> - Java synchronized → XD-2(OS Mutex) → XD-1(CPU 原子指令如 CMPXCHG) → XD-0(锁存器与状态保持)
> - MySQL B+Tree → XD-5(数据结构) → XD-1(磁盘 I/O 与页缓存) → XD-2(文件系统)
> - Vue 3 Proxy → XD-4(元编程/反射) → XD-6(拦截器/代理设计模式)
> - LLM Token 预测 → XD-7(深度学习) → XD-5(概率统计) → XD-4(自动微分) → XD-1(GPU 并行计算) |

## 使用规范（所有指令强制执行）

1. 所有原子笔记的 `知识体系` YAML 字段必须严格从本文档中选择 `{{技术栈}} → {{L?}} {{层级名}}` 格式填写。技术栈名称使用：`Java 后端`、`Node.js 后端 / NestJS`、`前端`、`数据库`、`DevOps/运维`、`软件工程`、`跨学科纵深`。
2. `标签` 中的技术栈标签必须与本文档中的技术栈名称一致（如 `Java/SpringBoot`、`前端/Vue`、`数据库/MySQL`、`后端/NestJS`、`软件工程/项目管理`、`运维/Docker`）。
3. 如果某个技术无法在本文档中找到对应层级，先判断是否属于跨学科基础（XD-X 层级），若仍不匹配，在笔记中标记 `[[技术划分]]` 并向我报告。
4. 本文档随知识库增长定期更新。
