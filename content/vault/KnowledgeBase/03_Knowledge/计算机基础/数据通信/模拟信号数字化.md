# 模拟信号数字化

## 📍 知识体系定位
- **所属技术栈**：跨学科纵深
- **所在层级**：XD-3 计算机网络 → 物理层编码
- **上游依赖**：<a href="obsidian://open?file=通信系统基础与信道">数据通信-通信系统基础与信道</a>
- **下游延伸**：音频编解码（MP3/AAC）、视频编解码（H.264）
- **同级技术**：图像压缩（JPEG）、无损压缩（ZIP）

## 概述（Overview）
> 将连续的模拟信号转换为离散的数字信号需要三步：**抽样**（时间离散化，按 $f_s \ge 2f_m$ 取值）、**量化**（幅度离散化，用有限个离散值逼近连续值）、**编码**（用二进制表示量化值）。PCM（脉冲编码调制）是经典的 A/D 转换标准；DPCM 利用相邻样值的相关性只传差值以压缩数据量。

## 设计初衷（Motivation）

### 均匀量化 vs 非均匀量化

| 维度 | 均匀量化 | 非均匀量化 |
|------|---------|-----------|
| 量化间隔 | 全部相等 | 小信号间隔小，大信号间隔大 |
| 实现复杂度 | 简单 | 复杂（需压缩-扩张器） |
| 小信号 SNR | **差**（量化误差占比大） | **好** |
| 大信号 SNR | 好 | 可接受 |
| 应用 | 简单系统 | 语音通信（电话网标准） |

### 设计思想
语音信号的幅度分布不均匀——小幅度信号出现概率远高于大幅度信号。非均匀量化通过对小信号使用更细的量化间隔，使小信号的量化噪声与信号幅度成比例，改善了主观听觉质量。电话网中的 A 律和 μ 律压扩标准即基于此原理。

### 跨学科溯源
- 抽样定理 → XD-5（奈奎斯特-香农采样定理：带限信号的完美重建条件）
- 量化噪声 → XD-5（信号处理：量化误差在 ±Δ/2 内均匀分布，SNR = 6.02n + 1.76 dB）

## 实现（Implementation）

### PCM 三步骤

```
模拟信号 → [抽样] → 离散时间信号 → [量化] → 离散幅度信号 → [编码] → 二进制码流
         f_s ≥ 2f_m         N=2^n 个量化级          n 位二进制
```

### 编码技术对比

| 技术 | 原理 | 特点 |
|------|------|------|
| PCM | 抽样 → 量化 → 编码 | 标准方案，每样值 n 位 |
| 增量调制(ΔM) | 只用 1 位表示相邻样值增减 | 极简，但斜率过载 |
| DPCM | 传差值（实际值 - 预测值）| 利用相关性大幅压缩数据量 |

> **💡 补充**：CD 音质 = PCM 44.1kHz × 16bit × 2 声道 = 1.411 Mbps。电话音质 = PCM 8kHz × 8bit = 64 kbps。这是为什么电话听起来比 CD 差——采样率和量化位数都更低。
