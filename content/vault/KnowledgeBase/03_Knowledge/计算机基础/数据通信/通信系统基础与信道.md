# 通信系统基础与信道

## 📍 知识体系定位
- **所属技术栈**：跨学科纵深
- **所在层级**：XD-3 计算机网络 → 物理层基础
- **上游依赖**：XD-0 物理（电磁波、光纤全反射）
- **下游延伸**：TCP/IP 协议栈、5G 通信
- **同级技术**：计算机网络（上层协议）、信号处理

## 概述（Overview）
> 通信系统的五要素模型——信源 → 发送设备 → 信道 → 接收设备 → 信宿。**奈奎斯特定理**给出无噪声信道的最大码元速率，**香农公式**给出有噪声信道的极限信息速率。数字通信相比模拟通信具有抗干扰强、易加密、易集成三大优势。

## 设计初衷（Motivation）

### 数字通信 vs 模拟通信

| 维度 | 模拟通信 | 数字通信 |
|------|---------|---------|
| 抗干扰 | 噪声累积放大 | 可再生中继（判决再整形） |
| 加密 | 困难 | 易加密（数字逻辑XOR） |
| 集成化 | 困难 | 易（数字芯片） |
| 带宽 | 窄 | 宽（代价） |

### 香农公式的核心意义

$$C = B \log_2(1 + \frac{S}{N})$$

- $C$：信道极限信息速率（bps）
- $B$：信道带宽（Hz）
- $S/N$：信噪比（线性值，非 dB）

> **核心推论**：带宽与信噪比可以互换——增加带宽可以容忍更低的信噪比；提升信噪比可以节省带宽。这是现代通信系统设计的理论基础。

### 跨学科溯源
- 奈奎斯特采样定理 → XD-5（信号处理：$f_s \ge 2f_m$ 是完美重建的充分必要条件）
- 香农公式 → XD-5（信息论：熵与信道容量的数学关系，香农 1948 年奠基）

## 实现（Implementation）

### 性能指标换算

```
码元速率（RB）：单位 Baud，每秒传输的码元数
信息速率（Rb）：单位 bps，每秒传输的比特数
关系：Rb = RB × log₂(M)
  M=2（二进制）：Rb = RB
  M=4（四进制）：Rb = 2×RB
```
