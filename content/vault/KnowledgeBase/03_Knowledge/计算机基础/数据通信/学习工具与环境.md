# 数据通信 — 学习环境与工具

## 信息来源
- **GNU Radio**：https://www.gnuradio.org/（开源 SDR 软件无线电框架）
- **Wireshark**：https://www.wireshark.org/（抓包分析 OSI 各层协议）

## 前置条件
- Python 3（GNU Radio 依赖）

## Step 1: 推荐学习工具

| 工具 | 用途 |
|------|------|
| **GNU Radio** | 可视化搭建通信系统（信号源→调制→信道模拟→解调→误码率分析） |
| **Wireshark** | 捕获并分析以太网/WiFi 数据包，查看 OSI 各层封装 |
| **MATLAB/Octave** | 绘制眼图、计算误码率曲线、仿真调制解调 |

## Step 2: 验证 Wireshark

1. 安装 Wireshark → 选择网卡 → 开始捕获
2. 浏览器访问任意网站 → 停止捕获
3. 过滤 `http` 或 `tcp` → 展开查看以太网帧头 → IP 头 → TCP 头 → HTTP 数据

## Step 3: 眼图概念验证（Octave）

```matlab
% 生成随机基带信号 + 噪声
data = sign(randn(1, 1000));
% 叠加显示所有码元波形 → 观察眼图开口大小
% 眼图开口越大 → 码间串扰越小 → 误码率越低
```

## 常见问题

1. **通信理论太抽象**：GNU Radio 将每个模块（调制器/信道/解调器）变成可拖拽的方块，输入音频信号看输出波形。
2. **OSI 模型记不住**：Wireshark 抓一个 HTTP 包 → 展开每一层 → 物理现象（实际字节）vs 抽象概念的联系。
