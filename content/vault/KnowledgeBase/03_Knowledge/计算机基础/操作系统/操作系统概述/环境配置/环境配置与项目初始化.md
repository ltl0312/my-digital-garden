# 操作系统学习 — 环境配置与项目初始化

## 信息来源
- **官方文档**：https://www.kernel.org/（Linux Kernel）、https://www.linux.org/（Linux 社区）
- **参考文章**：
  - 王道操作系统考研系列：https://blog.csdn.net/realoser/article/details/142601685

> ⚠️ 操作系统的学习环境主要是 Linux 虚拟机，用于观察进程、内存、文件系统等 OS 概念的实际表现。

## 前置条件
- VirtualBox 7.0+ 或 VMware Workstation 17+
- 至少 4GB 空闲内存、20GB 磁盘空间
- 支持虚拟化技术的 CPU（Intel VT-x / AMD-V，BIOS 中已开启）

## Step 1: 安装 Linux 虚拟机

### Windows 宿主（VirtualBox）
```bash
# 1. 下载 VirtualBox: https://www.virtualbox.org/
# 2. 下载 Ubuntu 22.04 LTS ISO: https://ubuntu.com/download/server
# 3. 在 VirtualBox 中新建虚拟机：
#    - 类型: Linux, 版本: Ubuntu (64-bit)
#    - 内存: 2048MB+
#    - 磁盘: 20GB 动态分配
# 4. 启动虚拟机，选择 ISO 镜像，完成 Ubuntu 安装
```

### macOS 宿主（UTM / VMware Fusion）
```bash
# 使用 UTM（免费）或 VMware Fusion 安装 Ubuntu Server
```

## Step 2: 验证安装
```bash
# 查看内核版本
uname -r
# 预期输出: 5.15.0-xxx-generic 或 6.x.x-xxx-generic

# 查看系统信息
cat /etc/os-release
# 预期输出: Ubuntu 22.04.x LTS

# 查看 CPU 信息
lscpu | head -10

# 查看内存信息
```

## Step 3: 初始化学习环境
```bash

# 安装进程/内存监控工具

# 安装 man 手册（C 标准库和系统调用文档）
sudo apt install -y manpages-dev manpages-posix-dev
```

## Step 4: 最小可运行示例 — 观察进程

```c
// test_process.c — 创建一个子进程，观察进程并发
#include <stdio.h>
#include <unistd.h>
#include <sys/wait.h>

int main() {
    pid_t pid = fork();  // 创建子进程

    if (pid == 0) {
        // 子进程执行的代码
        printf("[子进程] PID = %d, 父进程 PID = %d\n", getpid(), getppid());
    } else if (pid > 0) {
        // 父进程执行的代码
        printf("[父进程] PID = %d, 子进程 PID = %d\n", getpid(), pid);
        wait(NULL);  // 等待子进程结束
    } else {
        printf("fork 失败\n");
        return 1;
    }
    return 0;
}
```

```bash
# 编译运行
gcc test_process.c -o test_process
./test_process
# 预期输出（顺序可能不同）：
# [父进程] PID = 12345, 子进程 PID = 12346
# [子进程] PID = 12346, 父进程 PID = 12345
```

## Step 5: 核心配置项说明

| 配置项 | 默认值 | 推荐值 | 原因 |
|--------|--------|--------|------|
| 虚拟机内存 | 1024MB | 2048MB+ | 编译大型项目（如 Linux 内核）需要足够内存 |
| 虚拟磁盘 | 10GB | 20GB+ | 安装开发工具链和内核源码后占用较大 |
| CPU 核心数 | 1 | 2+ | 观察多核调度和并行执行需要多核 |
| 网络模式 | NAT | NAT 或 桥接 | NAT 足够学习使用，桥接用于网络编程实验 |

## 常见安装/配置问题

1. **VT-x/AMD-V 不可用**：进入 BIOS/UEFI → Advanced → CPU Configuration → 开启 Intel Virtualization Technology 或 SVM Mode
2. **虚拟机启动黑屏**：检查 ISO 镜像完整性（校验 SHA256），或尝试关闭 VirtualBox 的 3D 加速
3. **共享文件夹无法访问**：`sudo usermod -aG vboxsf $USER` 然后重启虚拟机
