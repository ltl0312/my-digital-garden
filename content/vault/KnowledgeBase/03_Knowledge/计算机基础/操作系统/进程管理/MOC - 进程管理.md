## 推荐学习路径

```
第 1 步：进程基础
  进程的概念、组成与状态  →  进程通信
  （理解进程是什么 + 进程间如何通信）

第 2 步：线程与调度
  线程与多线程模型  →  处理机调度与调度算法
  （理解线程与进程的区别 + OS 如何分配 CPU）

第 3 步：同步互斥三部曲（核心难点）
  进程同步与互斥  →  信号量机制与经典同步问题  →  管程与死锁
  （从软件方案演进 → PV 操作实战 → 高级封装与死锁攻防）

第 4 步：实验验证
  进程管理-实验环境与代码示例
  （用代码验证前三步的理论，亲手跑一遍 fork + 信号量）
```
