- **同级技术**：管程（信号量的高级封装）、Java synchronized/Lock

## 概述（Overview）
> **进程同步**（直接制约关系）：为完成某种任务而建立的多个进程，因需要在某些位置协调工作次序而产生的制约关系。
> **进程互斥**（间接制约关系）：多个进程不能同时访问同一临界资源而产生的制约关系。

**临界资源**：一个时间段内只允许一个进程使用的资源（如打印机、摄像头）。

### 临界区访问的四部分

```
do {
    ┌─────────────┐
    │  进入区      │ ← 检查可否进入，上锁（设置"正在访问"标志）
    ├─────────────┤
    │  临界区      │ ← 实际访问临界资源的代码段
    ├─────────────┤
    │  退出区      │ ← 解锁（解除"正在访问"标志）
    ├─────────────┤
    │  剩余区      │ ← 其他处理
    └─────────────┘
} while (true);
```

### 互斥访问的四原则

| 原则 | 含义 |
|------|------|
| **空闲让进** | 临界区空闲时，应允许请求进程立即进入 |
| **忙则等待** | 已有进程在临界区时，其他进程必须等待 |
| **有限等待** | 等待进入临界区的进程应在有限时间内进入（不会饥饿） |
| **让权等待** | 不能进入临界区时，应立即释放 CPU（不忙等待） |

## 设计初衷（Motivation）

### 软件实现方法的演进——四种算法对比

```cpp
// === 算法1：单标志法 ===
// 问题：违背"空闲让进"——必须轮流转交权限
int turn = 0;                // turn 表示当前允许进入的进程号

P0: while(turn != 0);       // 进入区：等轮到 P0
    临界区;
    turn = 1;                // 退出区：交给 P1

P1: while(turn != 1);
    临界区;
    turn = 0;                // 退出区：交给 P0

// === 算法2：双标志先检查 ===
// 问题：违背"忙则等待"——检查和上锁不是原子操作，可能同时进入
bool flag[2] = {false, false};
// flag[i]=true 表示进程 i 想进入临界区

P0: while(flag[1]);          // 进入区：先检查 P1 是否想进
    flag[0] = true;          // 进入区：后上锁（❌ 这里可能被切换！）
    临界区;
    flag[0] = false;         // 退出区

// === 算法3：双标志后检查 ===
// 问题：违背"空闲让进"和"有限等待"——都上锁后互相等待
P0: flag[0] = true;          // 进入区：先上锁
    while(flag[1]);          // 进入区：后检查
    临界区;
    flag[0] = false;         // 退出区

// === 算法4：Peterson 算法 ===
// 结合单标志法和双标志法：主动争取 + 主动谦让
// ✅ 满足空闲让进、忙则等待、有限等待
// ❌ 仍然违背让权等待（while 循环忙等）
bool flag[2] = {false, false};
int turn = 0;                // turn 表示优先让哪个进程进入

P0: flag[0] = true;          // 进入区：主动争取
    turn = 1;                // 进入区：主动谦让（让 P1 优先）
    while(flag[1] && turn==1);// 进入区：P1 想进 且 自己谦让了 → 等待
    临界区;
    flag[0] = false;         // 退出区
```

### 硬件实现方法

| 方法 | 原理 | 优点 | 缺点 |
|------|------|------|------|
| **中断屏蔽** | 关中断→访问临界区→开中断 | 简单高效 | 不适用于多处理机、仅限内核进程 |
| **TSL 指令** | 硬件原子指令，TestAndSet | 适用于多处理机 | 不满足让权等待 |
| **Swap/XCHG 指令** | 硬件原子指令，交换值 | 同 TSL | 同 TSL |
| **互斥锁（自旋锁）** | acquire/release 原子操作 | 等待短时代价低，适用多核 | 违背让权等待，不适用单核 |

```cpp
// 互斥锁（自旋锁）原理
acquire() {
    while (!available);       // 忙等待（自旋）
    available = false;        // 获得锁
}
release() {
    available = true;         // 释放锁
}
```
