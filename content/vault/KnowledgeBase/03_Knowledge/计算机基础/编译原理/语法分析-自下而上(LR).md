# 语法分析（二）：自下而上 LR 分析法

## 📍 知识体系定位
- **所在层级**：XD-4 编程语言与编译 → 语法分析
- **上游依赖**：<a href="obsidian://open?file=语法分析-自上而下(LL)">编译原理-语法分析-自上而下(LL)</a>
- **下游延伸**：Yacc/Bison 编译器生成器、SQL 解析器

## 概述（Overview）
> 自下而上分析采用**移进-归约**模式——从输入串出发，不断将栈顶的**句柄**（最左直接短语）归约为产生式左部，直到归约到开始符号。**LR 分析法**（Left-to-right, Rightmost derivation inverse）是基于 DFA + 栈的最强自底向上算法族：LR(0) → SLR(1) → LR(1) → LALR(1) 能力递减但实用性递增。

## 设计初衷（Motivation）

### 四种 LR 变体对比

| 方法 | 向前看 | 状态数 | 能力 | 实际应用 |
|------|--------|--------|------|---------|
| LR(0) | 不看 | 少 | 最弱 | 仅理论基础 |
| SLR(1) | FOLLOW 集 | 同 LR(0) | 中 | 简单语言 |
| LR(1) | 向前搜索符 | **极多** | **最强** | 理论完备 |
| **LALR(1)** | 合并同心 LR(1) | **同 LR(0)** | 接近 LR(1) | **Yacc/Bison** |

### 设计思想
LALR(1) 是工程与理论的完美折中——它合并 LR(1) 的"同心状态"（核心相同但搜索符不同的状态），使状态数从 LR(1) 的数千降到 LR(0) 的数百，同时保留了 LR(1) 约 95% 的识别能力。这就是为什么 Yacc/Bison 选择 LALR(1) 作为底层算法。

### 跨学科溯源
- LR 分析表 → XD-5（Action/Goto 二维表驱动 + 状态栈 + 符号栈，本质是下推自动机 PDA 的确定性实现）
- 同心状态合并 → XD-5（等价类划分：搜索符不同但核心相同的项目集合可合并）

## 实现（Implementation）

### 移进-归约四动作

| 动作 | 含义 |
|------|------|
| **移进(S)** | 将下一个输入符号压入栈 |
| **归约(R)** | 将栈顶的句柄替换为产生式左部非终结符 |
| **接受(Acc)** | 分析成功（归约到开始符号且输入结束） |
| **报错** | 语法错误 |

### Yacc/Bison 规则示例

```yacc
expr: expr '+' term   { $$ = $1 + $3; }
    | term            { $$ = $1; }
    ;
term: term '*' factor { $$ = $1 * $3; }
    | factor          { $$ = $1; }
    ;
```

> **💡 补充**：LL vs LR 的选择——LL 可手写递归下降（代码直观），LR 通常用生成器（Yacc/Bison）。LL 文法必须是"无左递归"的（需要改写），LR 天然支持左递归。大多数编程语言的实际文法更接近 LR（如 C 语言的 `if-else` 悬挂问题在 LR 中更自然解决）。
