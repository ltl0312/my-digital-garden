# 语法分析（一）：自上而下 LL(1)

## 📍 知识体系定位
- **所在层级**：XD-4 编程语言与编译 → 语法分析
- **上游依赖**：<a href="obsidian://open?file=词法分析">编译原理-词法分析</a>（Token 流是输入）
- **下游延伸**：手写递归下降解析器（PEG）、JSON/XML 解析器

## 概述（Overview）
> 自上而下分析从文法的**开始符号出发**，尝试推导出输入句子。**LL(1)** 是无回溯的确定性算法——**L**（Left to Right 扫描）、**L**（Leftmost 最左推导）、**1**（向前看 1 个符号）。要使用 LL(1)，必须先消除左递归和提取左公因子。

## 设计初衷（Motivation）

### 两大障碍

| 障碍 | 问题 | 解决方案 |
|------|------|---------|
| 左递归 `A → Aα` | 无限递归死循环 | 改写为右递归 `A → βA'` |
| 回溯 | 多候选式有相同前缀 → 选错需撤销 | 提取左公因子：`A → αβ | αγ` 改写为 `A → αA', A' → β | γ` |

### FIRST 集与 FOLLOW 集

- **FIRST(A)**：从 A 推导出的所有串中，第一个终结符的集合。用于确定"接下来应该选哪个产生式"。
- **FOLLOW(A)**：在所有合法句型中，紧跟在 A 后面的终结符集合。用于处理"A 可能推导出空串 ε"的情况。

### LL(1) 文法条件

对于所有具有相同左部的产生式 `A → α | β`：
1. `FIRST(α) ∩ FIRST(β) = ∅`（首符号不重叠）
2. 如果其中一个可推导出 ε，则其 FIRST 集与 FOLLOW(A) 不相交

### 跨学科溯源
- LL 预测分析表 → XD-5（二维查表：M[非终结符, 输入符号] → 产生式，本质上是一个确定性决策表）

## 实现（Implementation）

### 消除左递归示例

```
原文法：E → E + T | T
改写后：E → T E'
       E' → + T E' | ε
```

### LL(1) 预测分析表

