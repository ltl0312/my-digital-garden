# 编译原理 — 学习环境与工具

## Step 1: 推荐工具

| 工具 | 用途 |
|------|------|
| **ANTLR** | 现代解析器生成器（LL(*)），Java/C++/Python/JS 多语言目标 |
| **Flex + Bison** | 经典 Lex/Yacc 组合，C/C++ 目标 |
| **Godbolt** | 在线查看 C/C++ 编译后的汇编（观察优化效果） |
| **LLVM** | 完整的编译器基础设施，学习 IR、优化 Pass、目标代码生成 |

## Step 2: ANTLR 快速体验

```bash
# 安装 ANTLR
pip install antlr4-tools

# 编写语法文件 Expr.g4
grammar Expr;
expr: expr ('+'|'-') term | term;
term: term ('*'|'/') factor | factor;
factor: INT | '(' expr ')';
INT: [0-9]+;
WS: [ \t\r\n]+ -> skip;

# 生成解析器
antlr4 -Dlanguage=Python3 Expr.g4
```

## Step 3: Godbolt 优化观察

- 打开 https://godbolt.org/
- 粘贴 C 代码 → 选择编译器 GCC/Clang
- 切换 `-O0` vs `-O2` → 对比汇编输出
- 观察：常量折叠、循环展开、尾调用优化等

## 常见问题

1. **理论与实践脱节**：用手写一个简单的 JSON 解析器（递归下降 LL）建立直觉，再看 LR 理论。
2. **LL vs LR 选择困难**：手写用递归下降（LL），自动生成用 Yacc/Bison（LR/LALR），ANTLR 用 LL(*)。
