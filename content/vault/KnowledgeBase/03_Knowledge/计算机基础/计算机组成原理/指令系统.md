# 指令系统

## 📍 知识体系定位
- **所属技术栈**：跨学科纵深
- **所在层级**：XD-1 数字系统与体系结构 → 指令集架构
- **上游依赖**：<a href="obsidian://open?file=存储系统">计算机组成原理-存储系统</a>
- **下游延伸**：XD-4 编译原理（编译器后端将 AST 翻译为指令序列）
- **同级技术**：x86-64 ISA、ARM ISA、RISC-V ISA

## 概述（Overview）
> **指令系统（ISA, Instruction Set Architecture）** 是软件与硬件的接口——定义了 CPU 能理解的所有指令格式、操作码、寻址方式和寄存器组织。一条指令 = 操作码（做什么）+ 地址码（操作数在哪）。**CISC**（x86）追求一条指令做更多事；**RISC**（ARM/RISC-V）追求每条指令简单快速。

## 设计初衷（Motivation）

### CISC vs RISC

| 维度 | CISC（x86） | RISC（ARM/RISC-V） |
|------|------------|-------------------|
| 指令长度 | 变长（1-15字节） | 定长（4字节） |
| 指令数量 | 多（数百条） | 少（数十条） |
| 寻址方式 | 多（10+种） | 少（3-5种） |
| 访存指令 | 运算指令可访存 | 仅 Load/Store 访存 |
| 实现 | 微程序控制 | 硬布线控制 |
| 代表 | Intel/AMD x86 | ARM M系列、RISC-V |

### 设计思想
RISC 的精髓是"简单即快"——所有指令等长（流水线各阶段时间一致）、只有 Load/Store 访存（寄存器操作最快）、指令数量少（硬件实现简单，主频可以更高）。CISC 的生存之道是"兼容性"——x86 从 1978 年的 8086 到今天的 Core i9，向后兼容了 40+ 年的所有软件。

### 跨学科溯源
- 指令格式设计 → XD-4（编译器：操作码字段编码类似于语言的词法标记 Token）
- 寻址方式 → XD-5（数据结构：基址寻址 = 数组访问；变址寻址 = 指针运算）

## 实现（Implementation）

### 指令格式

```
一条机器指令 = [操作码 OP] + [地址码 A1 A2 A3...]

三地址指令：ADD R1, R2, R3    → R1 = R2 + R3
二地址指令：ADD R1, R2         → R1 = R1 + R2
单地址指令：INC R1             → R1 = R1 + 1
零地址指令：RET（隐含操作数，如栈顶）
```

### 常见寻址方式

| 寻址方式 | 含义 | 示例 |
|---------|------|------|
| 立即寻址 | 操作数在指令中 | `MOV AX, 5` |
| 直接寻址 | 指令中给出操作数地址 | `MOV AX, [1000]` |
| 寄存器寻址 | 操作数在寄存器中 | `MOV AX, BX` |
| 寄存器间接 | 寄存器存的是地址 | `MOV AX, [BX]` |
| 基址寻址 | `[基址寄存器 + 偏移量]` | 访问数组元素 |
| 变址寻址 | `[变址寄存器 + 形式地址]` | 字符串处理 |

> **💡 补充**：现代 CPU 实际使用的是微操作（μop）——x86 的复杂指令被硬件解码为多个简单的 RISC-like μop 再执行。这意味着 CISC 的"前端"复杂，"后端"与 RISC 趋同。
