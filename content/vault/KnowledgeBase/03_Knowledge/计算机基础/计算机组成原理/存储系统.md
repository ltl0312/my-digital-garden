# 存储系统

## 📍 知识体系定位
- **所属技术栈**：跨学科纵深
- **所在层级**：XD-1 数字系统与体系结构 → 存储层次
- **上游依赖**：<a href="obsidian://open?file=系统概述">计算机组成原理-系统概述</a>
- **下游延伸**：XD-2 操作系统（虚拟内存管理）
- **同级技术**：数据库存储引擎（B+Tree 页结构）

## 概述（Overview）
> 存储系统采用"金字塔"层次结构——从最快的寄存器（1 cycle）到最慢的磁盘（百万 cycles），通过**时间局部性**和**空间局部性**原理，用 Cache 和虚拟内存弥合 CPU 与主存之间的速度鸿沟。

## 设计初衷（Motivation）

### 设计思想
存储器的速度-容量-价格不可能三角：寄存器最快但最贵（容量 KB 级），磁盘最慢但最便宜（容量 TB 级）。层次化存储通过"把常用的数据放在离 CPU 更近的地方"来解决这个矛盾——Cache 缓存主存的"热点"，主存作为磁盘的"缓存"。

### 跨学科溯源
- Cache 替换算法（LRU）→ XD-5（缓存淘汰策略：最近最少使用的数据被优先淘汰）
- 虚拟内存 → XD-2（MMU 地址转换、TLB 快表、缺页中断）

## 实现（Implementation）

### 存储器层次结构

```
寄存器 (1 cycle, <1KB)          ← CPU 内部
    ↓
L1 Cache (2-4 cycles, 32KB)     ← SRAM，指令/数据分离
    ↓
L2 Cache (10-20 cycles, 256KB)  ← SRAM
    ↓
L3 Cache (30-50 cycles, 8MB+)   ← SRAM，多核共享
    ↓
主存 (100-200 cycles, GB级)      ← DRAM
    ↓
固态硬盘 SSD (10-100μs, TB级)    ← NAND Flash
    ↓
机械硬盘 HDD (10ms, TB级)        ← 磁盘
```

### Cache 三大映射方式

| 方式 | 原理 | 优点 | 缺点 |
|------|------|------|------|
| 直接映射 | 每个主存块映射到唯一的 Cache 行 | 简单，硬件成本低 | 冲突率高 |
| 全相联映射 | 主存块可放入 Cache 任意行 | 冲突率最低 | 比较电路复杂 |
| 组相联映射 | n 路组相联（每组 n 行） | 折中方案 | 主流选择 |

### 虚拟存储器

```
虚拟地址 → [TLB] → 物理地址
TLB（快表）：页表的高速缓存，加速地址转换
缺页：访问的页面不在主存中 → 触发缺页中断 → OS 从磁盘调入
替换算法：FIFO（先进先出）、LRU（最近最少使用）、Clock（时钟算法）
```

> **💡 补充**：程序员的实际感知——`int[]` 顺序访问比随机访问快 10-100 倍（空间局部性 + Cache 预取）；链表遍历比数组遍历慢得多（指针跳转破坏空间局部性）。
