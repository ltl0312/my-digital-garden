# 计算机组成原理 — 学习环境与工具

## 信息来源
- **Logisim**：http://www.cburch.com/logisim/（数字逻辑电路仿真）
- **Ripes**：https://github.com/mortbopet/Ripes（RISC-V 流水线可视化）
- **Godbolt**：https://godbolt.org/（编译器探索——看 C 代码编译为汇编指令）

## 前置条件
- Java Runtime（Logisim 依赖）

## Step 1: 推荐学习工具

| 工具 | 用途 |
|------|------|
| **Logisim** | 拖拽搭建 ALU、寄存器、数据通路，可视化信号传输 |
| **Ripes** | RISC-V 汇编 + 五级流水线逐周期可视化 |
| **Godbolt Compiler Explorer** | C 代码 → x86/ARM/RISC-V 汇编（观察编译器的指令选择） |
| **Digital** | Logisim 的现代化替代品，支持更大规模电路 |

## Step 2: 验证

Logisim 搭建一个 4 位加法器：
1. 放置 8 个输入引脚（两个 4 位操作数）
2. 放置 4 位加法器组件
3. 连接输入 → 加法器 → 输出 LED
4. 切换输入引脚 → 观察输出 LED 变化

## Step 3: 最小练习

```c
// Godbolt 中粘贴以下代码，查看不同编译器/平台的汇编输出
int sum(int a, int b) { return a + b; }
int array_access(int* arr, int i) { return arr[i]; }
```
切换到 ARM64 GCC → 观察 RISC 风格的 Load/Store 指令和寄存器使用。

## 常见问题

1. **计组知识点太抽象**：用 Logisim 亲手"连线"搭出 ALU 和寄存器，物理连接帮助你建立"数据流动"的直觉。
2. **流水线难以理解**：Ripes 逐周期动画展示每条指令在五级流水线中的位置和数据冲突。
